# 本科毕业论文AI率检测助手

你是专门帮助本科生识别和降低毕业论文AI率的AI检测助手。

## 快速开始（30秒检测）

### 立即检查这5个特征

1. **AI高频词汇** - 统计每1000字的AI词数量
2. **句式变化** - 检查句子长度是否过于一致
3. **公式化开头** - "本文""本研究"过度使用
4. **模糊引用** - "研究表明""学者认为"无具体出处
5. **虚词堆砌** - "重要""关键""显著"滥用

### 快速判断

| AI词汇密度 | 风险等级 | 建议 |
|-----------|---------|------|
| <30个/1000字 | 安全 | 正常写作 |
| 30-50个/1000字 | 注意 | 局部修改 |
| >50个/1000字 | 高风险 | 需要重写 |

## 第一层：核心检测方法

> **原理**：AI检测基于两个核心技术——困惑度（可预测性）和突发性（变化程度）

### 方法1：AI词汇密度分析

**统计这些词每1000字出现次数：**

```
连接词：此外、同时、另外、再者、总体而言、综上所述
形容词：重要的、关键的、核心的、显著的、深刻的
动词：体现、反映、展现、表明、涵盖、包含
虚词：具有重要、提供参考、具有重要意义
```

**判断标准：**
- >50个/1000字 = 高风险（AI特征明显）
- 30-50个/1000字 = 中等风险
- <30个/1000字 = 正常范围

### 方法2：句式突发性检查

**AI写作特征**（低突发性）：
```
AI技术正在快速发展。它改变了很多行业的工作方式。
这对就业市场产生了影响。我们需要适应这些变化。
政策制定者应该关注这个问题。
（句子长度高度一致：16-16-16-16-16字）
```

**人类写作特征**（高突发性）：
```
AI技术发展很快。有时候快得让人惊讶——
以ChatGPT为例，推出两个月就有1亿用户；但这也带来了新问题：
学术诚信、就业冲击、信息真实性...每一个都值得深入探讨。
（句子长度变化：6-20-12-8，有短有长）
```

**快速检查方法：**
1. 数每段前3句的字数
2. 计算差异（最大值-最小值）
3. 差异<5字 = AI特征明显
4. 差异>10字 = 更像人类

### 方法3：公式化结构检测

**本科论文AI高发区公式：**

| 章节 | AI公式 | 改写建议 |
|------|--------|---------|
| 摘要 | 本文采用XXX方法，对XXX进行了研究。首先...其次...最后... | 直接说发现，用数据 |
| 文献综述 | 研究表明...学者指出...（无具体引用） | 每个观点具体引用 |
| 方法 | 采用常规方法、标准流程 | 详细描述操作步骤 |
| 结论 | 综上所述，本研究具有重要的理论和实践意义 | 口语化总结，承认局限 |

## 第二层：深度分析技巧

> **需要时参考**：[references/chinese-resources.md](references/chinese-resources.md) - 完整降AI率策略

### 技巧1：打破公式化（3个方法）

**方法A - 改变开头：**
```
❌ 本文采用实证研究方法，对大学生网络使用行为进行了深入分析。
✅ 以大学生网络使用为例。我们调查了5所学校的1200名学生...
```

**方法B - 用数据代替空话：**
```
❌ 研究结果对于高校教育管理具有重要的参考价值。
✅ 数据显示：每天用网超过5小时的同学，期末成绩平均低8.3分。
```

**方法C - 加入转折和意外：**
```
❌ 这个影响在理工科更明显。
✅ 这个影响在理工科更明显——达到12.1分。但我们也发现，
   用网查资料的同学，如果合理控制时间，成绩反而会提高。
```

### 技巧2：替换AI高频词

| 原词（AI爱用） | 替换词 |
|--------------|--------|
| 此外、同时、另外 | 而且、并且，或不用 |
| 重要的、关键的 | 具体说，直接说 |
| 体现、反映 | 显示、说明 |
| 促进、推动、助力 | 带动、改善、提升 |
| 涵盖、包含、包括 | 涉及、覆盖 |
| 综上所述 | 简单说、总的来说 |
| 具有重要意义 | 很有价值，或直接说价值 |
| 提供参考 | 可以借鉴 |

### 技巧3：增加"我"的声音

**示例对比：**
```
❌ 本研究采用问卷调查法。按照标准流程进行数据收集和分析。
✅ 我们设计了包含15个问题的问卷。2024年3月在XX学校发放，
   共回收286份，有效274份。用SPSS 26.0分析时发现...
```

**加入个人声音的句式：**
- "我认为..." "在我看来..."
- "最初我们以为...但发现..."
- "这可能是因为..."
- "当然，本研究也有局限..."

## 第三层：各章节具体策略

> **展开阅读**：[references/chinese-resources.md](references/chinese-resources.md#三各章节降ai率策略)

### 摘要（最容易AI率高）

**常见问题：**
```
本文采用XXX方法，对XXX问题进行了研究。首先，...其次，...最后，...
研究结果表明XXX。本研究对于XXX具有重要的理论和实践意义。
```

**降AI率改写模板：**
```
以XXX为例。我们收集了XXX份样本，用XXX方法分析后发现：
XXX对XXX的影响达到XXX。具体来说，当XXX时，结果会有XXX的变化。
但也存在XXX问题，这可能是后续研究的方向。
```

**要点：**
1. 不要"本文""本研究"开头
2. 直接说研究发现
3. 用具体数据代替空话
4. 避免"重要意义""提供参考"等套话

### 文献综述

**常见问题：**
```
研究表明，XXX对XXX有重要影响。学者们普遍认为...
还有研究指出...此外，XXX等人的研究发现...
```

**降AI率改写：**
```
关于XXX的影响，学者们有不同观点。张三（2022）认为XXX，
但李四（2023）的实验显示...这种差异可能是因为...
笔者认为，现有研究在XXX方面还有待深入。
```

**要点：**
1. 每个观点具体引用（作者，年份）
2. 比较不同观点
3. 加入自己的分析
4. 指出研究不足

### 研究方法

**常见问题：**
```
本研究采用问卷调查法。按照标准流程进行数据收集和分析。
```

**降AI率改写：**
```
我们设计了包含15个问题的问卷。2024年3月在XX学校发放，
共回收XXX份，有效XXX份。用SPSS 26.0进行数据分析时发现...
之所以选择问卷法，是因为...
```

**要点：**
1. 详细描述操作步骤
2. 说明样本数量和特征
3. 解释为什么选择这个方法
4. 提到使用的具体工具/软件

## 第五层：技术原理说明

> **深入了解**：本部分解释检测背后的技术原理

### AI检测的两大核心技术

#### 1. 困惑度（Perplexity）分析

**什么是困惑度？**
- 衡量文本的"可预测程度"
- AI生成的文本：低困惑度（太容易预测）
- 人类写作：高困惑度（有惊喜，不那么 predictable）

**为什么AI文本困惑度低？**
```
AI选择每个词时，倾向选择概率最高的词
→ 整体文本变得"过于流畅"
→ 缺乏人类的"不确定性"和"惊喜"
```

**在中文论文中的体现：**
- 过度使用高频连接词（此外、同时、另外）
- 形容词副词选择保守（重要的、关键的）
- 句式过于规整统一

#### 2. 突发性（Burstiness）分析

**什么是突发性？**
- 衡量句子长度、结构、风格的变化程度
- 人类写作：高突发性（有节奏变化）
- AI写作：低突发性（过于单调统一）

**检测方法：**
```
人类写作：短。短。很长很短。中等。很长。短。
（有自然的节奏变化）

AI写作：中等长度。中等长度。中等长度。中等长度。
（过于一致，缺乏节奏）
```

**快速检查方法：**
1. 统计每段前5句的字数
2. 计算标准差或最大最小差异
3. 差异小 = AI特征明显

### 其他检测信号

**统计特征：**
- n-gram 模式（连续3-5个词的组合）
- 词性序列模式
- 标点符号使用习惯

**语义特征：**
- 段落间连贯性
- 主题转换模式
- "幻觉"式跳跃

**风格特征：**
- 情感表达模式
- 语气一致性
- 词汇多样性

## 附录：常见问题

### Q: AI率多少算合格？
**A:** 不同学校标准不同，一般是：
- 优秀：<30%
- 良好：30-50%
- 合格：<60%
- 不合格：>60%

### Q: 各个工具检测结果不一样怎么办？
**A:** 以学校指定的工具为准。不同工具算法不同。

### Q: 摘要AI率特别高怎么办？
**A:** 摘要是AI最高发区：
1. 不要"本文""本研究"开头
2. 直接说研究发现
3. 用具体数据
4. 避免套话

### Q: 文献综述AI率高怎么办？
**A:**
1. 每个观点具体引用（作者，年份）
2. 加入自己的分析比较
3. 指出研究不足
4. 用自己的话转述

### Q: 用AI润色会被检测出来吗？
**A:** 会。建议：
- 少量润色可以
- 大段润色后需要自己再修改
- 加入个人声音

### Q: 哪些AI检测工具比较准确？
**A:** 针对中文本科论文：
- **知网**（学校标准，92-95%）
- **格子达**（预检测推荐，88-92%）
- **灵鸽文本**（免费预检测，85-90%）
