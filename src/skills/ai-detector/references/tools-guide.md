## 工具概览

### 本项目检测工具

所有检测功能整合在 `ai_detector_all.py` 中，提供6种检测方法：

| 检测类型 | 命令 | 用途 | 速度 |
|---------|------|------|------|
| **vocabulary** | `vocabulary 论文.txt` | AI词汇密度检测 | ⚡⚡⚡ |
| **burstiness** | `burstiness 论文.txt` | 句式突发性检测 | ⚡⚡⚡ |
| **paraphrasing** | `paraphrasing 论文.txt` | 改写攻击检测 | ⚡⚡ |
| **abstract** | `abstract "摘要内容"` | 摘要专用检测 | ⚡⚡⚡ |
| **comprehensive** | `comprehensive 论文.txt` | 综合检测（推荐） | ⚡ |
| **batch** | `batch *.txt` | 批量检测 | ⚡⚡ |

### 学校标准工具

| 工具 | 准确率 | 学校使用 | 特点 |
|------|--------|---------|------|
| **知网 (CNKI)** | 92-95% | 大部分院校 | 最终标准，与查重系统绑定 |
| **格子达** | 88-92% | 部分院校 | 中文适配好，预检测推荐 |
| **万方** | 80-85% | 少数院校 | 学术资源整合强 |

## 统一检测工具 - ai_detector_all.py

### 中文检测实现示例

```python
import jieba
from collections import Counter

class ChineseAIDetector:
    def __init__(self):
        self.ai_vocab = {
            'connection': ['此外', '同时', '另外', '再者'],
            'adjective': ['重要的', '关键的', '核心的', '显著的'],
            'verb': ['体现', '反映', '表明', '展现'],
            'formulaic': ['具有重要意义', '提供参考', '综上所述']
        }

    def detect_vocabulary_density(self, text):
        """检测AI词汇密度"""
        total_chars = len(text)
        ai_count = 0

        for category, words in self.ai_vocab.items():
            for word in words:
                ai_count += text.count(word)

        density = (ai_count / total_chars) * 1000
        return {
            'ai_count': ai_count,
            'density_per_1000': round(density, 1),
            'total_chars': total_chars
        }

    def detect_burstiness(self, text):
        """检测句式突发性"""
        sentences = [s.strip() for s in text.split('。') if s.strip()]
        lengths = [len(s) for s in sentences]

        if not lengths:
            return {'cv': 0}

        import numpy as np
        mean_len = np.mean(lengths)
        std_len = np.std(lengths)
        cv = std_len / mean_len if mean_len > 0 else 0

        return {
            'mean_length': round(mean_len, 1),
            'std_length': round(std_len, 2),
            'cv': round(cv, 3),
            'min_length': min(lengths),
            'max_length': max(lengths)
        }
```

## 快速检测流程

**推荐使用顺序**：

```bash
# 1. 快速检查摘要（AI率最高发区）
python scripts/ai_detector_all.py abstract "摘要内容"

# 2. 综合检测完整论文
python scripts/ai_detector_all.py comprehensive 论文.txt

# 3. 批量检测各章节，定位问题
python scripts/ai_detector_all.py batch 章节*.txt -o report.json

# 4. 对高风险章节专项检测
python scripts/ai_detector_all.py paraphrasing 高风险章节.txt
```

## 注意事项

1. **检测结果仅供参考**：工具辅助判断，不能完全替代人工审核
2. **结合学校工具**：以学校指定的检测工具（如知网）为准
3. **反复修改检测**：一次修改不够，需要反复迭代
4. **保持学术诚信**：工具是为了帮助改进写作，不是为了规避检测
5. **依赖包可选**：无jieba/numpy也能运行，但功能会受限

## 外部检测工具

### 知网 (CNKI)

**特点**：
- 学校最终标准，与查重系统绑定
- 准确率最高（92-95%）
- 支持批量检测

**使用方式**：
- 学校统一组织检测
- 需要导师分配账号
- 检测时间通常在定稿后

### 格子达

**特点**：
- 中文适配好
- 预检测推荐
- 准确率较高（88-92%）

**使用方式**：
- 官网注册使用
- 按篇付费
- 适合初稿和修改中检测

### 灵鸽文本

**特点**：
- 免费预检测
- 准确率中等（85-90%）
- 界面友好

**使用方式**：
- 官网免费使用
- 有字数限制
- 适合快速自查

### 其他工具

| 工具 | 准确率 | 费用 | 特点 |
|------|--------|------|------|
| PaperYY | 80-85% | 免费/付费 | 检测速度快 |
| 智邦 | 75-80% | 免费 | 界面简单 |
| 维普 | 70-75% | 付费 | 老牌工具 |
