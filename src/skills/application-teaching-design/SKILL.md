# 应用型本科专业课程教学设计生成

## 任务目标
本 Skill 用于生成符合应用型本科教学设计规范的完整教学设计方案，帮助教师：
- 构建完整的知识建模图（核心知识点标红🔴、结构化知识框架标蓝🔵、先决知识点标绿🟢）
- 制定符合学习水平要求的知识点清单（记忆、理解、运用）
- 挖掘课程思政点并体现在知识建模图中
- 明确学习先决知识
- 分类汇总课上/课下资源和时间
- 设计完整的活动序列（活动1-N）
- 为每个活动构建活动知识建模图
- 制定每个活动的活动目标
- 设计详细的活动任务序列（导入任务、任务一/二/三...）
- 规范师生交互过程（教师行为、学生行为）
- 明确学习资源和评价标准
- 记录教学备注和反思

适用场景：应用型本科专业教师进行课程教学设计时，特别是需要严格按照规范要求提交教学设计的场合。

## 前置准备
在使用本技能前，需要提供以下课程信息，用户未输入必填信息时，提示用户输入以下课程信息：

**必填信息：**
- 课程名称：如"动态思维基础"
- 教案名称：如"动态思维的觉醒"
- 学时安排：如"4学时"（需明确课上课下分配，如课上200分钟+课下400分钟）
- 课程类型：应用型研究方向项目化教学课程/专业基础课程/公共基础课程/就业方向项目化教学课程
- 教学形式：讲授形式/翻转课堂
- 适用专业：如"本科动画专业"
- 学生层次：如"大一学生"
- 任务内容：详细描述本课的教学内容和要求

**选填信息：**
- 评价重点：需要特别关注的学习成果（如"动态思维理解"、"动态速写能力"、"人机协同创作"等）
- 课程思政点：需要融入的思政元素（如"工匠精神"、"文化自信"、"创新意识"等）
- 教学资源：已有的教学资源（如视频、案例、课件等）

**说明：**
- 教学形式将决定师生交互过程的设计方式
- 学时安排需要明确课上课下的时间分配，与活动序列保持一致
- 适用专业将自动判断学科类型（政治类、理工类、文史类、艺术类），并据此调整输出要求

## 操作步骤

**重要说明**：本技能将严格按照应用型本科教学设计规范的10个核心要素输出完整的教学设计方案。使用者只需提供课程基本信息，技能将自动生成符合规范的完整方案。

### 步骤1：构建知识建模图

**课程类型说明**：
本规范适用于两大类课程：
- **第一类**：应用型研究方向项目化教学课程/专业基础课程/公共基础课程
- **第二类**：就业方向项目化教学课程

---

#### 就业方向项目化教学课程填写注意事项

1. **知识点挖掘全面，注重培养学生工作任务能力**：特别是要明显包含但不仅限于以下类型的知识组块：
   - 任务方案研发（工程测量、计算或材料选配）
   - 任务实施方案的制定方法
   - 任务实施流程
   - 任务实施效果评测
   - 常见任务问题原因及解决方案

   根据专业不同，可能以上类型知识都有，也可能只有部分类型的知识。

2. **工程操作知识点挖掘**："任务方案研发（工程测量、计算或材料选配），任务实施方案的制定方法，任务实施流程，任务实施效果评测，常见任务问题原因及解决方案"等知识组块，必须有展开的知识点，展开的知识点不能完全是教材上的知识点，需要教师依据自身的工程经验挖掘工程操作知识点。

3. **不能仅依赖教材**：知识建模图不能仅是本专业教材上的知识点。

4. **核心知识点标注**：是"核心知识点"，要在知识建模图中标红（图形边线和字体均标红）。

5. **结构化知识框架标注**：是"核心的结构化知识框架"的，以"知识点-知识点-知识点-知识点…"表示，要体现在知识建模图中，并且标蓝（图形边线和字体均标蓝）。

6. **先决知识点标注**：先决知识点要与本次课的专业知识点有紧密相关的关系，要体现在知识建模图中，并且标绿（图形边线和字体均标绿）。

#### 应用型研究方向项目化教学课程/专业基础课程/公共基础课程填写注意事项

1. **知识点挖掘全面**：必须涵盖与后续项目化教学课程紧密关联的知识组块。

2. **陈述性知识点后尽可能列出相关范例知识点**：尤其是一些理论性强、难以理解的陈述性知识点后，必须有范例知识点。

3. **核心知识点标注**：是"核心知识点"，要在知识建模图中标红（图形边线和字体均标红）。

4. **结构化知识框架标注**：是"核心的结构化知识框架"的，以"知识点-知识点-知识点-知识点…"表示，也要体现在知识建模图中，并且标蓝（图形边线和字体均标蓝）。

5. **先决知识点标注**：先决知识点要与本次课的专业知识点有紧密相关的关系，要体现在知识建模图中，并且标绿（图形边线和字体均标绿）。

**知识建模图要求：**
1. **知识点挖掘全面**：必须涵盖与后续项目化教学课程紧密关联的知识组块
2. **陈述性知识点后列出范例**：尤其是一些理论性强、难以理解的陈述性知识点后，必须有范例知识点
3. **核心知识点标红**：使用🔴标注核心知识点（图形边线和字体均标红）
4. **结构化知识框架标蓝**：使用🔵标注核心的结构化知识框架（图形边线和字体均标蓝），以"知识点-知识点-知识点-知识点…"表示
5. **先决知识点标绿**：使用🟢标注先决知识点（图形边线和字体均标绿），要与本次课的专业知识点有紧密相关关系

**知识建模图结构：**
```
🔴 核心概念：XXX
│
├── 🔴 子概念1
├── 🔴 子概念2
├── 🔴 子概念3
│
├── 🔵 结构化知识框架（步骤包含1/2/3...）
│   ├── 步骤包含1：XXX
│   ├── 步骤包含2：XXX
│   └── 步骤包含3：XXX
│
├── 🟢 先决知识点
│   └── 是前提 → 核心概念
│
├── 支持案例与资源
│   ├── 案例1 → 支持 → 子概念1
│   ├── 案例2 → 支持 → 子概念2
│   └── 资源1 → 支持 → 子概念3
│
└── 课程思政点（隐性知识）
    ├── 思政点1 → 支持 → 相关概念
    └── 思政点2 → 支持 → 相关概念
```

**设计要点：**
- 使用树状结构或思维导图形式展示知识点之间的逻辑关系
- 使用"支持"、"具有特征"、"内容包含"、"步骤包含"、"是前提"等关系连接知识点
- 确保所有核心知识点、先决知识点、课程思政点都在知识建模图中体现
- 范例知识点可以是案例、视频、图片、参考书等具体资源

**程序性知识下级知识点图形标注规则**：
- 下级知识点为步骤或流程的仍标识为程序性知识
- 下级知识点不是步骤或流程的标识为陈述性知识

**认知策略提取要求**：
- 认知策略一般不在教材中，需要老师提炼
- 认知策略的作用：问题解决策略、学习方法、信息加工策略等

**事实范例收集要求**：
- 很多事实范例也不在教材中，需要老师持续不断的搜集、整理和补充完善
- 事实范例的作用：方案、产品、现象、案例、例子等

**避免孤立节点规则**：
- 原则上禁止出现孤立节点

**关系子内容数量规则**：
- 从同一个知识点引出的"内容包含""步骤包含"等关系中原则上至少包含2个子内容

### 步骤2：制定学习目标

**课程类型差异说明**：
- **第一类课程**（应用型研究方向项目化教学课程/专业基础课程/公共基础课程）：学习目标包含两部分——知识点（学习水平）、素质目标（课程思政点）
- **第二类课程**（就业方向项目化教学课程）：学习目标包含三部分——知识点（学习水平）、能力目标、素质目标（课程思政点）

#### 2.1 知识点（学习水平）

**知识点（学习水平）要求：**
1. **学习水平类型**：学习水平有记忆、理解、运用三种类型（每个知识点匹配最高层次学习水平）
2. **体现知识建模图**：总活动目标与裁剪活动的最高阶知识点目标，并且一定要体现在知识建模图中
3. **按标准格式撰写**：按照"知识点（学习水平）"的方式撰写

**学习水平定义：**
- **记忆**：能够回忆和识别基本事实、概念、原理等
- **理解**：能够解释和说明概念、原理的含义和内在逻辑
- **运用**：能够在具体情境中应用概念、原理解决问题

**知识点清单示例：**
1. 动态思维的觉醒（理解）
2. 动态思维（理解）
3. 动态视觉元素的审美规律和表现原理（理解）
4. 节奏（理解）
5. 韵律（理解）
6. 平衡（理解）
7. 对比（理解）
8. 动态观察方法（运用）
9. 从看形状转向看姿态/轨迹/力（理解）
10. 轨迹线（运用）

**设计要点：**
- 知识点要全面，涵盖知识建模图中的所有核心知识点
- 每个知识点都要标注学习水平（记忆/理解/运用）
- 知识点的表述要清晰、具体、可测
- 确保知识点与知识建模图保持一致

#### 2.2 能力目标（仅就业方向项目化教学课程需要）

**能力目标填写注意事项：**
1. **对应程序性知识点**：对应程序性知识点的运用学习水平、知识组块的运用水平、××项目工作任务/子任务/任务模块，聚焦学生能够完成任务所具备的能力
2. **来源于运用相应知识点**：能力目标来源于运用相应知识点，需要在知识建模图中体现出来

**能力目标示例：**
1. 能够独立完成××工程测量任务
2. 能够制定××任务实施方案
3. 能够运用××材料选配方法完成材料选择
4. 能够执行××任务实施流程
5. 能够进行××任务效果评测
6. 能够识别并解决××常见任务问题

**设计要点：**
- 能力目标要具体、可测、可评价
- 能力目标要与程序性知识点对应
- 能力目标要在知识建模图中体现
- 能力目标要与项目工作任务对应

#### 2.3 素质目标（课程思政点）

**素质目标（课程思政点）要求：**
1. **挖掘课程思政点**：需要老师挖掘本次课对应的课程思政点
2. **与知识点对应**：需要在上课中有对应的知识点
3. **特有素质**：一些本次课涉及到的特有素质，比如专业知识点相关爱国主义故事
4. **体现在知识建模图中**：思政点（隐性知识）要体现在知识建模图中
5. **用*号标注**：在素质目标后用*号标注课程思政点
6. **可填"/"**：没有可填"/"

**素质目标示例：**
1. 具备'发展变化'的辩证唯物主义世界观*
2. 具备'扎根生活、严谨治学'的工匠精神*
3. 具备'传承中华美学'的文化自信*
4. 具备'人机协同、驾驭技术'的创新意识与主体责任感*
5. 具备'精益求精、追求卓越'的职业态度*
6. 具备'团队协作、责任担当'的专业精神*

**设计要点：**
- 素质目标要与课程内容紧密结合，自然融入
- 素质目标要具体、可测、可评价
- 素质目标要在知识建模图中体现
- 素质目标要在师生交互过程中有对应的环节

### 步骤4：明确学习先决知识

**学习先决知识要求：**
1. **罗列所有先决知识点**：知识建模图中所有先决知识点要全部罗列
2. **按照标准格式撰写**：按照"知识点（学习水平）"的方式撰写
3. **与专业知识点紧密相关**：先决知识点要与本次课的专业知识点有紧密相关关系
4. **在知识建模图中体现**：先决知识点要用🟢标注

**学习先决知识示例：**
1. 平面构成的形式美法则与构成方法（运用）
2. 把握'形'需要注意的事项（理解）

**设计要点：**
- 先决知识是学生学习本次课内容必须具备的基础知识
- 先决知识要与本次课的专业知识点有直接关联
- 先决知识要在知识建模图中用🟢标注
- 先决知识要在导入任务中唤起学生的记忆

### 步骤5：分类汇总课上资源与课下资源

**课上资源与课下资源要求：**
1. **课上资源**：分类汇总本次课所有课上活动的学习资源
2. **课下资源**：分类汇总本次课所有课下活动的学习资源

4. **资源具体明确**：每个资源都要有明确的名称和来源

### 4. 素材库

### 步骤6：明确课上时间与课下时间

**课上时间与课下时间要求：**
1. **课上时间**：与后面课上活动设计的总时长保持一致
2. **课下时间**：与后面课下活动设计的总时长保持一致
3. **时间分配合理**：根据学生身心发展特点与理解水平合理分配时间
4. **时间单位明确**：使用"分钟"作为时间单位

**时间分配示例：**
- 课上时间：200分钟
- 课下时间：400分钟

**设计要点：**
- 课上课下时间要与活动序列保持一致
- 时间分配要考虑学生的认知负荷

### 师生交互过程

   **学生**：回答："动作很慢，因为它的动作幅度小，时间长。"

   **学生**：讨论后回答："'动态'更准确，因为树懒的动作是在变化的。"

4. **教师**：总结："对，'动态'就是以运动、变化、发展的视角来观察、分析、表现事物。这就是动态思维的定义。"
   **学生**：理解动态思维的定义。

**学习成果及评价标准**：
- 学习成果：学生能够理解动态思维的定义，能够举例说明动态思维的应用
- 评价标准：学生能够准确说出动态思维的定义，能够举出1-2个动态思维的应用例子

**备注**：
- 教学反思：学生对动态思维概念的理解还需要更多实例支撑
- 学情信息：大部分学生能够理解动态思维的基本概念，但部分学生对"变化、发展"的理解还不够深入

### 步骤13：输出最终方案

**输出格式固定为JSON格式，符合以下JSON Schema定义：**

**注意**：根据课程类型，学习目标部分会有所不同：
- **第一类课程**（应用型研究方向项目化教学课程/专业基础课程/公共基础课程）：学习目标包含两部分——知识点（学习水平）、素质目标（课程思政点）
- **第二类课程**（就业方向项目化教学课程）：学习目标包含三部分——知识点（学习水平）、能力目标、素质目标（课程思政点）

1. **标题**：课程标题
2. **课程设计名称**：课程设计名称

**课程设计数组结构说明：**
- 每个元素包含"key"和"value"两个字段
- "key"字段标识区块名称（如"学习目标"、"学习先决知识"、"知识建模图"等）

## 质量检查标准

**基本格式检查**：
- 知识点名称、类型和知识点形状完整
- 核心知识点、核心的结构化知识框架、先决知识点分别用红色、蓝色、绿色标识清楚
- 关系箭头完整
- 关系名称不能遗漏且不能自创
- 不用太纠结关系名称的对错
- 不能将知识建模图和思维导图相混淆

**内容检查**：
- 知识点涵盖陈述性知识、程序性知识、事实范例、认知策略
- 认知策略需要教师提炼
- 知识点分解细化到已知的先决知识技能
- 原则上禁止出现孤立节点
- 从同一个知识点引出的"内容包含""步骤包含"等关系中原则上至少包含2个子内容

**边界条件和异常处理**：

### 边界条件
- 输出长度异常（过短或过长）
- 重复内容过多
- 包含敏感词（针对政治类课程）
- 公式格式异常（针对理工类课程）

### 异常处理策略
- 轻微异常：提示用户确认，允许用户选择接受或重新生成
- 严重异常：自动触发重新生成，最多重试3次
- 持续异常：记录异常日志，提示用户联系技术支持

## 注意事项

**知识建模图注意事项：**
- 知识点挖掘全面，必须涵盖与后续项目化教学课程紧密关联的知识组块
- 陈述性知识点后尽可能列出相关范例知识点
- 核心知识点标红🔴，结构化知识框架标蓝🔵，先决知识点标绿🟢
- 使用树状结构或思维导图形式展示知识点之间的逻辑关系
- 原则上禁止出现孤立节点
- 从同一个知识点引出的"内容包含""步骤包含"等关系中原则上至少包含2个子内容

**知识点（学习水平）注意事项：**
- 学习水平有记忆、理解、运用三种类型
- 每个知识点匹配最高层次学习水平
- 按照标准格式撰写："知识点（学习水平）"

**素质目标（课程思政点）注意事项：**
- 需要老师挖掘本次课对应的课程思政点
- 需要在上课中有对应的知识点
- 思政点（隐性知识）要体现在知识建模图中
- 用*号标注课程思政点

**学习先决知识注意事项：**
- 知识建模图中所有先决知识点要全部罗列
- 按照"知识点（学习水平）"的方式撰写
- 先决知识点要与本次课的专业知识点有紧密相关关系

**课上/课下资源注意事项：**
- 分类汇总本次课所有课上/课下活动的学习资源
- 资源分类清晰（视频/短片资源、教具、教学课件、素材库、参考书、网络资源等）
- 资源具体明确，有明确的名称和来源

**课上/课下时间注意事项：**
- 课上时间与后面课上活动设计的总时长保持一致
- 课下时间与后面课下活动设计的总时长保持一致
- 使用"分钟"作为时间单位

**活动序列注意事项：**
- 活动序列要涵盖所有知识点
- 活动目标要明确，按"知识点（学习水平）"的方式撰写
- 活动时间要合理，与总时间保持一致
- 学习资源要分类列出，具体明确
- 课下任务也需要设计师生交互过程描述
- 课下任务的师生交互过程主要描述任务布置时的师生互动
- 课下任务的教学策略应包括自主学习法以及1-2种其他适合课下任务的教学策略

**师生交互过程注意事项：**
- 采用时间线式描述，按照实际教学过程的先后顺序
- 每一轮互动都包含教师的引导行为和学生的回应行为
- 每个任务（包括课下任务）都需要设计师生交互过程
- 课下任务的师生交互过程主要描述任务布置时的互动，包括任务要求说明、资源提供、疑问解答等
- 课下任务的师生交互过程描述以学生行为为主
- 课下任务的教师行为主要作为任务部署或下发的简要描述
- 课下任务的学生行为应针对教师下达的课下任务进行具体行为的描述
- 师生交互过程要标注教学策略使用方式
- 师生交互过程与任务描述中的教学策略保持一致

**活动序列注意事项：**
- 活动目标体现裁剪活动的最高阶知识点目标
- 按"知识点（学习水平）"的方式撰写
- 地点明确（课上/课下）
- 时间明确（XX分钟）
- 学习资源分类列出
- 课下任务的教学策略应包括自主学习法以及1-2种其他适合课下任务的教学策略

**活动知识建模图注意事项：**
- 每一项活动的知识建模图与下面的活动任务序列相匹配
- 活动知识建模图的切分合理
- 活动知识建模图使用🔴🔵🟢标注

**学科类型适配注意事项：**
- 政治类课程：注意敏感词处理，确保内容符合教育政策要求
- 理工类课程：公式统一使用LaTeX格式，特殊符号使用Unicode字符集
- 文史类课程：确保文本格式正确，支持富文本编辑
- 艺术类课程：支持多种图像格式，确保图像能够正常上传、存储和显示
