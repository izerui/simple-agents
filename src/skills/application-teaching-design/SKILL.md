# 基于已有知识建模图的教学设计生成

## 任务目标

本 Skill 用于基于已有的知识建模图生成符合应用型本科教学设计规范的完整教学设计方案,帮助教师:
- 将给定的知识建模图合理剪切成不同的活动
- 制定符合学习水平要求的知识点清单(记忆、理解、运用)
- 挖掘课程思政点并体现在设计中
- 明确学习先决知识
- 分类汇总课上/课下资源和时间
- 设计完整的活动序列(活动1-N)
- 为每个活动构建活动知识建模图(基于给定知识建模图的裁剪)
- 制定每个活动的活动目标
- 设计详细的活动任务序列(导入任务、任务一/二/三...)
- 规范师生交互过程(教师行为、学生行为)
- 明确学习资源和评价标准
- 记录教学备注和反思

适用场景:应用型本科专业教师已有知识建模图,需要基于该知识建模图生成完整教学设计时。

## 前置准备

在使用本技能前,需要提供以下信息,用户未输入必填信息时,提示用户输入:

**必填信息:**
- **知识建模图(JSON格式)**:已设计好的知识建模图,包含核心知识点、结构化知识框架、先决知识点、课程思政点等完整信息
- 课程名称:如"动态思维基础"
- 教案名称:如"动态思维的觉醒"
- 学时安排:如"4学时"(需明确课上课下分配,如课上200分钟+课下400分钟)
- 课程类型:应用型研究方向项目化教学课程/专业基础课程/公共基础课程/就业方向项目化教学课程
- 教学形式:讲授形式/翻转课堂
- 适用专业:如"本科动画专业"
- 学生层次:如"大一学生"
- 任务内容:详细描述本课的教学内容和要求

**选填信息:**
- 评价重点:需要特别关注的学习成果(如"动态思维理解"、"动态速写能力"、"人机协同创作"等)
- 课程思政点:需要融入的思政元素(如"工匠精神"、"文化自信"、"创新意识"等)
- 教学资源:已有的教学资源(如视频、案例、课件等)

**说明:**
- 知识建模图必须是JSON格式,包含完整的知识点结构和标注信息
- 教学形式将决定师生交互过程的设计方式
- 学时安排需要明确课上课下的时间分配,与活动序列保持一致
- 适用专业将自动判断学科类型(政治类、理工类、文史类、艺术类),并据此调整输出要求

## 学科类型适配

### 适用专业与学科类型映射

根据适用专业自动判断学科类型(政治类、理工类、文史类、艺术类):

| 适用专业 | 学科类型 |
|---------|---------|
| 本科计算机科学与技术专业 | 理工类 |
| 本科汉语言文学专业 | 文史类 |
| 本科马克思主义理论专业 | 政治类 |

### 各学科类型适配要求

**政治类课程**:输出内容符合国家教育政策要求,避免涉及敏感话题和敏感词汇,内容积极向上,符合社会主义核心价值观。

**理工类课程**:公式统一使用LaTeX格式表示,特殊符号使用Unicode字符集,公式和特殊符号能够正常复制、保存和回显。

**文史类课程**:严格按照应用型本科教学设计规范输出。

**艺术类课程**:支持多种图像格式(JPG、PNG、GIF、SVG等),图像能够正常上传、存储和显示。

## 操作步骤

**重要说明**:
1. 本技能基于已有的知识建模图生成教学设计,不重新生成知识建模图
2. 所有要素的设计都要严格基于给定的知识建模图
3. 活动知识建模图是总知识建模图的合理裁剪,不能超出或遗漏
4. 活动序列要覆盖知识建模图中的所有核心知识点
5. 确保所有要素之间的对应关系和一致性

### 步骤0:解析知识建模图JSON格式

#### JSON结构说明

知识建模图JSON包含以下主要字段:
```json
{
  "rootId": "节点ID",
  "datetime": 时间戳,
  "nodes": [节点数组],
  "lines": [连线数组]
}
```

#### 节点(nodes)字段解析

每个节点包含以下关键属性:

| 属性 | 说明 | 示例 |
|------|------|------|
| id | 节点唯一标识 | "node-1", "253" |
| text | 节点文本内容 | "动态思维" |
| borderColor | 边框颜色 | "#FF4D4F"(红), "#1890FF"(蓝), "#52C41A"(绿), "#000000"(黑) |
| fontColor | 字体颜色 | 与边框颜色一致 |
| nodeShape | 节点形状 | 0(圆形), 1(矩形) |
| borderWidth | 边框粗细 | 0(无边框), 1(细边框), 2(粗边框) |
| width | 节点宽度 | 自动计算或手动指定 |
| height | 节点高度 | 自动计算或手动指定 |
| x | x坐标 | 画布横坐标 |
| y | y坐标 | 画布纵坐标 |
| data.type | 知识类型 | 2(陈述性), 3(程序性), 5(认知策略), 6(事实范例) |
| data.backgroundImage | 背景图片 | 可选,用于图片资源 |
| data.startPostion | 起始位置 | {"x": 数值, "y": 数值} |

#### 颜色标注与知识点类型映射

通过 `borderColor` 和 `fontColor` 识别知识点类型:

| 颜色 | 十六进制值 | 知识点类型 | 说明 |
|------|-----------|-----------|------|
| 红色 | #FF4D4F | 核心知识点 | 课程的核心概念和原理 |
| 蓝色 | #1890FF | 结构化知识框架 | 知识的结构化框架,如步骤、流程 |
| 绿色 | #52C41A | 先决知识点 | 学习本课内容必须具备的基础知识 |
| 黑色 | #000000 | 普通知识点 | 其他知识点 |

#### 知识类型(data.type)映射

| data.type | 类型 | 说明 |
|----------|------|------|
| 2 | 陈述性知识 | 是什么?为什么?概念、原理 |
| 3 | 程序性知识 | 怎么做?操作步骤、流程 |
| 5 | 认知策略 | 如何学得好?学习方法 |
| 6 | 事实范例 | 案例、例子、资源 |
| 9 | 思政点 | 课程思政点 |

#### 连线(lines)字段解析

每条连线包含以下关键属性:

| 属性 | 说明 | 示例 |
|------|------|------|
| id | 连线唯一标识 | "line-1" |
| from | 源节点id | "node-1" |
| to | 目标节点id | "node-2" |
| text | 关系名称 | "包含", "支持", "是前提" |
| data.type | 关系类型 | 可选,如9表示思政点关系 |
| fromJunctionPoint | 起点连接位置 | "border"(默认), "left", "right", "top", "bottom" |
| toJunctionPoint | 终点连接位置 | "border"(默认), "left", "right", "top", "bottom" |
| lineShape | 线条样式 | 1(直线), 2(样式2), 3(样式3), 4(折线), 5(样式5), 6(样式6) |
| dashType | 虚线类型 | 0(实线), 1(虚线) |

#### 连接点优先级规则

根据目标节点相对于起始节点的位置,结合节点宽高自动计算最佳连接点。

**判断逻辑**:
```
B在A右侧:B.x > A.x + A.width/2
B在A左侧:B.x + B.width < A.x
B在A下方:B.y > A.y + A.height/2
B在A上方:B.y + B.height < A.y
```

**连接点选择规则**:

| 目标节点位置 | toJunctionPoint(终点) | fromJunctionPoint(起点) |
|:-------------|:----------------------|:------------------------|
| 右上(B在A右上方) | bottom | right |
| 右下(B在A右下方) | top | right |
| 左上(B在A左上方) | bottom | left |
| 左下(B在A左下方) | top | left |
| 正右(B在A正右侧) | left | right |
| 正左(B在A正左侧) | right | left |
| 正上(B在A正上方) | bottom | top |
| 正下(B在A正下方) | top | bottom |
| 其他情况 | border | border |

**说明**:根据B相对于A的位置,选择能让连线最短的连接点组合。连接点选择原则:fromJunctionPoint选择离目标节点近的边,toJunctionPoint选择离起始节点近的边。无法用简单规则判断时,默认使用 border 自动计算最近边框。

#### 常见关系类型

| 关系名称 | 说明 |
|----------|------|
| 包含 | 总分关系,父节点包含子节点 |
| 支持 | 提供支撑和辅助 |
| 是前提 | 必要性关系 |
| 具有特征 | 描述属性特征 |
| 具有属性 | 描述属性 |
| 定义 | 定义关系 |
| 组成/构成 | 分总关系 |
| 是一种 | 上下位关系 |

### 步骤1:解析给定的知识建模图

**知识建模图解析要求**:
1. **读取JSON格式知识建模图**:完整解析给定的知识建模图JSON数据
2. **识别核心知识点**:提取所有 `borderColor="#FF4D4F"` 的节点
3. **识别结构化知识框架**:提取所有 `borderColor="#1890FF"` 的节点
4. **识别先决知识点**:提取所有 `borderColor="#52C41A"` 的节点
5. **识别普通知识点**:提取所有 `borderColor="#000000"` 的节点
6. **识别知识类型**:根据 `data.type` 区分陈述性知识(2)、程序性知识(3)、认知策略(5)、事实范例(6)
7. **识别课程思政点**:提取 `data.type=9` 的节点或通过特殊关系标识的思政点
8. **识别知识点关系**:通过 `lines` 数组理解知识点之间的逻辑关系(包含、支持、是前提、具有特征等)

**解析流程**:
1. 遍历 `nodes` 数组,按颜色分类所有节点
2. 遍历 `lines` 数组,构建知识点之间的逻辑关系图
3. 识别根节点(通过 `rootId` 或无入边的节点)
4. 构建知识树结构,明确层级关系
5. 提取所有事实范例节点(data.type=6),作为学习资源
6. 识别课程思政点,为素质目标设计做准备

**设计要点**:
- 确保完整理解知识建模图的结构和内容
- 明确哪些知识点是核心的、哪些是结构化的、哪些是先决的
- 理解知识点之间的逻辑关系
- 识别所有可用的学习资源(事实范例)
- 为后续活动切分做好准备

### 步骤2:制定学习目标

**课程类型差异说明**:
- **第一类课程**(应用型研究方向项目化教学课程/专业基础课程/公共基础课程):学习目标包含两部分——知识点(学习水平)、素质目标(课程思政点)
- **第二类课程**(就业方向项目化教学课程):学习目标包含三部分——知识点(学习水平)、能力目标、素质目标(课程思政点)

#### 2.1 知识点(学习水平)

**知识点(学习水平)要求**:
1. **基于知识建模图**:所有知识点都必须来自给定的知识建模图
2. **学习水平类型**:学习水平有记忆、理解、运用三种类型(每个知识点匹配最高层次学习水平)
3. **体现知识建模图**:总活动目标与裁剪活动的最高阶知识点目标,并且一定要体现在知识建模图中
4. **按标准格式撰写**:按照"知识点(学习水平)"的方式撰写

**学习水平定义**:
- **记忆**:能够回忆和识别基本事实、概念、原理等
- **理解**:能够解释和说明概念、原理的含义和内在逻辑
- **运用**:能够在具体情境中应用概念、原理解决问题

**知识点清单示例**:
1. 动态思维的觉醒(理解)
2. 动态思维(理解)
3. 动态视觉元素的审美规律和表现原理(理解)
8. 动态观察方法(运用)

**设计要点**:
- 知识点要全面,涵盖知识建模图中的所有核心知识点
- 每个知识点都要标注学习水平(记忆/理解/运用)
- 知识点的表述要清晰、具体、可测
- 确保知识点与知识建模图保持一致

#### 2.2 能力目标(仅就业方向项目化教学课程需要)

**能力目标填写注意事项**:
1. **对应程序性知识点**:对应程序性知识点的运用学习水平、知识组块的运用水平、××项目工作任务/子任务/任务模块,聚焦学生能够完成任务所具备的能力
2. **来源于运用相应知识点**:能力目标来源于运用相应知识点,需要在知识建模图中体现出来

**能力目标示例**:
1. 能够独立完成××工程测量任务
2. 能够制定××任务实施方案
3. 能够运用××材料选配方法完成材料选择
4. 能够执行××任务实施流程

**设计要点**:
- 能力目标要具体、可测、可评价
- 能力目标要与程序性知识点对应
- 能力目标要在知识建模图中体现
- 能力目标要与项目工作任务对应

#### 2.3 素质目标(课程思政点)

**素质目标(课程思政点)要求**:
1. **基于知识建模图**:从给定的知识建模图中提取课程思政点
2. **与知识点对应**:需要在上课中有对应的知识点
3. **特有素质**:一些本次课涉及到的特有素质,比如专业知识点相关爱国主义故事
4. **体现在知识建模图中**:思政点(隐性知识)要体现在知识建模图中
5. **用*号标注**:在素质目标后用*号标注课程思政点
6. **可填"/"**:没有可填"/"

**素质目标示例**:
1. 具备'发展变化'的辩证唯物主义世界观*
2. 具备'扎根生活、严谨治学'的工匠精神*
3. 具备'传承中华美学'的文化自信*

**设计要点**:
- 素质目标要与课程内容紧密结合,自然融入
- 素质目标要具体、可测、可评价
- 素质目标要在知识建模图中体现
- 素质目标要在师生交互过程中有对应的环节

### 步骤3:明确学习先决知识

**学习先决知识要求**:
1. **基于知识建模图**:从给定的知识建模图中提取所有先决知识点(`borderColor="#52C41A"`)
2. **罗列所有先决知识点**:知识建模图中所有先决知识点要全部罗列
3. **按照标准格式撰写**:按照"知识点(学习水平)"的方式撰写
4. **与专业知识点紧密相关**:先决知识点要与本次课的专业知识点有紧密相关关系
5. **在知识建模图中体现**:先决知识点在JSON中通过 `borderColor="#52C41A"` 标注

**学习先决知识示例**:
1. 平面构成的形式美法则与构成方法(运用)
2. 把握'形'需要注意的事项(理解)

**设计要点**:
- 先决知识是学生学习本次课内容必须具备的基础知识
- 先决知识要与本次课的专业知识点有直接关联
- 先决知识在JSON中通过 `borderColor="#52C41A"` 标注
- 先决知识要在导入任务中唤起学生的记忆

### 步骤4:分类汇总课上资源与课下资源

**课上资源与课下资源要求**:
1. **课上资源**:分类汇总本次课所有课上活动的学习资源
2. **课下资源**:分类汇总本次课所有课下活动的学习资源
3. **资源分类清晰**:按照资源类型分类(视频/短片资源、教具、教学课件、素材库、参考书、网络资源等)
4. **资源具体明确**:每个资源都要有明确的名称和来源
5. **与知识点匹配**:资源要与知识建模图中的知识点相对应

**课上资源示例**:
### 1. 视频/短片资源
- 《蜘蛛侠:纵横宇宙》动作片段
- 皮克斯《跳跳灯》

### 2. 教具
- 动态思维特征分析表
- AI工具
- 速写纸

### 3. 教学课件
- 动态思维基础PPT
- 动态视觉元素的审美规律和表现原理PPT

### 4. 素材库
- 静态图片A
- 动态模糊图片B

**课下资源示例**:
### 1. 视频
- 人起立动作视频
- 扔球动作视频

### 2. 参考书
- [英]威廉姆斯著;邓晓娥译.原动画基础教程[M].中国青年出版社,2006.01

### 3. 网络资源
- B站:'极客湾 Geekerwan''动画人'
- YouTube:'Toniko Pantoja''BA Animation'

### 4. 素材库
- 速写班长

**设计要点**:
- 资源分类要清晰,便于查找和使用
- 资源要具体,有明确的名称和来源
- 资源要与教学活动相匹配
- 资源要标注使用环节(课上/课下)

### 步骤5:明确课上时间与课下时间

**课上时间与课下时间要求**:
1. **课上时间**:与后面课上活动设计的总时长保持一致
2. **课下时间**:与后面课下活动设计的总时长保持一致
3. **时间分配合理**:根据学生身心发展特点与理解水平合理分配时间
4. **时间单位明确**:使用"分钟"作为时间单位

**时间分配示例**:
- 课上时间:200分钟
- 课下时间:400分钟

**设计要点**:
- 课上课下时间要与活动序列保持一致
- 时间分配要考虑学生的认知负荷
- 时间分配要确保完成学习任务

### 步骤6:设计活动序列

**活动序列要求**:
1. **基于知识建模图裁剪**:活动序列是基于给定的知识建模图合理裁剪的结果
2. **活动目标**:体现裁剪活动的最高阶知识点目标,按"知识点(学习水平)"的方式撰写
3. **地点**:课上/课下
4. **时间**:XX分钟
5. **学习资源**:按照本次活动所有课上/课下任务的资源分类列出
6. **覆盖所有知识点**:活动序列要覆盖知识建模图中的所有核心知识点
7. **切分合理**:活动切分遵循相对独立、结构化、易被学生消化理解的原则

**活动序列表格示例**:

## 质量检查标准

**基本格式检查**:
- 知识点名称、类型和知识点形状完整
- 核心知识点、核心的结构化知识框架、先决知识点分别用红色(#FF4D4F)、蓝色(#1890FF)、绿色(#52C41A)标识清楚
- 关系箭头完整
- 关系名称不能遗漏且不能自创
- 不用太纠结关系名称的对错
- 不能将知识建模图和思维导图相混淆

**内容检查**:
- 知识点涵盖陈述性知识、程序性知识、事实范例、认知策略
- 知识点分解细化到已知的先决知识技能
- 原则上禁止出现孤立节点
- 从同一个知识点引出的"内容包含""步骤包含"等关系中原则上至少包含2个子内容

**边界条件和异常处理**:

### 边界条件
- 输出长度异常(过短或过长)
- 重复内容过多
- 包含敏感词(针对政治类课程)
- 公式格式异常(针对理工类课程)

### 异常处理策略
- 轻微异常:提示用户确认,允许用户选择接受或重新生成
- 严重异常:自动触发重新生成,最多重试3次
- 持续异常:记录异常日志,提示用户联系技术支持
