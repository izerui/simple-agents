# 课程设计最终 JSON 生成

## 任务目标

你的目标不是解释思路，而是直接产出最终 JSON。

默认要求：
- 严格符合 `references/schema.json`
- 面向解析、校验、前端回填和导入接口映射
- 不输出旧版 `课程设计[] + 根层活动序列对象` 结构
- 不输出把结构信息塞进字符串的写法

## 必填信息

缺失时先追问：
- 课程名称
- 课程设计名称 / 周次课次
- 学时安排（课上 / 课下）
- 课程类型
- 教学形式
- 适用专业
- 学生层次
- 任务内容

## 选填信息

有就吸收，没有也继续生成：
- 知识建模图 JSON / 图示
- 教材、课件、案例、作业模板、题库
- 课程思政点
- 评价重点
- 资源链接或附件信息

## 输出结构

最终 JSON 顶层固定为：

```json
{
  "标题": "",
  "课程设计名称": "",
  "课程信息": {},
  "学习目标": {},
  "学习先决知识": [],
  "知识建模图": {},
  "课上资源": [],
  "课下资源": [],
  "活动序列": []
}
```

## 核心建模规则

### 1. 活动必须是数组
- `活动序列` 是数组
- 每个活动必须有 `活动id`、`排序`、`活动名称`
- 不再使用 `活动1` / `活动2` 作为对象 key

### 2. 活动目标必须是数组
- `活动目标` 是数组
- 每项都是 `{ 名称, 学习水平, 说明 }`
- 学习水平只能是 `记忆`、`理解`、`运用`

### 3. 资源必须是对象数组
- `课上资源`、`课下资源`、活动资源、任务资源都用对象数组
- 每项至少包含：
  - `资源分类`
  - `资源描述`
- 可选补充：
  - `资源名称`
  - `链接`
  - `定位`
- 不要再输出交替行字符串、逗号列表或分号列表

### 4. 富文本字段用内容块数组
- `师生交互过程`
- `学习成果`
- `评价标准`

以上字段都使用数组，元素为：

```json
{ "类型": "文本", "内容": "..." }
```

或：

```json
{ "类型": "图片", "地址": "..." }
```

### 5. 建模图字段要保留结构化引用
- 顶层、活动级、任务级都可有 `知识建模图`
- 结构固定为：

```json
{
  "系统建模编码": "",
  "文本": "",
  "图片列表": []
}
```

其中：
- `系统建模编码` 用于对接前端已有建模选择能力
- `文本` 用于 LLM 直接生成的知识结构表达
- `图片列表` 用于承接上传图片或外部图片

### 6. 任务结构必须完整

每个任务必须包含：
- `任务id`
- `排序`
- `任务名称`
- `知识建模图`
- `知识组块`
- `任务描述`
- `任务时长分钟`
- `学习地点`
- `教学方式`
- `师生交互过程`
- `学习成果`
- `评价标准`
- `学习资源`
- `上传资源`
- `备注`

### 7. 教学方式结构

固定结构：

```json
{
  "方式": ["讲授", "小组讨论"],
  "其他": ""
}
```

`方式` 可选值仅限：
- `讲授`
- `小组讨论`
- `答疑`
- `实验`
- `实训`
- `自主学习`
- `翻转课堂`
- `案例分析`
- `项目实践`
- `其他`

### 8. 时间统一用整数分钟
- 使用 `课上分钟`、`课下分钟`、`任务时长分钟`
- 不要写成 `"15分钟"`

## 前端适配约束

这套 JSON 需要能顺滑映射到前端当前导入/保存逻辑，因此生成时必须满足：

- 顶层 `课上资源`、`课下资源` 可直接映射为课程资源明细
- 活动级 `课上资源`、`课下资源` 可直接映射为活动序列表汇总资源
- `活动目标` 可直接映射为前端 `pointList / pointSummaryList`
- `教学方式.方式` 使用中文标签，前端再做字典映射
- `学习成果` 与 `评价标准` 分开，不要合并成一个字段
- `上传资源` 单独存，不要混进 `学习资源`
- `导入任务描述` 与 `师生交互过程` 分开

## 业务约束

- `活动排序` 必须与数组顺序一致，从 1 开始连续递增
- `任务排序` 必须与数组顺序一致，从 1 开始连续递增
- 同一文件内 `活动id` 不得重复
- 同一文件内 `任务id` 不得重复
- 每个活动的 `时间分配` 必须等于其下任务按 `学习地点` 汇总后的分钟数
- `课程信息.学时安排` 必须等于所有活动的时间分配汇总
- 若 `学习地点` 为 `课上`，`教学方式.方式` 不能包含 `自主学习`
- 若 `学习地点` 为 `课下`，`教学方式.方式` 不能包含 `讲授`
- 若 `课程类型` 包含 `项目化`，通常必须提供非空 `能力目标`

## 生成建议

- `活动名称` 使用真实语义名称，不用“活动1/活动2”
- `任务名称` 使用语义化名称，不用“任务一/任务二”占位
- `知识组块` 用字符串数组表达知识点或知识模块
- `导入任务描述` 聚焦引入情境，不要和 `师生交互过程` 混写
- `资源描述` 要写清楚资源用途，不要只写资源名

## 校验方式

- `python3 src/skills/application-teaching-design/scripts/validate_json.py path/to/result.json`

## 最终输出方式

- 只输出 JSON
- 不附加 Markdown 解释
- 不输出旧结构兼容版
