# 应用型本科教学设计规范

## 核心要素

应用型本科教学设计规范包含10个核心要素，每个要素都有详细的填写要求和注意事项。

---

## 核心要素1：知识建模图

### 填写注意事项

1. **知识点挖掘全面**：必须涵盖与后续项目化教学课程紧密关联的知识组块
2. **陈述性知识点后列出范例**：尤其是一些理论性强、难以理解的陈述性知识点后，必须有范例知识点
3. **核心知识点标红**：是"核心知识点"，要在知识建模图中标红（图形边线和字体均标红）
4. **结构化知识框架标蓝**：是"核心的结构化知识框架"的，以"知识点-知识点-知识点-知识点…"表示，也要体现在知识建模图中，并且标蓝（图形边线和字体均标蓝）
5. **先决知识点标绿**：先决知识点要与本次课的专业知识点有紧密相关的关系，要体现在知识建模图中，并且标绿（图形边线和字体均标绿）

### 知识建模图结构示例

```
🔴 核心概念：XXX
│
├── 🔴 子概念1
├── 🔴 子概念2
├── 🔴 子概念3
│
├── 🔵 结构化知识框架（步骤包含1/2/3...）
│   ├── 步骤包含1：XXX
│   ├── 步骤包含2：XXX
│   └── 步骤包含3：XXX
│
├── 🟢 先决知识点
│   └── 是前提 → 核心概念
│
├── 支持案例与资源
│   ├── 案例1 → 支持 → 子概念1
│   ├── 案例2 → 支持 → 子概念2
│   └── 资源1 → 支持 → 子概念3
│
└── 课程思政点（隐性知识）
    ├── 思政点1 → 支持 → 相关概念
    └── 思政点2 → 支持 → 相关概念
```

### 关系类型说明

- **支持**：表示一个知识点对另一个知识点的支撑作用
- **具有特征**：表示知识点具有的属性或特征
- **内容包含**：表示知识点包含的内容或要素
- **步骤包含**：表示流程或步骤的包含关系
- **是前提**：表示先决知识点是后续知识点的基础
- **关键点包含**：表示关键点的包含关系

## 核心要素2：知识点（学习水平）

### 填写注意事项

1. **学习水平类型**：学习水平有记忆、理解、运用三种类型
2. **匹配最高层次**：每个知识点匹配最高层次学习水平
3. **体现知识建模图**：总活动目标与裁剪活动的最高阶知识点目标，并且一定要体现在知识建模图中

### 学习水平定义

- **记忆**：能够回忆和识别基本事实、概念、原理等
- **理解**：能够解释和说明概念、原理的含义和内在逻辑
- **运用**：能够在具体情境中应用概念、原理解决问题

### 格式要求

按照"知识点（学习水平）"的方式撰写。

### 示例

1. 动态思维的觉醒（理解）
2. 动态思维（理解）
3. 动态视觉元素的审美规律和表现原理（理解）
4. 节奏（理解）
5. 韵律（理解）
6. 平衡（理解）
7. 对比（理解）
8. 动态观察方法（运用）
9. 从看形状转向看姿态/轨迹/力（理解）
10. 轨迹线（运用）

## 核心要素3：素质目标（课程思政点）

### 填写注意事项

1. **挖掘课程思政点**：需要老师挖掘本次课对应的课程思政点
2. **与知识点对应**：需要在上课中有对应的知识点
3. **特有素质**：一些本次课涉及到的特有素质，比如专业知识点相关爱国主义故事
4. **可填"/"**：没有可填"/"
5. **体现在知识建模图中**：思政点（隐性知识）要体现在知识建模图中

### 示例

1. 具备'发展变化'的辩证唯物主义世界观*
2. 具备'扎根生活、严谨治学'的工匠精神*
3. 具备'传承中华美学'的文化自信*
4. 具备'人机协同、驾驭技术'的创新意识与主体责任感*

**说明**：用*号标注课程思政点

## 核心要素8：活动知识建模图

### 填写注意事项

1. **与活动任务序列匹配**：每一项活动的知识建模图与下面的活动任务序列相匹配，不能画多或者画少
2. **切分合理**：一个活动应能相对完整地达成学习目标，活动知识建模图的切分遵循相对独立、结构化、易被学生消化理解的原则
3. **时长合理**：活动的时长应符合学生身心发展特点与理解水平

### 示例

```
🔴 核心概念：动态思维（红色框突出）
│
├── 🔴 定义
│   └── 以运动、变化、发展视角观察/分析/表现事物
│
├── 支持内容
│   ├── 《疯狂动物城》树懒"闪电"片段 → 支持 → 动态思维
│   ├── "定格挑战"与"过程还原"
│   │   ├── 具有特征：根据起止帧猜测并绘制中间关键状态
│   │   └── 支持 → AI时代：人类定义逻辑与创意的基石
│   │       └── 支持 → 发展变化
│   └── 区别动画与静态艺术的核心
│       ├── 关键点包含1：动画创作的灵魂
│       └── 关键点包含2：以运动、变化、发展视角观察/分析/表现事物
│
└── 🔴 三个核心特征
    ├── 具有特征1：时空性
    ├── 具有特征2：流程性
    └── 具有特征3：预测性
```

## 核心要素10：活动任务序列

### 填写注意事项

#### 导入任务

1. **围绕先决知识点**：教师需要设计相应师生交互过程，创设情境，选用合理有效的教学策略，重点是要唤起和帮助学生回忆起先决知识的教学策略
2. **展开典型语言和行为**：要展开师生互动的典型语言和行为，其中老师引导学生进行思维或思考的恰当的"引导语"是关键点
3. **不能时间太长**：主要目的是唤起学生对和本次课最直接相关的已有的先决知识的记忆，好让学生更好地理解本次课
4. **引出本次课程的内容**：唤醒先决知识，引出本次课程的内容（第一个活动导入必须写，活动之间有就写，没有可填"/"）

#### 任务一/二/三...

1. **任务描述**：因为何种思考或原因，采用××教学策略，达到××的学习结果
2. **任务时长**：根据教学经验，判断和预估课上和课下的用时；确保完成学习任务的基础上，尽量用最短时长
3. **学习地点**：一个任务只对应一种学习地点，不能既有课上又有课下
4. **教学方式（或学习方式）**：教学方式恰当，每次课上有充分的师生互动时间与空间；教学方式与教学策略逻辑一致
5. **师生交互过程**：
   - 老师要采取合适的教学策略，例如举例示范、难点答疑、学生设计互评等，是任务栏的核心内容
   - 师生互动过程要体现出教学策略的关键点
   - 要设计关键的引导语，语言设计清晰明确、具有操作性，目的是让学生能够知道怎么做
   - 写清楚教学过程的一个标志，就是能够让同专业老师直接可以上课，非同行老师看明白是如何使用的教学策略
   - 老师不能太多采取简单问答的方式进行教学，这种简单的教学互动，只是引起听课学生的注意力，学生的学习困惑仍然会是困惑
   - 互动过程，要尝试设计有质量的嵌套问题，引起学生的分解、比较、分类、演绎或归纳的思考
6. **学习资源**：学习资源标注清晰、具体，例如该学习任务对应到教材的哪几页、具体的音频或视频资源等，应匹配学习目标；学习资源最好进行归类
7. **学习成果及评价标准**：
   - 项目学习成果一定要设计，并且清晰、具体，写明学生的学习收获和具体表现
   - 学习成果与知识目标、能力目标相对应
   - 成果工作量合理，难度适中
   - 学习成果评价标准（或行为评价量表）清晰、具体、客观，针对性、操作性强
   - 允许学生改善并重新提交学习成果
   - 学习成果评价标准必须提前告知学生
   - 尽可能所有学生都要参与评价
   - 相应知识组块、师生交互过程、学习成果与评价标准必须保持一致
8. **备注**：上课结束以后对于该活动（任务）的教学心得、体会或反思等；补充课上收集到的学生学情信息，例如：学生的常见的学习问题；需要特别关注的学生特征；学生学习的好方法；学生对本次课程的反馈与建议

## 教学策略

### 帮助理解的有效策略

1. **图表策略**：使用思维导图、结构化图表、可视化图表等
2. **视频策略**：使用优秀动画案例视频、自然现象视频、文化视频、示范视频等
3. **案例策略**：使用动画案例分析、自然现象案例、文化案例等
4. **举例策略**：使用生活举例、专业举例等
5. **例题演示策略**：演示如何分析、如何计算等
6. **类比策略**：使用类比方法降低理解难度
7. **故事引申策略**：通过故事引申意义
8. **结构化理解策略**：使用知识建模图、流程图等
9. **关联理解策略**：关联先决知识、生活经验等

### 帮助记忆的有效策略

1. **自编顺口溜**：编写朗朗上口的顺口溜
2. **生活常识关联**：将知识点与生活常识关联

### 帮助运用的有效策略

1. **操作手册**：提供具体的操作步骤
2. **教师示范**：教师示范具体操作
3. **一对一指导**：针对学生常见问题进行个别辅导
