# 知识建模图模板

## 基本结构

```
🔴 核心概念：XXX
│
├── 🔴 子概念1
│   ├── 具有特征1：XXX
│   ├── 具有特征2：XXX
│   └── 具有特征3：XXX
│
├── 🔴 子概念2
│   ├── 内容包含1：XXX
│   ├── 内容包含2：XXX
│   └── 内容包含3：XXX
│
├── 🔵 结构化知识框架（步骤包含1/2/3...）
│   ├── 步骤包含1：XXX
│   ├── 步骤包含2：XXX
│   └── 步骤包含3：XXX
│
├── 🟢 先决知识点
│   └── 是前提 → 核心概念
│
├── 支持案例与资源
│   ├── 案例1 → 支持 → 子概念1
│   ├── 案例2 → 支持 → 子概念2
│   ├── 资源1 → 支持 → 子概念3
│   └── 资源2 → 支持 → 结构化知识框架
│
└── 课程思政点（隐性知识）
    ├── 思政点1 → 支持 → 相关概念
    ├── 思政点2 → 支持 → 相关概念
    └── 思政点3 → 支持 → 相关概念
```

---

## 颜色标注说明

- 🔴 **红色**：核心知识点（图形边线和字体均标红）
- 🔵 **蓝色**：核心的结构化知识框架（图形边线和字体均标蓝）
- 🟢 **绿色**：先决知识点（图形边线和字体均标绿）

---

## 关系类型说明

| 关系类型 | 说明 | 示例 |
|----------|------|------|
| 支持 | 表示一个知识点对另一个知识点的支撑作用 | 案例1 → 支持 → 子概念1 |
| 具有特征 | 表示知识点具有的属性或特征 | 子概念1 → 具有特征1：XXX |
| 内容包含 | 表示知识点包含的内容或要素 | 子概念2 → 内容包含1：XXX |
| 步骤包含 | 表示流程或步骤的包含关系 | 结构化知识框架 → 步骤包含1：XXX |
| 是前提 | 表示先决知识点是后续知识点的基础 | 先决知识点 → 是前提 → 核心概念 |
| 关键点包含 | 表示关键点的包含关系 | 核心概念 → 关键点包含1：XXX |

## 完整示例：动态思维的觉醒

```
🔴 核心概念：动态思维的觉醒
│
├── 🔴 具有特征1：时空性
├── 🔴 具有特征2：流程性
├── 🔴 具有特征3：预测性
│
├── 🔴 动态视觉元素的审美规律和表现原理
│   ├── 节奏（具有属性）
│   ├── 韵律（具有属性）
│   ├── 平衡（具有属性）
│   └── 对比（具有属性）
│       └── 比较对象：水流 vs 熔岩
│
├── 🔴 动态观察方法
│   ├── 内容包含1：轨迹线
│   ├── 内容包含2：力的传导
│   ├── 内容包含3：轮廓线变化
│   └── 从看形状转向看姿态/轨迹/力
│
├── 🔴 动画与静态艺术的核心区别
│   ├── 关键点包含1：动画创作的灵魂
│   └── 关键点包含2：以运动、变化、发展视角观察/分析/表现事物
│
├── 🔴 力的传导与动态表现
│
├── 🔴 Timing与Spacing原理
│   ├── Timing（时间安排）
│   ├── Spacing（空间间距）
│   └── Prompt生成：重球 vs 气球落地
│
├── 🔵 动画中的动态思维（结构化知识框架）
│   ├── 步骤包含1：创意阶段（为什么动？）
│   ├── 步骤包含2：设计阶段（怎么动？）
│   └── 步骤包含3：呈现阶段（Timing与Spacing）
│
├── 🟢 平面构成的形式美法则与构成方法（先决知识）
│   └── 是前提 → 动态视觉元素的审美规律和表现原理
│
├── 🟢 把握'形'需要注意的事项（先决知识）
│
├── 支持案例与资源
│   ├── 《蜘蛛侠：纵横宇宙》动作片段 → 支持 → 节奏
│   ├── 流水视频、熔岩视频 → 支持 → 韵律
│   ├── 京剧动作 → 支持 → 平衡、传承中华美学
│   ├── 《疯狂动物城》树懒"闪电"片段 → 支持 → 动态思维
│   ├── 皮克斯《跳跳灯》 → 支持 → 动画中的动态思维
│   └── 艾德·霍克斯《动态自然》 → 支持 → 感知动态
│
└── 课程思政点（隐性知识）
    ├── 扎根生活、严谨治学 → 支持 → 捕捉肉眼不可见细节
    ├── 传承中华美学 → 支持 → 京剧动作
    └── 人机协同、驾驭技术 → 支持 → AI时代：人类定义逻辑与创意的基石
```

## 设计要点

1. **知识点挖掘全面**：必须涵盖与后续项目化教学课程紧密关联的知识组块
2. **陈述性知识点后列出范例**：尤其是一些理论性强、难以理解的陈述性知识点后，必须有范例知识点
3. **使用颜色标注**：核心知识点标红🔴、结构化知识框架标蓝🔵、先决知识点标绿🟢
4. **使用树状结构**：使用树状结构或思维导图形式展示知识点之间的逻辑关系
5. **使用关系连接**：使用"支持"、"具有特征"、"内容包含"、"步骤包含"、"是前提"等关系连接知识点
6. **确保一致性**：确保所有核心知识点、先决知识点、课程思政点都在知识建模图中体现
7. **范例具体**：范例知识点可以是案例、视频、图片、参考书等具体资源
