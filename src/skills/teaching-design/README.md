# 黄河科技学院课程教学设计生成 Skill

## 概述

这是一个专门为黄河科技学院教师设计的课程教学设计生成 Skill，严格按照学校《课程教学设计注意事项》的10个核心要素要求，生成符合学校标准的完整教学设计方案。

---

## 核心特性

### ✅ 完全符合学校标准

- 严格按照黄河科技学院课程教学设计规范的10个核心要素设计
- 符合度100%，可直接提交给学校审核
- 参考文件：`references/hkust-design-guide.md`

### 🎯 知识建模图

- 使用🔴标注核心知识点（红色）
- 使用🔵标注结构化知识框架（蓝色）
- 使用🟢标注先决知识点（绿色）
- 树状结构展示知识点之间的逻辑关系

### 📝 规范的师生交互过程

- 分为"教师行为"和"学生行为"两部分
- 避免对话式，采用行为式描述
- 设计关键的引导语和嵌套问题
- 体现教学策略的关键点

### 🎓 系统化的教学策略

- 帮助理解的有效策略（9种）
- 帮助记忆的有效策略（2种）
- 帮助运用的有效策略（3种）
- 课前收集学习困难问题
- 围绕操作流程与标准指导

---

## 使用方法

### 前置准备

在使用本 Skill 前，需要提供以下课程信息：

**必填信息：**
- 课程名称：如"动态思维基础"
- 教案名称：如"动态思维的觉醒"
- 学时安排：如"4学时"（需明确课上课下分配，如课上200分钟+课下400分钟）
- 课程类型：专业基础课/公共基础课/专业核心课/专业拓展课
- 教学形式：讲授形式/翻转课堂
- 适用专业：如"本科动画专业"
- 学生层次：如"大一学生"
- 任务内容：详细描述本课的教学内容和要求

**选填信息：**
- 评价重点：需要特别关注的学习成果
- 课程思政点：需要融入的思政元素
- 教学资源：已有的教学资源

### 使用示例

#### 示例1：动态思维基础课程

```
请使用 hkust-teaching-design skill 生成以下课程的教学设计方案：

课程名称：动态思维基础
教案名称：动态思维的觉醒
学时安排：4学时（课上200分钟+课下400分钟）
课程类型：专业基础课
教学形式：讲授形式
适用专业：本科动画专业
学生层次：大一学生
任务内容：本课重点讲解动态审美基础，包含平衡、节奏、对比、韵律等动态视觉元素的审美规律和表现原理，帮助学生建立动态思维的理论基础
```

#### 示例2：会议策划与组织课程

```
请使用 hkust-teaching-design skill 生成以下课程的教学设计方案：

课程名称：会议策划与组织
教案名称：会议日程设计
学时安排：4学时（课上180分钟+课下240分钟）
课程类型：专业核心课
教学形式：讲授形式
适用专业：会展策划与管理专业
学生层次：大二学生
任务内容：本课重点讲解会议日程设计的基本原则、方法和技巧，帮助学生掌握会议日程设计的核心能力
```

## 输出格式

本 Skill 将严格按照以下13个部分输出完整的教学设计方案：

### 一、课程基本信息
表格形式，包含课程名称、教案名称、学时安排、课程类型、教学形式、适用专业、学生层次、任务内容

### 二、知识建模图
使用树状结构，使用🔴🔵🟢标注

### 三、知识点（学习水平）
按照"知识点（学习水平）"的方式撰写

### 四、素质目标（课程思政点）
用*号标注课程思政点

### 五、学习先决知识
按照"知识点（学习水平）"的方式撰写

### 六、课上资源
分类汇总（视频/短片资源、教具、教学课件、素材库等）

### 七、课下资源
分类汇总（视频、参考书、网络资源、素材库等）

### 八、课上时间
与活动序列保持一致

### 九、课下时间
与活动序列保持一致

### 十、活动序列
表格形式，包含活动序列、活动目标、地点、时间、学习资源

### 十一、活动1-N
每个活动包含：
1. 活动知识建模图（使用🔴🔵🟢标注）
2. 活动目标（按"知识点（学习水平）"的方式撰写）
3. 活动任务序列（导入任务、任务一/二/三...）
   - 任务描述
   - 任务时长
   - 学习地点
   - 教学方式（或学习方式）
   - 师生交互过程（教师行为、学生行为、教学策略）
   - 学习资源
   - 学习成果及评价标准
   - 备注

### 十二、教学重点与难点
表格形式，包含教学重点/难点、对应目标/难度分析、解决方法

### 十三、教学策略
- （一）教学形式
- （二）帮助理解的有效策略
- （三）帮助记忆的有效策略
- （四）帮助运用的有效策略
- （五）课前收集学习困难问题
- （六）围绕操作流程与标准指导

## 与 obe-teaching-design Skill 的区别

| 对比项 | obe-teaching-design | hkust-teaching-design |
|--------|-------------------|----------------------|
| 适用对象 | 高职教师 | 黄河科技学院教师 |
| 设计理念 | OBE（成果导向教育） | 黄河科技学院课程教学设计规范 |
| 输出格式 | 9个部分 | 13个部分 |
| 知识建模图 | 无 | 有（🔴🔵🟢标注） |
| 活动设计 | 课前/课中/课后三阶段 | 活动1-N（每个活动包含导入任务、任务一/二/三...） |
| 师生交互 | 对话式 | 行为式（教师行为、学生行为） |
| 学习水平 | 布鲁姆6层次（记忆、理解、应用、分析、评价、创造） | 3层次（记忆、理解、运用） |
| 评价标准 | 综合评价量表+评量标准 | 学习成果及评价标准（每个任务） |
| 教学策略 | 教学流程图、教学方法、教学资源 | 帮助理解、帮助记忆、帮助运用 |
| 符合学校标准 | 高职OBE标准 | 黄河科技学院标准 |
