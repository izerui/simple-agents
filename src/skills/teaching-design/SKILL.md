# 应用型本科专业课程教学设计生成

## 任务目标
本 Skill 用于生成符合应用型本科教学设计规范的完整教学设计方案，帮助教师：
- 构建完整的知识建模图（核心知识点标红🔴、结构化知识框架标蓝🔵、先决知识点标绿🟢）
- 制定符合学习水平要求的知识点清单（记忆、理解、运用）
- 挖掘课程思政点并体现在知识建模图中
- 明确学习先决知识
- 分类汇总课上/课下资源和时间
- 设计完整的活动序列（活动1-N）
- 为每个活动构建活动知识建模图
- 制定每个活动的活动目标
- 设计详细的活动任务序列（导入任务、任务一/二/三...）
- 规范师生交互过程（教师行为、学生行为）
- 明确学习资源和评价标准
- 记录教学备注和反思
- 分析教学重点与难点并提供解决方法
- 设计系统化的教学策略（帮助理解、帮助记忆、帮助运用）

适用场景：应用型本科专业教师进行课程教学设计时，特别是需要严格按照规范要求提交教学设计的场合。

## 前置准备
在使用本技能前，需要提供以下课程信息：

**必填信息：**
- 课程名称：如"动态思维基础"
- 教案名称：如"动态思维的觉醒"
- 学时安排：如"4学时"（需明确课上课下分配，如课上200分钟+课下400分钟）
- 课程类型：专业基础课/公共基础课/专业核心课/专业拓展课
- 教学形式：讲授形式/翻转课堂
- 适用专业：如"本科动画专业"
- 学生层次：如"大一学生"
- 任务内容：详细描述本课的教学内容和要求

**选填信息：**
- 评价重点：需要特别关注的学习成果（如"动态思维理解"、"动态速写能力"、"人机协同创作"等）
- 课程思政点：需要融入的思政元素（如"工匠精神"、"文化自信"、"创新意识"等）
- 教学资源：已有的教学资源（如视频、案例、课件等）

**说明：**
- 课程类型将影响教学策略和教学活动的设计侧重点
- 教学形式将决定师生交互过程的设计方式
- 学时安排需要明确课上课下的时间分配，与活动序列保持一致

## 操作步骤

**重要说明**：本技能将严格按照应用型本科教学设计规范的10个核心要素输出完整的教学设计方案。使用者只需提供课程基本信息，技能将自动生成符合规范的完整方案。

### 步骤1：构建知识建模图

**知识建模图要求：**
1. **知识点挖掘全面**：必须涵盖与后续项目化教学课程紧密关联的知识组块
2. **陈述性知识点后列出范例**：尤其是一些理论性强、难以理解的陈述性知识点后，必须有范例知识点
3. **核心知识点标红**：使用🔴标注核心知识点（图形边线和字体均标红）
4. **结构化知识框架标蓝**：使用🔵标注核心的结构化知识框架（图形边线和字体均标蓝），以"知识点-知识点-知识点-知识点…"表示
5. **先决知识点标绿**：使用🟢标注先决知识点（图形边线和字体均标绿），要与本次课的专业知识点有紧密相关关系

**知识建模图结构：**
```
🔴 核心概念：XXX
│
├── 🔴 子概念1
├── 🔴 子概念2
├── 🔴 子概念3
│
├── 🔵 结构化知识框架（步骤包含1/2/3...）
│   ├── 步骤包含1：XXX
│   ├── 步骤包含2：XXX
│   └── 步骤包含3：XXX
│
├── 🟢 先决知识点
│   └── 是前提 → 核心概念
│
├── 支持案例与资源
│   ├── 案例1 → 支持 → 子概念1
│   ├── 案例2 → 支持 → 子概念2
│   └── 资源1 → 支持 → 子概念3
│
└── 课程思政点（隐性知识）
    ├── 思政点1 → 支持 → 相关概念
    └── 思政点2 → 支持 → 相关概念
```

**设计要点：**
- 使用树状结构或思维导图形式展示知识点之间的逻辑关系
- 使用"支持"、"具有特征"、"内容包含"、"步骤包含"、"是前提"等关系连接知识点
- 确保所有核心知识点、先决知识点、课程思政点都在知识建模图中体现
- 范例知识点可以是案例、视频、图片、参考书等具体资源

### 步骤2：制定知识点（学习水平）

**知识点（学习水平）要求：**
1. **学习水平类型**：记忆、理解、运用三种类型
2. **匹配最高层次**：每个知识点匹配最高层次学习水平
3. **体现知识建模图**：所有知识点都要在知识建模图中体现
4. **按标准格式撰写**：按照"知识点（学习水平）"的方式撰写

**学习水平定义：**
- **记忆**：能够回忆和识别基本事实、概念、原理等
- **理解**：能够解释和说明概念、原理的含义和内在逻辑
- **运用**：能够在具体情境中应用概念、原理解决问题

**知识点清单示例：**
1. 动态思维的觉醒（理解）
2. 动态思维（理解）
3. 动态视觉元素的审美规律和表现原理（理解）
4. 节奏（理解）
5. 韵律（理解）
6. 平衡（理解）
7. 对比（理解）
8. 动态观察方法（运用）
9. 从看形状转向看姿态/轨迹/力（理解）
10. 轨迹线（运用）
...

**设计要点：**
- 知识点要全面，涵盖知识建模图中的所有核心知识点
- 每个知识点都要标注学习水平（记忆/理解/运用）
- 知识点的表述要清晰、具体、可测
- 确保知识点与知识建模图保持一致

### 步骤3：挖掘素质目标（课程思政点）

**素质目标（课程思政点）要求：**
1. **挖掘课程思政点**：需要老师挖掘本次课对应的课程思政点
2. **与知识点对应**：需要在上课中有对应的知识点
3. **特有素质**：一些本次课涉及到的特有素质，比如专业知识点相关爱国主义故事
4. **体现在知识建模图中**：思政点（隐性知识）要体现在知识建模图中
5. **用*号标注**：在素质目标后用*号标注课程思政点

**素质目标示例：**
1. 具备'发展变化'的辩证唯物主义世界观*
2. 具备'扎根生活、严谨治学'的工匠精神*
3. 具备'传承中华美学'的文化自信*
4. 具备'人机协同、驾驭技术'的创新意识与主体责任感*

**设计要点：**
- 素质目标要与课程内容紧密结合，自然融入
- 素质目标要具体、可测、可评价
- 素质目标要在知识建模图中体现
- 素质目标要在师生交互过程中有对应的环节

### 步骤4：明确学习先决知识

**学习先决知识要求：**
1. **罗列所有先决知识点**：知识建模图中所有先决知识点要全部罗列
2. **按照标准格式撰写**：按照"知识点（学习水平）"的方式撰写
3. **与专业知识点紧密相关**：先决知识点要与本次课的专业知识点有紧密相关关系
4. **在知识建模图中体现**：先决知识点要用🟢标注

**学习先决知识示例：**
1. 平面构成的形式美法则与构成方法（运用）
2. 把握'形'需要注意的事项（理解）

**设计要点：**
- 先决知识是学生学习本次课内容必须具备的基础知识
- 先决知识要与本次课的专业知识点有直接关联
- 先决知识要在知识建模图中用🟢标注
- 先决知识要在导入任务中唤起学生的记忆

### 步骤5：分类汇总课上资源与课下资源

### 步骤6：明确课上时间与课下时间

**课上时间与课下时间要求：**
1. **课上时间**：与后面课上活动设计的总时长保持一致
2. **课下时间**：与后面课下活动设计的总时长保持一致
3. **时间分配合理**：根据学生身心发展特点与理解水平合理分配时间
4. **时间单位明确**：使用"分钟"作为时间单位

**时间分配示例：**
- 课上时间：200分钟
- 课下时间：400分钟

**设计要点：**
- 课上课下时间要与活动序列保持一致
- 时间分配要考虑学生的认知负荷
- 时间分配要确保完成学习任务
- 时间分配要符合学校的教学安排

### 步骤8：构建活动知识建模图

**活动知识建模图要求：**
1. **与活动任务序列匹配**：每一项活动的知识建模图与下面的活动任务序列相匹配，不能画多或者画少
2. **切分合理**：一个活动应能相对完整地达成学习目标，活动知识建模图的切分遵循相对独立、结构化、易被学生消化理解的原则
3. **时长合理**：活动的时长应符合学生身心发展特点与理解水平
4. **使用颜色标注**：核心知识点标红🔴、结构化知识框架标蓝🔵、先决知识点标绿🟢

**活动知识建模图示例：**

**设计要点：**
- 活动知识建模图要与总知识建模图保持一致
- 活动知识建模图要聚焦于本活动的知识点
- 活动知识建模图要使用颜色标注
- 活动知识建模图要与下面的活动任务序列相匹配

### 步骤9：制定活动目标

**活动目标要求：**
1. **列出所有知识点**：除先决知识外，本次活动知识建模图中的知识点全部列出
2. **按标准格式撰写**：按照"知识点（学习水平）"的方式撰写，每个知识点匹配最高层次学习水平
3. **与活动知识建模图一致**：活动目标要与活动知识建模图保持一致

**活动目标示例：**
1. 动态思维（理解）
2. 以运动、变化、发展视角观察/分析/表现事物（记忆）
3. 区别动画与静态艺术的核心（理解）

**设计要点：**
- 活动目标要全面，涵盖活动知识建模图中的所有知识点
- 活动目标要按标准格式撰写
- 活动目标要与活动知识建模图保持一致
- 活动目标要体现最高层次学习水平

### 步骤10：设计活动任务序列

**活动任务序列要求：**

#### 10.1 导入任务

**导入任务要求：**
1. **围绕先决知识点**：教师需要设计相应师生交互过程，创设情境，选用合理有效的教学策略
2. **唤起先决知识**：重点是要唤起和帮助学生回忆起先决知识的教学策略
3. **展开典型语言和行为**：要展开师生互动的典型语言和行为，其中老师引导学生进行思维或思考的恰当的"引导语"是关键点
4. **不能时间太长**：主要目的是唤起学生对和本次课最直接相关的已有的先决知识的记忆
5. **引出本次课程的内容**：唤醒先决知识，引出本次课程的内容

**师生交互过程要求：**
采用时间线式描述，按照实际教学过程的先后顺序，依次描述教师和学生的互动行为。每一轮互动都包含教师的引导行为和学生的回应行为，体现教学过程中的自然对话和互动流程。

**导入任务示例：**

### 师生交互过程

### 任务一知识组块

**任务描述**：因为动态思维的定义对于大一新生来说较为抽象，若直接讲授容易流于表面，采用对比分析法，通过对比静态图像与动态影像的感知差异，引导学生主动归纳出动态思维的本质，达到学生能够自主构建并清晰阐述动态思维定义的学习结果。

**任务时长**：10分钟

**学习地点**：课上

**教学方式（或学习方式）**：
- ☑ 讲授
- ☐ 小组讨论
- ☐ 答疑
- ☐ 实验
- ☐ 实训
- ☐ 自主学习
- ☐ 翻转课堂
- ☑ 其他：对比分析

### 师生交互过程

#### 1. 对比分析

1. **教师**：在屏幕上并排展示两张图：图A是一张高清的运动员跳高剪影（静态）；图B是一张跳高过程中的运动模糊照片（也是静态的像素，但动态感极强）。（采用对比分析法，创设对比情境）
   **学生**：观察两张图片，对比静态图像与动态影像的感知差异。

2. **教师**：提出引导性问题："哪一张图让你感觉到'动'？是哪一部分线索告诉你的？"（运用对比分析法，通过问题引导学生观察差异）
   **学生**：思考并回答教师提出的问题。

#### 2. 知识讲解

1. **教师**：引导学生思考：当看图A时，大脑自动补全了前后的动作。（运用引导发现法，引导学生自主思考）
   **学生**：听讲，理解教师的引导。

2. **教师**：讲解动态思维的定义：这种不依赖画面本身在动，而是依赖大脑对时间流逝和状态变化的推演的能力，就是动态思维。（运用引导发现法，在引导中讲解概念）
   **学生**：听讲，理解动态思维的概念。

3. **教师**：引导学生用自己的话定义什么是动态思维，它关注的焦点是什么。（运用引导发现法）
   **学生**：尝试用自己的话定义动态思维。

#### 3. 总结与巩固

1. **教师**：修正与总结学生的定义，强调动态思维就是一种以运动、变化和发展的视角去观察、分析和表现事物的思维方式。（运用归纳总结法）
   **学生**：根据教师的总结，完善自己的定义。

2. **教师**：引导学生进行'我的词条'微词条总结。（运用归纳总结法）
   **学生**：进行'我的词条'微词条总结。

**教学策略**：对比分析法、引导发现法、归纳总结法

### 学习资源

1. 教学课件：动态思维基础PPT
2. 素材库：静态图片A、动态模糊图片B

### 学习成果及评价标准

**学习成果**：
'我的定义'微词条。学生需要用一句话总结动态思维，并举一个生活中的例子（非动画领域，如花开、水流）来佐证该定义。

**评价标准**：
- 优秀（A）：定义准确包含'运动/变化'和'视角/思维模式'两个维度；例子贴切且生动。
- 良好（B）：定义基本准确；例子能说明问题。
- 合格（C）：仅能复述老师给出的关键词；例子牵强。
- 待改进（D）：无法理解定义，无法举例。

**评价方式**：同桌互评后教师抽查，允许现场修正。

### 步骤11：分析教学重点与难点

**教学重点与难点要求：**

#### 11.1 教学重点

**教学重点分析：**
- 根据三维目标和职业岗位需求，确定教学重点内容
- 教学重点通常是完成任务必须掌握的核心知识、关键技能
- 每个教学重点应明确对应知识目标或技能目标

**教学重点解决方法：**
- 设计针对性教学活动，通过案例教学、实践操作等方式强化重点
- 提供充分的练习和应用机会
- 结合多媒体资源和实际案例进行讲解
- 使用图表、视频、案例、对比、举例、例题演示等策略

| 教学重点 | 对应目标 | 解决方法 |

#### 11.2 教学难点

**教学难点分析：**
- 根据学生认知水平和任务复杂度，确定教学难点
- 教学难点通常涉及抽象概念理解、复杂技能应用、跨知识整合等

**教学难点解决方法：**
- 采用分层教学，从简单到复杂逐步深入
- 使用类比、对比等教学方法降低理解难度
- 增加实践环节，通过动手操作突破难点
- 提供针对性指导和支持

**教学难点示例：**
| 教学难点 | 难度分析 | 解决方法 |
|----------|----------|----------|
| 从静态思维向动态思维的转变 | 涉及思维模式重构，学生习惯于静态观察 | 采用**举例类比**方法，将动态思维与生活经验关联（如观察流水、旗帜飘动）；通过**故事引申**意义，说明思维转变的重要性 |
| 力的传导与轨迹线的理解 | 抽象概念，难以直接观察 | 采用**视频**展示自然现象（流水、熔岩）；使用**图表**展示力的传导路径；通过**举例**说明力的传导过程 |
| 平衡、节奏、对比、韵律在动态中的综合理解 | 需要整合多个审美要素，复杂度高 | 采用**案例**分析方法，拆解优秀作品中的要素应用；使用**结构化图表**展示四个要素的关系；通过**例题演示**综合分析 |
| Timing与Spacing的量化理解 | 涉及时间与空间的抽象关系 | 采用**图表**可视化Timing与Spacing的对比数据；使用**例题演示**计算过程；通过**对比**重球与气球的差异 |

**设计要点：**
- 教学重点要对应教学目标
- 教学重点要设计具体的解决方法
- 教学难点要分析难度原因
- 教学难点要设计针对性的解决方法
- 解决方法要具体、可操作

### 步骤12：设计教学策略

**教学策略要求：**

#### 12.1 教学形式
**讲授形式**或**翻转课堂**

#### 12.2 帮助理解的有效策略

**图表策略：**
- **动态思维结构图**：使用思维导图展示动态思维的三个核心特征（时空性、流程性、预测性）及其关系
- **审美规律框架图**：使用结构化图表展示平衡、节奏、对比、韵律四个要素的内涵和相互关系
- **Timing与Spacing对比图**：使用可视化图表展示重球与气球落地的Timing与Spacing数据对比
- **知识建模图**：使用拓扑图展示本课所有知识点及其关联关系，让学生以整体结构化方式理解学习内容

**视频策略：**
- **优秀动画案例视频**：《蜘蛛侠：纵横宇宙》动作片段、《疯狂动物城》树懒"闪电"片段、皮克斯《跳跳灯》
- **自然现象视频**：流水视频、熔岩视频，对比不同动态的节奏与韵律
- **文化视频**：京剧动作视频，传承中华美学，展示传统动态美
- **示范视频**：教师动态观察方法示范视频

**案例策略：**
- **动画案例分析**：分析《蜘蛛侠：纵横宇宙》《疯狂动物城》《跳跳灯》等经典动画片段
- **自然现象案例**：分析流水、熔岩等自然现象的动态特征
- **文化案例**：分析京剧动作中的平衡与美感

**举例策略：**
- **生活举例**：花开、水流、旗帜飘动等生活现象中的动态思维
- **专业举例**：动画创作中的动态思维应用案例

**例题演示策略：**
- **审美要素分析演示**：演示如何分析动画片段中的节奏、韵律、平衡、对比
- **Timing与Spacing计算演示**：演示如何计算帧间距，理解时间与空间的关系

**类比策略：**
- **静态vs动态类比**：对比静态图像与动态影像的感知差异
- **水流vs熔岩类比**：对比不同物质的动态特征

**故事引申策略：**
- **思维转变故事**：通过故事引申从静态思维向动态思维转变的重要性
- **工匠精神故事**：通过故事引申扎根生活、严谨治学的专业态度

**结构化理解策略：**
- **知识建模图**：使用拓扑图展示知识点之间的关联关系
- **三阶段流程图**：展示动画创作中动态思维的三个阶段

**关联理解策略：**
- **先决知识关联**：关联平面构成的形式美法则与动态视觉审美规律
- **生活经验关联**：将动态思维与学生的生活经验关联

#### 12.3 帮助记忆的有效策略

**自编顺口溜：**
- **动态思维三特征顺口溜**："时空流程预测性，动态思维要牢记"
- **审美四要素顺口溜**："平衡节奏对比韵律，动态审美四要素"

**生活常识关联：**
- **时间关联**：将"时空性"关联到日常生活中的时间感知
- **流程关联**：将"流程性"关联到做事的步骤和流程
- **预测关联**：将"预测性"关联到对未来的预期和判断

#### 12.4 帮助运用的有效策略

**操作手册：**
- **动态观察方法操作手册**：提供从看形状转向看姿态/轨迹/力的具体操作步骤
- **Timing与Spacing调整手册**：提供如何调整Timing与Spacing的具体方法

**教师示范：**
- **动态速写示范**：教师示范如何进行2分钟动态速写
- **轨迹线绘制示范**：教师示范如何绘制轨迹线，表现力的传导

**一对一指导：**
- **个别辅导**：针对学生常见问题进行个别辅导和集体讲解
- **作业点评**：选取典型作业进行示范点评，引导学生对比不同作业的差异

#### 12.5 课前收集学习困难问题

在课前通过学习平台收集学生的学习困难问题，包括：
- 对动态思维概念的理解困难
- 对力的传导与轨迹线的理解困难
- 对Timing与Spacing的量化理解困难
- 对动态观察方法转变的适应困难

#### 12.6 围绕操作流程与标准指导

- **动态观察流程**：从看形状→看姿态→看轨迹→看力的传导
- **动态速写标准**：轮廓线变化、轨迹线清晰、力的传导明确
- **Timing与Spacing调整标准**：根据物体特性调整时间与空间的关系

**设计要点：**
- 教学策略要系统化，分为帮助理解、帮助记忆、帮助运用三类
- 每个策略要具体、可操作
- 教学策略要与师生交互过程保持一致
- 教学策略要针对教学重点和难点

## 注意事项

**知识建模图注意事项：**
- 知识点挖掘全面，必须涵盖与后续项目化教学课程紧密关联的知识组块
- 陈述性知识点后尽可能列出相关范例知识点
- 核心知识点标红🔴，结构化知识框架标蓝🔵，先决知识点标绿🟢
- 使用树状结构或思维导图形式展示知识点之间的逻辑关系

**知识点（学习水平）注意事项：**
- 学习水平有记忆、理解、运用三种类型
- 每个知识点匹配最高层次学习水平
- 按照标准格式撰写："知识点（学习水平）"

**素质目标（课程思政点）注意事项：**
- 需要老师挖掘本次课对应的课程思政点
- 需要在上课中有对应的知识点
- 思政点（隐性知识）要体现在知识建模图中
- 用*号标注课程思政点

**学习先决知识注意事项：**
- 知识建模图中所有先决知识点要全部罗列
- 按照"知识点（学习水平）"的方式撰写
- 先决知识点要与本次课的专业知识点有紧密相关关系

**课上/课下资源注意事项：**
- 分类汇总本次课所有课上/课下活动的学习资源
- 资源分类清晰（视频/短片资源、教具、教学课件、素材库、参考书、网络资源等）
- 资源具体明确，有明确的名称和来源

**课上/课下时间注意事项：**
- 课上时间与后面课上活动设计的总时长保持一致
- 课下时间与后面课下活动设计的总时长保持一致
- 使用"分钟"作为时间单位

**活动序列注意事项：**
- 活动序列要涵盖所有知识点
- 活动目标要明确，按"知识点（学习水平）"的方式撰写
- 活动时间要合理，与总时间保持一致
- 学习资源要分类列出，具体明确
- 课下任务也需要设计师生交互过程描述
- 课下任务的师生交互过程主要描述任务布置时的师生互动
- 课下任务的教学策略应包括自主学习法以及1-2种其他适合课下任务的教学策略

**师生交互过程注意事项：**
- 采用时间线式描述，按照实际教学过程的先后顺序
- 每一轮互动都包含教师的引导行为和学生的回应行为
- 每个任务（包括课下任务）都需要设计师生交互过程
- 课下任务的师生交互过程主要描述任务布置时的互动，包括任务要求说明、资源提供、疑问解答等
- 课下任务的师生交互过程描述以学生行为为主
- 课下任务的教师行为主要作为任务部署或下发的简要描述
- 课下任务的学生行为应针对教师下达的课下任务进行具体行为的描述
- 师生交互过程要标注教学策略使用方式
- 师生交互过程与任务描述中的教学策略保持一致

**活动序列注意事项：**
- 活动目标体现裁剪活动的最高阶知识点目标
- 按"知识点（学习水平）"的方式撰写
- 地点明确（课上/课下）
- 时间明确（XX分钟）
- 学习资源分类列出
- 课下任务的教学策略应包括自主学习法以及1-2种其他适合课下任务的教学策略

**活动知识建模图注意事项：**
- 每一项活动的知识建模图与下面的活动任务序列相匹配
- 活动知识建模图的切分合理
- 活动的时长应符合学生身心发展特点与理解水平
- 使用🔴🔵🟢标注

**活动目标注意事项：**
- 除先决知识外，本次活动知识建模图中的知识点全部列出
- 按照"知识点（学习水平）"的方式撰写
- 每个知识点匹配最高层次学习水平

**活动任务序列注意事项：**

**导入任务：**
- 围绕先决知识点，设计师生交互过程
- 唤起先决知识，引出本次课程的内容
- 不能时间太长

**任务一/二/三...：**
- 任务描述：因为何种思考或原因，采用××教学策略，达到××的学习结果
- 任务时长：确保完成学习任务的基础上，尽量用最短时长
- 学习地点：一个任务只对应一种学习地点
- 教学方式：教学方式恰当，与教学策略逻辑一致
- 师生交互过程：
  - 老师要采取合适的教学策略
  - 师生互动过程要体现出教学策略的关键点
  - 要设计关键的引导语
  - 写清楚教学过程的一个标志，就是能够让同专业老师直接可以上课
  - 老师不能太多采取简单问答的方式进行教学
  - 分为教师行为和学生行为
- 学习资源：标注清晰、具体，应匹配学习目标
- 学习成果及评价标准：
  - 学习成果清晰具体
  - 学习成果与知识目标、能力目标相对应
  - 成果工作量合理，难度适中
  - 评价标准清晰、具体、客观
  - 允许学生改善并重新提交学习成果
  - 学习成果评价标准必须提前告知学生
  - 尽可能所有学生都要参与评价
- 备注：上课结束以后对于该活动（任务）的教学心得、体会或反思等；补充课上收集到的学生学情信息

**教学重点与难点注意事项：**
- 教学重点对应教学目标
- 教学重点设计具体的解决方法
- 教学难点分析难度原因
- 教学难点设计针对性的解决方法

**教学策略注意事项：**
- 教学策略系统化，分为帮助理解、帮助记忆、帮助运用三类
- 每个策略具体、可操作
- 教学策略与师生交互过程保持一致
- 教学策略针对教学重点和难点

**一致性原则：**
- 知识建模图、知识点（学习水平）、素质目标、学习先决知识、课上/课下资源、课上/课下时间、活动序列、活动知识建模图、活动目标、活动任务序列、教学重点与难点、教学策略必须保持高度一致
- 确保每个知识点都有对应的教学环节、学习资源和评价标准

**时间控制：**
- 课上课下时间要与活动序列保持一致
- 活动时长要合理，符合学生身心发展特点

**灵活性：**
- 根据不同课程特点和学生层次，灵活调整知识建模图的结构、活动序列的安排、教学策略的选择
