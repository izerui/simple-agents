# 高职OBE教学设计生成

## 任务目标
本 Skill 用于生成符合OBE（成果导向教育）理念的高职课程教学设计方案，帮助教师：
- 基于布鲁姆教育目标分类学制定可测可量的三维教学目标
- 分析教学重点与难点并提供解决方法
- 设计教学策略（教学流程图、教学方法、教学资源）
- 安排教学活动（课前、课中、课后三个阶段）
- 设计与目标匹配的情境化教学案例
- 编写覆盖不同认知层次的配套习题
- 制定整合多维度表现的综合评价量表
- 制定基于质量等级的评量标准

适用场景：高职教师进行课程任务教学设计时，特别是需要确保目标可测、案例关联、评价全面的场合。

## 前置准备
在使用本技能前，需要提供以下课程信息：

**必填信息：** 
- 课程名称：如"会议策划与组织"
- 教案名称：如"会议日程设计"
- 学时安排：如"4学时"
- 任务内容：简要描述本教学任务的内容和要求
- 课程类型：理论、实训、理论+实训（三选一）

**选填信息：** 
- 适用专业：如"会展策划与管理专业"
- 学生层次：如"大二学生"
- 评价重点：需要特别关注的评价维度（如"会议日程设计"、"小组讨论参与度"、"汇报表现"等）

**说明**：
- 课程类型将影响教学策略和教学活动的设计侧重点：
  - 理论课：侧重知识讲解、案例分析、小组讨论等
  - 实训课：侧重实践操作、技能训练、成果展示等
  - 理论+实训课：平衡理论与实践，合理分配时间

## 操作步骤

**重要说明**：本技能将严格按照以下固定格式输出完整的OBE教学设计方案，包含九个部分。使用者只需提供课程基本信息，技能将自动生成完整方案。

### 步骤1：分析课程信息，确定布鲁姆认知层次
- 根据任务内容和学生层次，确定知识目标、技能目标、素养目标应涵盖的布鲁姆认知层次
- 知识目标通常涵盖记忆、理解、应用层次
- 技能目标通常涵盖分析、评价、创造层次
- 素养目标关注职业能力、协作能力和问题解决能力，并可融入思政元素
- 参考 [references/blooms-taxonomy.md](references/blooms-taxonomy.md) 选择合适的布鲁姆分级动词

### 步骤2：生成三维教学目标
- 知识目标：
  - 每个目标以布鲁姆分级动词开头
  - 直接使用动词，不使用"能够"、"可以"等辅助词
  - 目标表述清晰、可测、可量
  - 确保每个目标对应具体的知识内容
  - 示例："复述会议日程的基本组成要素"、"解释会议日程编排的基本原则"
- 技能目标：
  - 侧重实际操作和能力培养
  - 使用分析、评价、创造等高阶动词
  - 目标应体现任务完成的能力要求
  - 示例："分析给定会议日程的优缺点"、"独立设计完整的大型会议日程"
- 素养目标：
  - 侧重职业素养、沟通协作、问题解决等核心素养
  - 目标应体现职业岗位要求
  - 示例："培养严谨细致的工作态度"、"提升团队协作和沟通能力"

### 步骤3：分析教学重点与难点
- 教学重点分析：
  - 根据三维目标和职业岗位需求，确定教学重点内容
  - 教学重点通常是完成任务必须掌握的核心知识、关键技能
  - 每个教学重点应明确对应知识目标或技能目标
  - 示例："会议日程编排的基本原则"、"会议日程的时间合理性要求"
- 教学重点解决方法：
  - 设计针对性教学活动，通过案例教学、实践操作等方式强化重点
  - 提供充分的练习和应用机会
  - 结合多媒体资源和实际案例进行讲解
- 教学难点分析：
  - 根据学生认知水平和任务复杂度，确定教学难点
  - 教学难点通常涉及抽象概念理解、复杂技能应用、跨知识整合等
  - 示例："会议时间的合理分配"、"不同类型会议的差异化设计"
- 教学难点解决方法：
  - 采用分层教学，从简单到复杂逐步深入
  - 使用类比、对比等教学方法降低理解难度
  - 增加实践环节，通过动手操作突破难点
  - 提供针对性指导和支持
- 参考 [references/obe-design-guide.md](references/obe-design-guide.md) 中的教学重点难点分析方法

### 步骤4：设计教学策略
- 教学流程图设计：
  - 设计清晰的教学流程，体现教学过程的逻辑顺序
  - 流程图应包含课前、课中、课后三个阶段
  - 突出关键教学环节和决策点
  - 流程描述：使用文字或箭头表示流程，如"课前预习→情境导入→案例分析→小组讨论→成果展示→评价反馈→课后拓展"
- 教学方法选择：
  - 根据教学目标和内容特点选择合适的教学方法
  - 常用教学方法：案例教学法、项目教学法、任务驱动法、小组讨论法、情境模拟法、翻转课堂等
  - 每个教学方法应明确其应用环节和预期效果
  - 示例："案例教学法（环节：案例分析，效果：通过真实案例理解理论知识）"
- 教学资源准备：
  - **资源生成原则**：根据教学方法生成配套资源，确保每个教学方法都有可直接使用的资源支撑
  - **资源类型与生成要求**：
    - 教学案例：当教学方法中包含"案例教学法"时，生成真实或仿真的情境化教学案例，包含背景、任务、问题分析、解决方案
    - 小组讨论材料：当教学方法中包含"小组讨论法"时，生成讨论题和讨论组织方式（分组规则、讨论流程、成果呈现形式）
    - 教学视频：当教学方法中需要视频资源时，生成视频主题、内容要点、使用说明
    - PPT课件：当教学方法中包含"知识讲解"时，生成课件大纲和核心内容
    - 工具软件：当教学方法中涉及软件操作时，生成软件名称、功能说明、操作步骤
    - 评价量表：生成完整的综合评价量表，与三维目标对应
  - **资源与方法的对应关系**：
    - 案例教学法 → 教学案例（完整情境案例）
    - 小组讨论法 → 小组讨论材料（讨论题+组织方式）
    - 情境模拟法 → 情境模拟脚本（情境描述、角色设定、任务要求）
    - 项目教学法 → 项目任务书（项目目标、任务分解、交付要求）
    - 任务驱动法 → 任务清单（任务描述、完成标准、评价依据）
    - 翻转课堂 → 翻转学习资源（课前学习材料、课前任务单）
  - 每个资源应明确其用途和使用环节
  - 示例："教学案例：某科技公司年度战略研讨会案例（环节：案例分析，内容：完整背景、任务、问题分析、解决方案）"
- 参考 [references/obe-design-guide.md](references/obe-design-guide.md) 中的教学策略设计模板

### 步骤5：设计教学活动安排
- 分课前、课中、课后三个阶段设计教学活动
- 课前阶段：
  - 教学环节：如课前预习、资源学习、问题思考等
  - 教学内容：学生需要学习或准备的资料、问题等
  - 教师活动：发布预习任务、提供学习资源、设置预习问题等
  - 学生活动：自主学习、查阅资料、完成预习任务等
  - 设计意图：为课中学习做铺垫，激发学生学习兴趣
    - **标注说明**：如果设计意图与素养目标对应且具有思政效果，用星号（*）标注
    - 示例："培养职业素养，树立正确的价值观*"
- 课中阶段：
  - 教学环节设计要求：
    - 每个环节标注时间分配，最少时间为5分钟，最长环节不超过30分钟
    - 环节设置应体现教学流程的逻辑顺序
    - 常见环节：情境导入、知识讲解、案例分析、小组讨论、实践操作、成果展示、评价反馈等
  - 课中阶段以表格形式输出，包含五个部分：
    - 教学环节：环节名称及时间分配
    - 教学内容：该环节涉及的教学内容和知识点
    - 教师活动：教师的组织、引导、讲解、评价等活动
    - 学生活动：学生的学习、讨论、实践、展示等活动
    - 设计意图：该环节的教学目的和预期效果
      - **标注说明**：如果设计意图与素养目标对应且具有思政效果，用星号（*）标注
- 课后阶段：
  - 教学环节：如课后作业、拓展学习、反思总结等
  - 教学内容：需要完成的作业、拓展阅读、反思问题等
  - 教师活动：布置作业、提供拓展资源、反馈指导等
  - 学生活动：完成作业、拓展学习、总结反思等
  - 设计意图：巩固学习成果，促进知识迁移和能力提升
    - **标注说明**：如果设计意图与素养目标对应且具有思政效果，用星号（*）标注
- 参考 [references/obe-design-guide.md](references/obe-design-guide.md) 中的教学活动安排表格模板

### 步骤6：设计教学案例
- 案例背景：根据课程特点和任务主题，设计真实或仿真的工作情境
- 任务描述：明确学生需要完成的具体任务
- 问题分析：设置需要解决的矛盾或问题
- 优化方案：提供对比方案，体现目标要求
- 案例设计要点：
  - 与三维目标高度一致，每个目标都应在案例中找到对应环节
  - 情境真实，符合职业岗位实际需求
  - 具有可操作性，学生能够实际执行
  - 包含认知冲突，激发学生思考和解决问题

### 步骤7：编写配套习题
- **习题设计原则**：
  - 习题应覆盖布鲁姆不同认知层次：记忆、理解、应用、分析、评价、创造
  - 每个层面至少包含两种不同类型的题目
  - 常见题型：选择题（单选、多选）、判断题、填空题、简答题、案例分析题、方案设计题等
  - 每个习题应明确对应三维目标中的具体目标
  - 提供参考答案或评分标准
- **各层次题型要求**：
  - **记忆层面**：至少2种题型，如单选题、判断题、填空题
    - 单选题：考察基本概念、要素的识别
    - 判断题：考察基本原理的理解
    - 填空题：考察基本要素的列举
  - **理解层面**：至少2种题型，如单选题、判断题、简答题
    - 单选题：考察概念解释、意义说明
    - 判断题：考察原理阐述的正误判断
    - 简答题：考察概念解释、意义说明
  - **应用层面**：至少2种题型，如多选题、简答题、案例分析题
    - 多选题：考察方法应用的多个要点
    - 简答题：考察方法应用、方案制定
    - 案例分析题：考察情境解决
  - **分析层面**：至少2种题型，如多选题、案例分析题、简答题
    - 多选题：考察问题分析的多个方面
    - 案例分析题：考察优缺点评价、改进建议
    - 简答题：考察问题分析
  - **评价层面**：至少2种题型，如多选题、简答题、案例分析题
    - 多选题：考察方案评估的多个标准
    - 简答题：考察适用性判断、价值判断
    - 案例分析题：考察方案评估
  - **创造层面**：至少2种题型，如方案设计题、案例分析题、简答题
    - 方案设计题：考察方案设计、创新建议
    - 案例分析题：考察综合运用
    - 简答题：考察创新建议
- 参考 [references/obe-design-guide.md](references/obe-design-guide.md) 中的配套习题设计模板

### 步骤8：制定综合评价量表
- 评价维度设置：
  - 任务成果维度（如会议日程设计）：重点突出，分值占比最高
  - 过程表现维度（如小组讨论参与度、汇报表现）
  - 素养维度（如职业态度、协作能力）
- 评价标准制定：
  - 每个维度下设3-5个评价标准
  - 每个标准明确具体要求，可观察、可测量
  - 分值分配合理，总分通常为100分
- 量表设计要点：
  - 与三维目标高度一致，确保每个目标都有对应的评价指标
  - 评价标准清晰、具体，便于教师评分和学生理解
  - 突出任务成果评价，体现OBE以成果为导向的理念
  - 关注过程性评价，全面反映学生学习表现
- 参考 [references/obe-design-guide.md](references/obe-design-guide.md) 中的评价量表模板

### 步骤9：制定评量标准
- 评量标准表格设计：
  - 横向：质量维度，包括知识、能力、素养三个维度
  - 纵向：质量等级，分为A（优）、B（良）、C（中）三个等级
- 评量标准表述：
  - 使用"布鲁姆动词+评量对象"的表述方式
  - 每条标准尽可能可测可量
  - 与教学活动或习题保持对应关系
- 质量等级定义：
  - A（优）：完全达到目标，表现优秀
  - B（良）：基本达到目标，表现良好
  - C（中）：部分达到目标，有待提升
- 评量标准设计要点：
  - 每个质量维度对应三维目标中的知识、技能、素养目标
  - 评量标准与教学活动和习题形成闭环
  - 等级划分清晰，便于教师评价和学生自我评估
- 参考 [references/obe-design-guide.md](references/obe-design-guide.md) 中的评量标准表格模板

### 步骤10：输出最终方案

**输出格式固定为以下九个部分，严格按照顺序和结构输出：** 

#### 一、课程基本信息
以表格形式呈现，包含：课程名称、教案名称、学时安排、课程类型、任务内容

#### 二、三维教学目标（基于布鲁姆教育目标分类学）
- （一）知识目标：记忆、理解、应用层次，每个目标使用布鲁姆动词开头
- （二）技能目标：分析、评价、创造层次，每个目标使用布鲁姆动词开头
- （三）素养目标：关注职业素养、创新意识、伦理意识等，可融入思政元素（用*标注）

#### 三、教学重点与难点
- （一）教学重点：表格形式，包含教学重点、对应目标、解决方法
- （二）教学难点：表格形式，包含教学难点、难度分析、解决方法

#### 四、教学策略
- （一）教学流程图：文字流程图，包含课前、课中、课后三阶段
- （二）教学方法选择：表格形式，包含教学方法、应用环节、预期效果
- （三）教学资源准备：表格形式，包含资源类型、资源名称、对应方法、使用环节、资源内容说明

#### 五、教学活动安排
- （一）课前阶段：表格形式，包含教学环节、教学内容、教师活动、学生活动、设计意图（思政效果用*标注）
- （二）课中阶段：表格形式，包含教学环节（时间分配）、教学内容、教师活动、学生活动、设计意图（思政效果用*标注）
- （三）课后阶段：表格形式，包含教学环节、教学内容、教师活动、学生活动、设计意图（思政效果用*标注）

#### 六、配套教学资源
根据教学方法生成完整资源，包含：
- 教学案例：完整案例（背景、任务、问题分析、解决方案）
- 小组讨论材料：讨论主题、讨论问题、分组规则、讨论流程、成果呈现、评价标准
- 标准模板：根据需要提供相应模板（如提示词模板、预算模板等）
- 评价框架：评价量表或评价标准
- 其他资源：根据课程类型补充必要资源

#### 七、配套习题
每个布鲁姆层次至少包含2种题型，总习题数量不少于10题：
- **记忆层面**：单选题、判断题
- **理解层面**：单选题、判断题
- **应用层面**：多选题、简答题
- **分析层面**：多选题、案例分析题
- **评价层面**：多选题、简答题
- **创造层面**：方案设计题、案例分析题

每道题包含：题目、答案、解析、对应目标

#### 八、综合评价量表
表格形式，包含：评价维度、评价标准、分值、得分
- 任务成果维度（如预算方案设计）：重点突出，分值占比最高
- 过程表现维度（如小组讨论参与度、汇报表现）
- 素养维度（如职业态度、协作能力）
- 总分：通常为100分或120分

#### 九、评量标准
表格形式，横向为质量维度（知识、能力、素养），纵向为质量等级（A优、B良、C中）
- 每条标准使用"布鲁姆动词+评量对象"的表述方式
- 标尽可能可测可量，与教学活动或习题保持对应
- 素养维度可标注思政效果（用*标注）

**一致性检查清单**：
- [ ] 教学方法与教学资源一一对应
- [ ] 设计意图中的思政效果用星号标注
- [ ] 每个布鲁姆层次的习题至少包含2种题型
- [ ] 评量标准与教学活动和习题保持对应

## 注意事项
- 目标可测性：每个教学目标都必须是可观察、可测量的，避免使用模糊表述如"了解"、"掌握"，应使用具体动词如"复述"、"解释"、"设计"
- 动词规范：知识目标直接使用布鲁姆分级动词开头，不使用"能够"、"可以"等辅助词
- 一致性原则：三维目标、教学重点难点、教学策略、教学活动安排、教学案例、配套习题、综合评价量表、评量标准必须保持高度一致，确保每个目标都有对应的教学环节、习题和评价指标
- 任务导向：教学案例、评价量表和教学活动应突出任务成果，体现职业岗位需求
- 时间控制：课中教学活动每个环节时间最少5分钟，最长不超过30分钟
- 灵活调整：根据不同课程特点和学生层次，灵活调整布鲁姆认知层次的选择、教学环节安排和评价维度的设置
- 分值分配：综合评价量表中，任务成果维度（如会议日程设计）的分值应占比最高，体现OBE以成果为导向的理念
- 评量标准对应：评量标准应与教学活动和习题形成对应关系，确保评价的一致性
