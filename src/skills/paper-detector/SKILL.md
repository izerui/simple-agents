# 论文检测器

AI驱动的学术论文检测工具，生成专业的剽窃和AIGC检测报告。

## 使用时机

当用户需要以下功能时使用此技能：
- 检测论文相似度或剽窃
- 检测论文中的AI生成内容（AIGC）
- 生成专业检测报告
- 学术诚信、引用分析或原创性检查

## 快速开始

1. **输入**：用户提供论文文件（.md）
2. **处理**：执行12步检测工作流程
3. **输出**：生成综合检测报告

## 检测工作流程（12步）

```
步骤1:  文档读取与预处理    → 提取基本信息
步骤2:  章节提取            → 识别论文结构
步骤3:  文本分割            → 生成检测片段（100-2000字）
步骤4:  引用识别            → 识别文献引用标记
步骤5:  相似度检测（核心）  → 分析表达、内容、结构相似度
步骤6:  AIGC检测（核心）    → 检测AI生成内容比例
步骤7:  剽窃类型检测        → 识别4种剽窃类型
步骤8:  过度引用检测        → 检测引用密度
步骤9:  相似内容检测        → 检测重复的表格/公式
步骤10: 增强AI检测[可选]   → 词汇密度、突发性、改写攻击
步骤11: 统计指标计算       → 计算所有指标
步骤12: 报告生成           → 生成专业报告
```

### 检测架构

**混合检测模式**：
- **规则检测**：快速预处理，基准数据
- **Claude AI深度分析**：语义理解，专业分析
- **AI覆盖规则**：当Claude AI置信度 > 0.6时，AI结果覆盖规则检测结果

**核心原则**：
- ✅ **完整性**：所有12步必须执行
- ✅ **AI驱动**：Claude AI分析优先
- ✅ **可追溯性**：每步都有清晰的输入输出
- ✅ **可验证性**：生成详细检测报告

## 核心检测步骤

### 步骤1: 文档读取与预处理

**输入**：论文文件路径（.md）

**输出**：
- `content`：完整文档内容
- `paper_info`：基本信息（标题、作者、字数等）

**要求**：
- 准确提取文本（处理不同文件格式）
- 统计字数（知网标准：排除空格和换行符）
- 识别段落数和基本结构

### 步骤2: 章节提取

识别以下章节：
- 摘要、关键词
- 引言/文献综述
- 研究方法
- 结果与讨论
- 结论
- 参考文献
- 致谢

### 步骤3: 文本分割

**分割规则**：
- 最小片段长度：100字
- 最大片段长度：2000字
- 按自然段落分割
- 保留章节位置信息

**输出格式**：
```
片段1: 摘要_1, 256字
片段2: 引言_1, 458字
...
```

### 步骤4: 引用识别

**识别格式**：
- `[数字]` 格式：如 [1]、[2-3]
- `(作者, 年份)` 格式：如 (Smith, 2020)

**输出**：
- `citations`：引用列表
- `cleaned_content`：去除引用后的内容

### 步骤5: 相似度检测（核心）

**分析维度**：

1. **表达相似度**
   - 与常见学术表达对比
   - 识别通用句式
   - 检测过度使用的连接词

2. **内容相似度**
   - 专业术语密度
   - 引用标记分析
   - 数据陈述方式

3. **结构相似度**
   - 段落组织结构
   - 论证逻辑模式
   - 句子排列方式

**相似度等级**：
| 相似度 | 等级 | 说明 |
|--------|------|------|
| ≥50% | 高 | 与现有文献高度相似 |
| 40-50% | 中 | 有明显借鉴痕迹 |
| 30-40% | 低 | 部分表达类似 |
| <30% | 正常 | 相对原创 |

### 步骤6: AIGC检测（核心）

**分析维度**：

1. **语言特征**
   - 句式规整度（长度变化、多样性）
   - 词汇丰富度
   - 表达自然度

2. **内容特征**
   - 个人观点识别
   - 具体案例分析
   - 逻辑连贯性

3. **结构特征**
   - 段落组织
   - 逻辑连接
   - 论证深度

**AIGC风险等级**：
| 生成率 | 风险等级 | 说明 |
|--------|----------|------|
| ≥50% | 极高 | AI生成概率很高 |
| 30-50% | 高 | AI生成概率较高 |
| 15-30% | 中 | 有明显AI特征 |
| 5-15% | 低 | 有一定AI特征 |
| <5% | 正常 | AI生成概率极低 |

### 步骤7: 剽窃类型检测

**4种剽窃类型**：

1. **观点剽窃**（30-40%相似度）
   - 论点结构和逻辑相似

2. **文字表述剽窃**（40-60%相似度）
   - 文字高度相似，可能直接复制或简单改写

3. **整体剽窃**（≥60%相似度且>300字）
   - 大段内容高度相似

4. **过度引用**（>3个引用/100字）
   - 引用密度过高

### 步骤8-11: 其他检测与指标

详见 [检测流程规范](references/workflow-spec.md)：
- 过度引用检测
- 相似内容检测（表格、公式）
- 增强AI检测（可选）
- 统计指标计算（43项核心指标）

### 步骤12: 报告生成

生成包含9个部分的报告：

1. **基本信息**：标题、作者、关键词、检测时间、送检时间、报告编号、字数
2. **检测摘要**：
   - 知网指标（5项）：总文字复制比、去除引用文献复制比、去除本人已发表文献复制比、去除已发表文献复制比、最大单篇文字复制比
   - 维普指标（3项）：引用率、复制率、原创率
   - AIGC指标：总体生成率、风险等级
3. **字数统计**：总字数、片段数、重复字数、最大单段复制字数及位置
4. **相似度分布**：
   - 相似度范围统计表（≥50%、40%-50%、30%-40%、<30%）
   - 相似来源类型统计（学位论文、期刊论文、会议论文、图书资源、网络资源）
5. **剽窃类型检测**：4种剽窃类型分析
6. **各章节复制比**：各章节（摘要、引言、文献综述、研究方法、实验结果、讨论、结论）的复制比统计表
7. **相似片段详情**：相似片段详细列表（位置、相似度、字数、来源类型）
8. **AIGC检测分析**：总体生成率、章节AIGC生成率统计表、高风险片段详情
9. **相似内容检测**：相似表格和公式统计

## 输出格式

检测报告应以Markdown格式生成，包含清晰的章节和详细分析。

## 重要说明

### 检测质量保证

1. **完整性**：所有12步必须按顺序执行
2. **AI驱动**：Claude AI分析结果覆盖规则检测结果（置信度>0.6时）
3. **可追溯性**：每步都有清晰的输入输出
4. **一致性**：所有检测项遵循统一标准

### 分析原则

1. **语义优先**：参考库只是辅助，你的语义理解才是关键
2. **上下文分析**：在段落上下文中进行判断
3. **整体评估**：关注整体质量，而非个别段落
4. **专业判断**：对有争议的内容提供专业分析
5. **客观公正**：提供客观数据和分析，不判断论文是否"合格"

### 理论限制

1. **接受局限性**：理解检测并非完美
2. **保守判断**：设置较高的检测阈值以避免误报
3. **多方法结合**：使用多种检测方法
4. **人工验证**：重要情况需要人工验证

## 参考标准

- **本科毕业论文**：总文字复制比 ≤ 30%
- **硕士毕业论文**：总文字复制比 ≤ 20%
- **博士毕业论文**：总文字复制比 ≤ 15%
- **期刊投稿**：总文字复制比 ≤ 15%
- **AIGC生成率**：一般 ≤ 10%

## 常见问题

### 边缘情况

- **极短论文**（<500字）：警告统计显著性有限
- **非标准格式**：可能需要预处理
- **混合语言**：分别检测每种语言
- **代码/数学内容多**：调整检测阈值

### 错误处理

如果任何步骤失败：
1. 记录详细的错误信息
2. 尽可能继续下一步
3. 在最终报告中包含错误信息
4. 建议人工审查
