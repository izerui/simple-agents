# 论文检测器（校准版）

AI驱动的学术论文检测工具，生成专业的剽窃和AIGC检测报告。

> **⚠️ 重要定位声明**
> 本技能是**论文检测诊断工具**，而非论文写作指导工具。
> - ✅ **检测功能**：查重、AIGC率检测、相似度分析、剽窃类型识别
> - ❌ **不做**：论文写作指导、内容优化建议、修改方案推荐、质量改进建议
> - 🎯 **核心目标**：提供客观数据和检测结果，供用户参考，**不提供任何修改或优化建议**

> **📊 检测方法说明（v2.0）**
> 本技能采用AI语义分析进行论文检测，并通过对比分析优化了检测参数。
> - ✅ **优化系数**：基于实际对比数据调整（知网查重率 × 0.35 + 2.5%）
> - ✅ **权重调整**：表达相似度70%，语义15%，结构10%，数据5%
> - ✅ **阈值提高**：高相似度≥70%，中相似度50-70%
> - ⚠️ **仅供参考**：本结果为AI辅助分析，不能替代知网、维普官方检测

---

## 使用时机

当用户需要以下功能时使用此技能：
- 检测论文相似度或剽窃
- 检测论文中的AI生成内容（AIGC）
- 生成专业检测报告
- 学术诚信、引用分析或原创性检查

---

## 快速开始

1. **输入**：用户提供论文文件（支持 .md、.txt 或直接粘贴文本）
2. **处理**：AI执行12步检测工作流程（以43项指标为主线）
3. **输出**：生成包含43项指标的综合检测报告

> **🔧 重要说明**：本技能采用**纯AI驱动模式**
> - ✅ AI按段落流式读取并分析，无需预先处理
> - ❌ 不使用任何Python脚本、execute或外部工具
> - ✅ 基于AI的语言理解能力进行专业分析

---

## 检测工作流程（12步）

```
步骤1:  文档读取与预处理    → 提取基础信息（指标13-16）
步骤2:  章节提取            → 识别论文结构
步骤3:  按段落读取内容      → 逐段流式读取分析
步骤4:  引用指标检测        → 检测引用率、自引率、他引率（指标6、10-11）
步骤5:  相似度指标检测      → 检测总文字复制比等相似度指标（指标1-5、21-26、41）
步骤6:  AIGC指标检测        → 检测AIGC生成率和各章节占比（指标27-40）
步骤7:  剽窃类型检测        → 识别4种剽窃类型
步骤8:  复写率检测          → 检测复写率（指标9）
步骤9:  术语指标检测        → 检测专业术语和去除术语相似率（指标19-20）
步骤10: 相似内容检测        → 检测表格、公式、图片
步骤11: 指标汇总计算        → 计算43项指标（指标12、17-18、42-43）
步骤12: 生成报告            → 输出完整检测报告
```

## 核心检测步骤

### 步骤1: 文档读取与预处理

**输入**：论文文件路径（.md）

**输出**：
- `content`：完整文档内容
- `paper_info`：基本信息（标题、作者、字数等）

**检测指标**：
- **论文字符数**（指标13）：按知网标准统计
- **论文页数**（指标14）：根据字符数和表格图片估算
- **表格数量**（指标15）：统计Markdown表格和引用标记
- **图片数量**（指标16）：统计图片标记和引用标记

**要求**：
- 准确提取文本（处理不同文件格式）
- 统计字数（知网标准：排除空格和换行符）
- 识别段落数和基本结构

---

### 步骤2: 章节提取

**目标**：识别论文结构

**识别章节**：
- 摘要、关键词
- 引言/绪论
- 文献综述
- 研究方法/主要研究内容及其方法
- 结果与分析
- 讨论
- 结论
- 参考文献（排除，不检测）
- 致谢（排除，不检测）

**输出**：
- `sections`：章节字典（章节名称、位置、字数）
- `detection_scope`：检测范围列表
- `excluded`：排除部分列表

---

### 步骤3: 按段落读取内容

**流式分析模式**：
- 按自然段落顺序处理整个文档
- 每次读取一个段落或逻辑单元（100-2000字符）
- 每读取一个段落，立即进行分析（相似度、AIGC检测、引用等）
- 累积所有段落的检测结果

**读取规则**：
- 按自然段落边界读取
- 每次读取一个完整的段落或逻辑单元
- 记录段落的章节位置和字数
- 保持分析过程的连贯性

**分析流程**：
```
读取段落1 → 分析（相似度/AIGC/引用）→ 记录结果
读取段落2 → 分析（相似度/AIGC/引用）→ 记录结果
...
累积所有结果 → 生成统计报告
```

---

### 步骤4: 引用指标检测

**检测指标**：
- **引用率**（指标6）：带引用标记字数 / 总字数 × 100%
- **自引率**（指标10）：自引字数 / 总引用字数 × 100%
- **他引率**（指标11）：他引字数 / 总引用字数 × 100% = 100% - 自引率

**识别格式**：
- `[数字]` 格式：如 [1]、[2-3]
- `(作者, 年份)` 格式：如 (Smith, 2020)

**检测方法**：
1. 识别所有引用标记
2. 提取作者姓名（识别自引）
3. 统计引用字数和密度

**输出格式**：
```json
{
  "引用率": "22.5%",
  "引用数量": 35,
  "自引率": "15.8%",
  "他引率": "84.2%"
}
```

---

### 步骤5: 相似度指标检测

**检测指标**：
- **总文字复制比**（指标1）：总相似字数 / 总字数 × 100%
- **去除引用文献复制比**（指标2）：(总相似字数-引用字数) / 总字数 × 100%
- **去除本人文献复制比**（指标3）：(总相似字数-自引字数) / 总字数 × 100%
- **单篇最大文字复制比**（指标4）：max(各文献相似字数) / 总字数 × 100%
- **重复字符数**（指标5）：sum(各相似片段字数)
- **来源相似度**（指标21-26）：期刊、综合、外文、博硕、互联网、自建库相似度
- **单篇最大重复字符数**（指标41）：max(各文献来源相似字数)

**检测方法**（4维度相似度分析 - 已校准）：
1. **表达相似度**（70%权重）：检测文字复制、句子结构相似性
2. **语义相似度**（15%权重）：分析论证逻辑、观点表达相似性
3. **结构相似度**（10%权重）：分析段落组织、论证框架相似性
4. **数据/案例相似度**（5%权重）：识别数据引用、案例复用

**综合相似度计算**（校准后）：
```
综合相似度 = 表达相似度×0.7 + 语义相似度×0.15 + 结构相似度×0.10 + 数据相似度×0.05
```

**来源类型判断**：
- 期刊论文：ISSN、卷期号、J标记
- 学位论文：[D]、博士、硕士标记
- 图书：[M]标记
- 外文文献：非中文内容
- 网络资源：URL、访问日期
- 自建库：内部特征

**相似度等级**（校准后）：
| 相似度 | 等级 | 说明 |
|--------|------|------|
| ≥70% | 高 | 与现有文献高度相似 |
| 50-70% | 中 | 有明显借鉴痕迹 |
| 30-50% | 低 | 部分表达类似 |
| <30% | 正常 | 相对原创 |

**优化说明**：
- 原阈值（高≥50%、中40-50%）经对比分析发现存在过度标记问题
- 调整后阈值基于实际数据优化，旨在减少误判
- 提高检测结果的参考价值

---

### 步骤6: AIGC指标检测

**检测指标**：
- **全文疑似AIGC生成率**（指标27）：sum(各片段AIGC概率×片段字数) / 总字数 × 100%
- **全文人写概率**（指标28）：100% - AIGC生成率
- **各章节AI/人工占比**（指标29-40）：6个章节的AI占比和人工占比

**检测方法**（3维度AIGC分析）：
1. **语言特征分析**（40%权重）
   - 句子规律性：分析句子长度变化、多样性
   - 词汇丰富度：检测词汇多样性和个性化
   - 表达自然度：识别过于规律、模板化表达

2. **内容特征分析**（35%权重）
   - 个人观点：检测独特见解和观点
   - 具体案例分析：判断是否有具体研究数据、案例支撑
   - 逻辑连贯性：分析论证逻辑的自然流畅

3. **结构特征分析**（25%权重）
   - 段落组织：分析自然度和个性化
   - 逻辑连接：检测逻辑连接词的自然度
   - 论证深度：评估深度和个人思考痕迹

**综合AIGC概率计算**：
```
AIGC概率 = 语言特征×0.4 + 内容特征×0.35 + 结构特征×0.25
```

**风险等级**：
| 生成率 | 风险等级 | 说明 |
|--------|----------|------|
| ≥50% | 极高 | AI生成概率很高 |
| 30-50% | 高 | AI生成概率较高 |
| 15-30% | 中 | 有明显AI特征 |
| 5-15% | 低 | 有一定AI特征 |
| <5% | 正常 | AI生成概率极低 |

---

### 步骤7: 剽窃类型检测

**检测4种剽窃类型**（基于校准后阈值）：

1. **疑似观点抄袭**（30-50%相似度）
   - 特征：论证结构、逻辑相似
   - 判定：结构相似度≥50% 且 语义相似度≥50%

2. **疑似文字抄袭**（50-70%相似度）
   - 特征：文字高度相似，缺乏原创性改写
   - 判定：表达相似度≥50% 且 相似度在50-70%

3. **疑似整体抄袭**（≥70%相似度且>300字符）
   - 特征：大段内容高度相似
   - 判定：综合相似度≥70% 且 相似字数>300

4. **过度引用**（>3个引用/100字）
   - 特征：引用密度过高
   - 判定：引用密度>3/100字符

---

### 步骤8: 复写率检测

**检测指标**：
- **复写率**（指标9）：复写相似字数 / 总字数 × 100%

**检测方法**：
识别文字不同但结构相似的片段：
1. 结构相似度分析：段落组织、论证逻辑
2. 语义相似度分析：核心观点、推理路径
3. 表达差异度分析：词汇替换、句式变化

**判定标准**：
| 结构相似度 | 语义相似度 | 表达差异度 | 判定 |
|-----------|-----------|-----------|------|
| ≥70% | ≥70% | 任意 | 高复写 |
| 50-70% | 50-70% | 任意 | 中复写 |
| 30-50% | 30-50% | 任意 | 低复写 |

---

### 步骤9: 术语指标检测

**检测指标**：
- **专业术语**（指标19）：术语总数、术语密度
- **去除专业术语相似率**（指标20）：(总相似字数-术语字数) / 总字数 × 100%

**检测方法**：
1. 识别专业术语（基于领域知识库）
2. 统计术语出现频率和密度
3. 术语分类（方法术语、理论术语、技术术语）
4. 计算去除术语后的相似度

---

### 步骤10: 相似内容检测

**检测内容**：
- 疑似相似表格数量
- 疑似相似公式数量
- 图片类型分布

**检测方法**：
1. 识别Markdown表格格式和表格引用标记
2. 识别图片标记和图片引用标记
3. 统计数量和类型分布

---

### 步骤11: 指标汇总计算

**计算所有43项指标的综合结果**：

**维普指标计算**（已校准）：
- **全文总相似比**（指标12）= 总文字复制比×1.0 + 复写率×0.5 + 引用率×0.3
- **去除本人引用相似率**（指标42）= (总相似字数-自引相似字数) / 总字数 × 100%
- **自写率**（指标43）= 100% - 校准后总文字复制比

**优化公式**：
```
调整后知网查重率 = AI检测值 × 0.35 + 2.5%
调整后维普自写率 = 100% - (AI检测复制率 × 0.35 + 2.5%)
```

**优化说明**：
- 基于同学生对比分析（平均差异+14.34%）
- 优化系数0.35，基础偏移+2.5%
- 旨在减少AI语义分析与真实检测结果之间的偏差
- 详见 [calibration-guide.md](references/calibration-guide.md)

**基础统计计算**：
- **总相似片段**（指标17）= count(相似度≥30%片段)
- **检测范围**（指标18）：已检测章节列表

**验证**：
- ✅ 所有43项指标计算正确
- ✅ 指标逻辑一致
- ✅ 百分比关系验证（引用率 + 复制率 + 原创率 ≈ 100%）

---

### 步骤12: 生成报告

**生成包含10个部分的检测报告**，详见 [report-template.md](references/report-template.md)

报告结构：
1. **基本信息**：标题、作者、字数等
2. **检测摘要**：知网5项+维普7项+AIGC2项+补充2项
3. **论文基础统计**：字数、页数、表格、图片等
4. **相似度来源分布**：6项来源统计
5. **各章节指标统计**：各章节复制比
6. **AIGC检测详细分析**：13项AIGC指标
7. **专业术语分析**：术语统计
8. **剽窃类型检测**：4种剽窃类型
9. **相似片段详情**：高中低相似片段
10. **相似内容检测**：表格、公式、图片统计

## 重要说明

### 检测质量保证

1. **纯AI驱动**：所有检测步骤由Claude AI完成，不使用脚本或execute
2. **完整性**：所有12步必须按顺序执行
3. **可追溯性**：每步都有清晰的输入输出
4. **一致性**：所有检测项遵循统一标准
5. **优化机制**：所有检测结果应用优化系数，减少AI语义分析的偏差

### 优化质量保证

1. **自动优化**：所有相似度指标自动应用优化公式
2. **双值输出**：同时输出原始AI值和调整后值
3. **置信度标注**：标注检测结果的置信度等级
4. **免责声明**：明确说明结果仅供参考，不能替代官方检测

### 分析原则

1. **检测诊断，不提供方案**：仅输出检测结果和数据，**绝不提供**修改建议、优化方案、改进措施
2. **语义优先**：AI的语义理解是关键
3. **上下文分析**：在段落上下文中进行判断
4. **整体评估**：关注整体质量，而非个别段落
5. **专业判断**：对有争议的内容提供专业分析
6. **客观公正**：提供客观数据和分析，不判断论文是否"合格"
7. **保持边界**：检测报告**只包含**：
   - ✅ 检测数据（相似度、AIGC率、引用率等）
   - ✅ 统计分析（分布统计、类型识别等）
   - ✅ 风险等级判定
   - ❌ **不包含**任何"建议"、"推荐"、"应该"、"可以"等指导性内容

## 参考标准

- **本科毕业论文**：总文字复制比 ≤ 30%
- **硕士毕业论文**：总文字复制比 ≤ 20%
- **博士毕业论文**：总文字复制比 ≤ 15%
- **期刊投稿**：总文字复制比 ≤ 15%
- **AIGC生成率**：一般 ≤ 10%

**调整后风险等级**：
- 高风险：调整后查重率 ≥ 50%
- 中风险：调整后查重率 30-50%
- 低风险：调整后查重率 15-30%
- 正常：调整后查重率 < 15%

详细标准见 [standards.md](references/standards.md)

## 43项核心指标

### 指标分类

| 分类 | 数量 | 指标 |
|------|------|------|
| 知网核心指标 | 5项 | 总文字复制比、去除引用文献复制比、去除本人文献复制比、单篇最大文字复制比、重复字符数 |
| 维普核心指标 | 7项 | 引用率、复制率、原创率、复写率、自引率、他引率、全文总相似比 |
| 论文基础统计 | 8项 | 论文字符数、论文页数、表格数量、图片数量、总相似片段、检测范围、专业术语、去除专业术语相似率 |
| 相似度来源统计 | 6项 | 期刊、综合、外文、博硕、互联网、自建库相似度 |
| AIGC检测指标 | 13项 | 全文AIGC率、全文人写率、6章节的AI/人工占比 |
| 其他补充指标 | 4项 | 单篇最大重复字符数、去除本人引用相似率、自写率、复制率 |

详细指标检测方法见 [metrics-detection.md](references/metrics-detection.md)

## 常见问题

### 边缘情况

- **极短论文**（<500字）：警告统计显著性有限
- **非标准格式**：可能需要预处理
- **混合语言**：分别检测每种语言
- **代码/数学内容多**：调整检测阈值

### 错误处理

如果任何步骤失败：
1. 记录详细的错误信息
2. 尽可能继续下一步
3. 在最终报告中包含错误信息
4. 建议人工审查
