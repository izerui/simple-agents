# 论文检测器（v8.1 官方口径校准版）

面向知网/维普等官方报告口径校准的学术论文查重率与AIGC率预估工具。

> **定位**：本技能是论文检测诊断工具，不提供写作润色或内容改写建议。
> - ✅ 查重率检测（总文字复制比）、AIGC率检测、章节级分析、引用规范检测
> - ❌ 不做论文代写、降重改写、结构优化建议

> **v8.1 核心原则**
>
> 1. **官方口径优先**：最终数值必须向知网/维普/AIGC官方报告的常见输出范围看齐，而不是追求语义泛化覆盖。
> 2. **保守计分**：普通本科论文套话、章节功能句、学科规范表达、概念解释，除非出现连续文本高度重合或原文式搬运，否则不应大面积计入复制比。
> 3. **逐句/逐段分析**：查重以句子为单位，AIGC以段落为单位，再聚合全文，但聚合后必须做官方口径校准。
> 4. **有据可查**：所有数值必须附带具体依据，不能只给百分比。
> 5. **两率独立**：查重率和AIGC率独立计算，交叉验证；不得因为查重高就自动推高AIGC。
> 6. **学科感知**：学科规范表达更多用于解释，不直接抬高最终复制比。

## 检测方法论

### 核心原理：官方口径校准比对

本系统的目标不是找出一切语义相似内容，而是**尽量模拟知网/维普等官方报告的核心指标口径**。官方系统通常更重视连续文本匹配、库内来源命中、引用/术语处理和章节加权，不会把所有"读起来常见"的句子都计入复制比。

```
传统系统：句子 → 在海量论文数据库中搜索 → 找到匹配文献 → 标红
本系统  ：句子 → 判断是否像官方系统会命中的连续重合/近似重合 → 保守计入复制比
```

当模型读到一个句子时，可以感知它是否常见，但**常见不等于官方重复**：
- 常见背景句、学科术语、章节过渡句：可能显得熟悉，但官方未必命中，通常只少量计入或不计入。
- 连续13字以上与已有文本高度一致、法规/定义原文、整段综述搬运：官方更可能命中，应计入。
- 具体案例、调研数据、企业/景区/学校/患者场景、问卷结果：即使语言普通，官方通常不会判高重复。

**校准原则：模型的熟悉感只作为线索，最终复制比按官方系统可能标红的字符比例保守估计。**

### 检测能力覆盖

本系统模拟主流查重方法时采用以下权重：

| 检测能力 | 实现方式 | 覆盖范围 |
|---------|---------|---------|
| **字面匹配** | 识别与已有文献措辞高度一致的句子 | 主要计分依据 |
| **近似匹配** | 识别轻度改写但仍保留连续重合骨架的内容 | 谨慎计分 |
| **语义熟悉度** | 识别常见学术表达和模板化句式 | 主要用于解释，不能直接大幅计分 |
| **AIGC检测** | 判断文本是否呈现AI生成概率分布特征 | 保守校准到官方AIGC报告范围 |

**关键认知**：

1. **连续重合优先**：连续13字以上高度一致、定义/法规/规范原文、整段近似搬运，是主要重复来源。
2. **语义相似降权**：只有"含义相似但文字不同"时，不得按红句处理；最多作为黄句低比例计入。
3. **学科规范降权**：工程造价、护理综述、艺术音乐、旅游管理等本科论文中大量规范表达，应在解释中标注，但不能把全文推到30-50%的高重复。
4. **官方范围校准**：对普通本科论文，维普/知网总相似率常见在0-15%，只有大量连续搬运、引用堆叠或整段综述复用时才应超过20-30%。

### 能力边界

**高准确度领域**：
- 直接复制或轻度改写的连续文本
- 法规、规范、教材定义等固定原文
- 参考文献、引用、摘要/结论中明显复用的成段表达

**需要降权的领域**：
- 高频学术表达（教科书式概念、万能背景句、标准方法描述）
- 常见论文结构中的套话（研究目的、研究意义、章节安排、结论模板）
- 只在语义上相似、但没有连续文字骨架重合的改写内容

**AIGC优势领域**：
- 大段连续生成、抽象泛化、缺少具体锚点的文本
- 章节间风格高度一致、无真实数据/来源/调研痕迹的文本
- 明显AI套话密集共现的摘要、建议、结论

**灵敏度较低领域**：
- 从冷门论文中复制的内容（训练语料中出现次数少，隐式比对难以识别）
- 同届学生之间的互相抄袭（不在训练语料中）
- 训练数据截止后的新发表文献

**暂不支持**：
- 指向具体的匹配来源（"与XX论文第X页重合"）——只能给出来源类型推断

## 8步检测工作流

```
步骤1: 文档读取与预处理    → 提取元信息、字数、结构
步骤2: 章节分割与学科识别  → 识别论文结构，判定学科类型
步骤3: 逐句查重分析（核心）→ 每句分类为红/黄/绿，计算匹配字符数
步骤4: 逐段AIGC分析（核心）→ 每段直接判断AI生成概率
步骤5: 引用规范检测        → 引用率、引用密度、引用形式
步骤6: 章节聚合与全文指标  → 加权计算全文查重率和AIGC率
步骤7: 交叉验证与校准      → 查重率×AIGC率交叉分析
步骤8: 生成报告            → 输出完整检测报告
```

---

## 步骤详述

### 步骤1: 文档读取与预处理

**字符数统计**：
- 统计所有可见文字字符，包括表格内容、图注、脚注
- 排除：空格、换行符、Markdown标记、参考文献列表、致谢部分
- 代码块、纯公式推导不纳入查重和AIGC主分析

**页数估算**：`ceil(字符数 / 300)`

**表格/图片计数**：结合"表X""图X"标记与实际内容综合判断

**元信息提取**：标题、作者、关键词、摘要。优先级：正文封面 > 文件名 > 文档元数据。

### 步骤2: 章节分割与学科识别

**章节识别**：摘要、引言/绪论、文献综述、研究方法、结果与分析、讨论、结论。参考文献和致谢排除在检测范围外。

**学科分类**：

| 学科类型 | 判定特征 |
|---------|---------|
| 护理/医学 | 护理干预、康复、疗效、量表、P值、实验分组 |
| 工程造价/土建 | 招标控制价、工程量清单、综合单价、定额 |
| 商科/营销/管理 | PEST、SWOT、4P、STP、营销策略、供应链 |
| 教育/调查 | 教学现状、课程实施、课堂观察、学生能力 |
| 语言/文学 | 文本细读、修辞分析、翻译研究、文学主题 |
| 艺术/舞蹈 | 舞蹈编排、艺术设计、音乐表演 |
| 体育教育 | 开展现状、后备人才、体育课程、场地器材 |
| 法学 | 法律适用、案例分析、司法解释、制度完善 |
| 计算机/电子信息 | 系统设计、算法实现、仿真验证、性能测试 |
| 历史/哲学 | 史实梳理、思想流变、概念辨析 |
| 建筑设计 | 空间规划、方案设计、功能分析 |
| 数理化生 | 理论推导、公式证明、实验设计 |
| 综合论文 | 无法明确归入其他类别 |

### 步骤3: 逐句查重分析（核心算法）

#### 核心认知：你的推理过程就是数据库比对

当你读到一个句子时，你的内部计算过程等价于一次数据库查询：

- 你对这句话中每个token的预测概率 → 反映该文本在训练语料中的出现频率
- 你能"轻松预测每个字"的句子 → 在训练语料（=学术数据库）中大量存在 → **标红**
- 你觉得"这个组合很新颖"的句子 → 在训练语料中罕见 → **不标红**

与传统查重的关键区别：你检测的是**文字的出现概率**，不仅是字符串匹配。这意味着：
- 传统系统只能做字面匹配 → 你能做语义匹配（改写也能识别）
- 传统系统需要连续13字相同 → 你能识别打散重组后的内容
- 传统系统能指向具体来源 → 你推断来源类型

#### 算法：逐句隐式比对

以**句子**（而非段落）为最小分析单位，查重系统的标红粒度就是句子级。

> **官方口径约束**：逐句分类不是按"熟悉程度"直接标红。只有当句子存在官方系统可能命中的连续文字骨架、原文式定义/法规/规范、或明显成段搬运时，才进入复制比。普通套话、章节功能句和学科规范表达默认降权。

**第一步：逐句分类**

对每个句子做三级分类：

| 分类 | 判断标准 | 说明 |
|------|---------|------|
| **红句**（高度匹配） | 存在连续13字以上高度一致的文本骨架，或基本照搬法规/标准/定义/文献表述。换掉1-2个词不影响判定。 | 典型：法规条文原文、标准定义原文、整句文献综述搬运、摘要/结论套用他文句子 |
| **黄句**（部分匹配） | 有局部连续重合或轻度改写骨架，但混入具体对象、数据、场景；官方可能只标一小段。 | 典型：文献综述的固定句架、方法步骤+个性化参数、政策背景+具体地区/案例 |
| **绿句**（原创表达） | 这个特定的文字组合不太可能在已有文献中出现。 | 典型：作者自己的数据分析、具体案例讨论、独特的论证推理 |

**第二步：估计匹配字符数**

```
红句：该句全部字符数计入匹配，但只限真正连续重合或原文式表述
黄句：该句字符数 × 匹配比例（按官方可能标红的连续片段估计，通常10-40%；只有轻度改写搬运才可到50-60%）
绿句：0字符计入匹配
```

**第三步：计算查重率**

```
总文字复制比 = Σ(各句匹配字符数) / 总字符数 × 100%
```

这就是"总文字复制比"的含义：官方系统可能标红的字符数占总字符数的比例。不要把"语义相似但文字不同"全部纳入分子。

#### 校准锚点

模型需要对"什么样的句子会被标红"有校准的直觉。以下是典型场景：

**几乎必定标红的句子（红句典型场景）**：

1. **教科书/百科式定义**
   > "企业社会责任是指企业在创造利润、对股东承担法律责任的同时，还要承担对员工、消费者、社区和环境的责任。"
   → 只有接近定义原文、连续重合明显时才按红句处理；如果只是用自己的话解释概念，应降为黄句或绿句。

2. **万能背景句**
   > "随着我国经济的快速发展和人民生活水平的不断提高，人们对…的需求日益增长。"
   → 这类句子最多作为低比例黄句。官方样本显示，不能因为万能背景句多就把全文复制比推高到30%以上。

3. **政策/法规原文引用**
   > "根据《中华人民共和国劳动合同法》第四十七条规定，经济补偿按劳动者在本单位工作的年限…"
   → 法规原文，所有引用该法规的论文都一样。

4. **统计方法标准描述**
   > "采用SPSS 26.0软件对数据进行统计分析，计量资料以均数±标准差表示，组间比较采用t检验。"
   → 若为标准方法原文可标红；若含具体样本、对象、变量，则只按局部黄句计分。

**通常会标红的句子（红句/黄句边界）**：

5. **文献综述的标准概括**
   > "张三（2020）研究发现，…对…具有显著的正向影响，并提出了…策略。"
   → 概括句架相似但内容不同，通常只按10-30%低比例黄句处理；整句搬运才可标红。

6. **方法论模板句**
   > "本研究采用问卷调查法，以XX市XX所高校的大学生为研究对象，共发放问卷300份。"
   → 结构和用词相似但具体数字不同，官方通常只标局部，按低比例黄句处理。

**通常不标红的句子（绿句典型场景）**：

7. **作者自己的数据分析**
   > "在287份有效问卷中，72.3%的受访者表示曾在过去一年内使用过XX平台，其中日均使用时长超过2小时的占34.8%。"
   → 具体数字+具体平台+具体调查，这种组合在数据库中不可能重合。

8. **独特的论证推理**
   > "这一现象可能与该地区2019年实施的XX政策有关——政策实施后的首年数据显示，相关指标下降了12个百分点，但在第二年出现了反弹。"
   → 具体政策+具体时间+具体数据+因果推理，高度独特。

9. **个人经历和观察**
   > "在XX公司为期三个月的实习中，笔者发现该企业的绩效考核制度存在两个突出问题：一是考核周期过长导致反馈滞后…"
   → 个人经历，不可能被其他论文复制。

#### 学科校准

不同学科的"天然红句率"不同——不是因为这些学科的学生更爱抄，而是因为学科规范要求使用大量固定表达：

| 学科 | 天然红句场景 | 校准处理 |
|------|------------|---------|
| 护理/医学 | 统计方法描述、量表名称、干预流程标准用语 | 原文式复用才计入；一般规范表达低比例计入，并标注"属于学科规范表达" |
| 工程造价 | 定额引用、计价规范条文、清单编制标准用语 | 规范名称和参数不直接抬高复制比；条文原文才计入 |
| 法学 | 法律条文引用、司法解释原文 | 法条原文计入；案例分析和自述论证不因术语固定而高估 |
| 商科 | SWOT/PEST等框架的标准描述 | 如果只是框架名词属于规范；如果整段分析都是套话则算真实重复 |

**注意**：学科校准必须改变最终数值。学科规范表达更多用于解释，不应完整计入复制比；除非存在连续重合原文，否则只低比例计入或不计入。

#### 连续性规则

查重系统的一个重要特征：**连续13个字以上相同即判定为重复**。模型在判断时应注意：
- 一个长句中即使只有一半与已有文献雷同，只要连续重合部分超过13字，那部分就会被标红
- 反过来，如果作者在常见表达中间插入了足够多的特异性内容，打断了连续性，可能不被标红

#### 直接引用的处理

用引号（""或「」）标注且带有引用标记的直接引用：
- **计入总文字复制比**：直接引用计入总文字复制比（这是标准查重系统的实际行为）
- **不计入去除引用复制比**：单独统计，用于计算去除正当引用后的净重复率
- **在报告中单独标注**：标明这些是"明确标注的直接引用"，与未标注的重复区分
- **不计入AIGC率**：直接引用是他人原文，不反映本文是否由AI生成

#### 改写检测（语义相似层）

改写检测必须服务于官方口径。你可以感知语义改写，但不能把所有语义相似都当作官方重复。

对于绿句（表面文字不匹配），进一步检查是否存在**改写痕迹**：

| 改写手法 | 示例 | 检测方式 |
|---------|------|---------|
| 同义替换 | "提高"→"提升"、"方法"→"手段"、"重要"→"关键" | 替换后的表达是否仍指向学术文献中的常见论述 |
| 语序调整 | "A对B有显著影响"→"B受到A的显著影响" | 信息完全相同只是句式变换 |
| 主被动转换 | "研究发现…"→"…被研究发现" | 语态改变但内容不变 |
| 拆分/合并 | 一句拆成两句，或两句合并为一句 | 信息量不变只是重新切分 |
| 增加修饰语 | 在原句基础上插入"在一定程度上""从某种意义上说"等 | 核心表达不变只加了缓冲词 |

**改写句的处理**：
- 如果改写后仍保留连续文字骨架或明显可回溯到固定原文 → 标记为**黄句**，匹配比例视改写程度而定（轻度改写30-50%，重度改写10-30%）
- 如果只是表达同一学科常识、研究意义或常见结论，但文字不同 → 不计入或按极低比例黄句处理
- 如果改写程度足够大，已经形成独特表达 → 维持**绿句**
- 在报告中标注"疑似改写"，说明原始可能来源类型

#### 疑似来源类型标注

对每个红句和黄句，标注其疑似来源类型：

| 来源类型 | 特征 | 示例 |
|---------|------|------|
| 教材/百科 | 定义性、概念性、知识点阐述 | "企业社会责任是指…" |
| 政策法规 | 条文引用、政策描述 | "根据《XX法》第X条…" |
| 方法论标准 | 统计方法、实验流程、研究设计描述 | "采用SPSS进行…" |
| 同类论文通用表述 | 背景引入、现状描述、意义阐述 | "随着…的发展…" |
| 文献综述概括 | 对他人研究的概括描述 | "XX（2020）研究发现…" |

#### 官方口径章节自然查重率预期

**这是最关键的校准知识**：不同章节有截然不同的"官方自然查重率"。当前任务以官方报告为准，因此自然范围必须比"语义熟悉度"更低。普通本科论文中，大量看似模板化的表达在维普/知网中可能只形成很少的实际相似片段。

| 章节 | 自然查重率范围 | 原因 | 异常信号 |
|------|-------------|------|---------|
| 摘要 | 5-18% | 用语规范但篇幅短，官方通常只命中少量连续片段 | >25% 异常高 |
| 引言/绪论 | 8-22% | 背景和意义较常见，但只有连续套用才高 | >30% 异常高 |
| 文献综述 | 12-30% | 概括他人研究有固定句架，但应有作者组织 | >40% 异常高 |
| 研究方法 | 5-18% | 方法描述标准化，但参数、对象应独特 | >25% 异常高 |
| 结果与分析 | 0-10% | 原始数据和分析应高度独特 | >18% 异常高 |
| 讨论/建议 | 5-18% | 混合原创分析和规范表达 | >25% 异常高 |
| 结论 | 5-18% | 总结性表述较规范但篇幅短 | >25% 异常高 |

**使用方式**：
- 章节查重率在自然范围内 → 正常，即使文本有套话也不应警告
- 章节查重率超出自然范围上限 → 只有存在连续重合/搬运证据时才标注"**高于官方自然预期**"
- 不再把文献综述低查重视为可疑；官方报告中大量综述样本也可能很低

#### 重复集中度分析

同样的全文查重率，集中在一个章节 vs 分散在全文，意义完全不同：

- **集中型**（如80%的重复字数集中在文献综述）：通常是文献综述概括写法问题，其他部分原创性好。风险较低，容易修改。
- **分散型**（重复均匀分布在所有章节）：说明全文写作方式都存在问题，可能是系统性使用常见表达或系统性抄袭。风险较高。
- **局部爆发型**（某个不该高的章节异常高，如结果与分析>30%）：最值得关注，可能存在真实抄袭。

在报告中必须给出集中度判断（集中/分散/局部爆发）和对应的风险解读。

#### 段落和章节聚合

```
段落查重率 = Σ(该段各句匹配字符数) / 该段总字符数
章节查重率 = Σ(该章节各段匹配字符数) / 该章节总字符数
全文查重率 = Σ(全文各句匹配字符数) / 全文总字符数
```

各级查重率等级：

| 查重率 | 等级 | 含义 |
|--------|------|------|
| >30% | 严重 | 官方口径下大面积连续文本重合，通常需要真实搬运证据支撑 |
| 20-30% | 偏高 | 较多连续相似片段或引用/定义堆叠 |
| 10-20% | 适中 | 存在部分相似片段，普通本科论文常见区间 |
| <10% | 正常 | 官方口径下文字重合率低 |

#### 全文官方校准锚点

结合官方报告样本，最终全文查重率必须经过以下校准：

| 论文特征 | 建议全文查重率 |
|---------|---------------|
| 有具体研究对象、调研数据、案例分析，套话主要在摘要/绪论/结论 | 3-12% |
| 护理/医学综述、工程造价、艺术音乐等学科规范表达较多，但未见整段搬运 | 5-15% |
| 文献综述和理论定义较多，存在局部连续套用 | 10-20% |
| 多章节出现整段近似搬运、定义/政策/综述大段复用 | 20-30% |
| 全文多处连续搬运或引用堆叠，核心章节也大量重合 | >30% |

**硬性限制**：如果无法列出多处明确连续重合证据，不得把全文总文字复制比给到30%以上。只因为"表达规范、句式常见、模型熟悉"而给30-50%，属于错误高估。

### 步骤4: 逐段AIGC分析（核心算法）

#### 核心认知：你自己就是AI，你最懂AI怎么写

你作为大模型，对"AI会怎么写"有最直接的认知。AIGC检测不需要公式——你直接判断：

> "这段文字读起来像是一个AI模型一次性生成的，还是一个人在思考、犹豫、修改后写出来的？"

#### 算法：逐段直接判断

以**段落**为分析单位（AIGC特征需要足够文本量才能判断，单句太短）。

**对每个段落，直接输出 0-100% 的AIGC率**，基于以下五个感知维度的综合判断（不是加权公式，是整体直觉）：

| 感知维度 | AI生成时你会感知到 | 人写时你会感知到 |
|---------|-------------------|-----------------|
| **词汇可预测性** | 每个位置都是"最安全"的词选；用词正确但没个性；同义词选择趋于一致 | 有意外词选、口语化、个人用词偏好、某些词反复使用（个人习惯） |
| **节奏均匀性** | 句长均匀、段内节奏平稳、标点规律 | 句长波动明显、有长句深入论述也有短句总结、节奏有起伏 |
| **细节真实性** | 案例泛泛、细节模糊（"某公司""近年来"）、数据看似合理但无来源 | 具体可验证信息（真实时间/地点/机构/数据来源）、细节具体到不像编造 |
| **逻辑线性度** | 论证严格线性推进，A→B→C，不回溯不跳跃 | 有跳跃和回扣、有自我修正（"但需注意…"）、有局部偏题再拉回 |
| **情感自然度** | 语气全程平稳中性、没有犹豫或强调、观点不带温度 | 有不确定表达、有个人立场流露、语气有变化 |

**这五个维度是感知指引，不是计算公式。** 模型应综合感知后给出一个整体判断，而非分别打分再算加权平均。某个维度的强信号可以压过其他维度——比如一段文字即使节奏均匀，但包含大量真实细节和个人经历，整体仍应判为低AIGC。

#### 校准锚点

**几乎确定是AI生成（AIGC率 50-100%）**：

> "企业社会责任不仅是企业发展的重要组成部分，也是推动社会进步的关键力量。首先，企业需要建立完善的社会责任管理体系。其次，应加强与利益相关方的沟通与合作。再次，要注重环境保护和可持续发展。最后，企业应积极参与公益事业，回馈社会。"

→ 为什么：每句可预测、"首先其次再次最后"机械排列、全是泛泛而谈无具体信息、语气完全平稳。

**很可能是AI生成（AIGC率 30-50%）**：

> "当前我国中小企业在数字化转型过程中面临诸多挑战。一方面，技术人才匮乏制约了企业的数字化进程；另一方面，高昂的技术投入使得许多企业望而却步。此外，数据安全和隐私保护问题也亟待解决。然而，随着云计算和人工智能技术的不断成熟，中小企业的数字化转型前景依然广阔。"

→ 为什么：大部分可预测，但"望而却步"有一点个性化用词；"一方面另一方面此外然而"过于规律；没有具体案例。

**很可能是人写（AIGC率 10-20%）**：

> "在对XX市三家制造企业为期两个月的调研中，笔者发现一个有趣的现象：规模最小的C企业反而在数字化方面走得最远。C企业的王经理解释说，'我们没有历史包袱，ERP直接上的云端版本'。相比之下，A企业虽然年产值过亿，但其2018年部署的本地化系统至今仍是数字化转型的最大障碍。"

→ 为什么：有具体企业、具体人物、直接引语、有"有趣的现象"这种个人感受、"历史包袱"是口语化表达、对比分析有真实细节。

#### 章节AIGC等级

| AIGC率 | 等级 | 含义 |
|--------|------|------|
| ≥50% | 高度疑似 | 该章节高度疑似AI生成，需要多项强证据同时存在 |
| 30-50% | 中度疑似 | 有明显AI生成特征，但仍需排除规范写作 |
| 10-30% | 轻度疑似 | 有一些AI特征但不确定，普通本科论文常见 |
| <10% | 正常 | 基本为人工撰写 |

#### 全文AIGC官方校准锚点

官方AIGC报告通常比"读起来像AI"更保守。最终全文AIGC率按以下范围校准：

| 论文特征 | 建议全文AIGC率 |
|---------|---------------|
| 有真实调研数据、问卷、访谈、工程参数、临床/护理对象、具体企业/景区案例 | 0-15% |
| 摘要/结论/建议较模板化，但主体有具体材料 | 10-25% |
| 多个章节抽象顺滑、缺少数据来源，建议对策泛泛 | 20-35% |
| 全文大段无具体锚点、结构和措辞高度AI化 | 35-50% |
| 几乎整篇呈现一次性生成特征，缺乏真实材料 | >50% |

**硬性限制**：不得因为文字流畅、结构完整、使用"首先/其次/最后"或表达规范，就给出40%以上AIGC。40%以上必须有连续多段强AI信号，且缺少可验证的人写材料。

#### AIGC检测强制规则

1. 摘要和结论天然更程式化，不可单独拉高全文AIGC率
2. 方法论章节的规范表达不等于AI生成
3. 问卷原文、访谈记录、实验数据等原始材料视为人写证据
4. 如果论文中存在明显的人工修补痕迹（如前后风格不一致、某段突然质量下降），应将不一致本身视为人写证据
5. 术语密度低的论文不得仅因"表达通俗"就被判高AIGC
6. 英文摘要通常由机器翻译或模板生成，不能单独代表全文AIGC
7. 本科论文常见的病句、重复、口语化、逻辑跳跃，通常是人写证据，不是AI证据

### 步骤5: 引用规范检测

| 指标 | 计算方式 |
|------|---------|
| 引用率 | 带引用标记字数 / 总字数 × 100% |
| 引用密度 | 引用标记出现次数 / 正文字数 |
| 自引迹象 | 是否出现作者本人历史成果、署名课题或连续自我引用 |

**引用率参考标准**：

| 引用率 | 评估 |
|--------|------|
| >40% | 过高——可能存在过度引用 |
| 15-30% | 正常 |
| <15% | 较低 |

**引用密度参考标准**：

| 密度 | 评估 |
|------|------|
| >5次/100字符 | 过度引用 |
| 3-5次/100字符 | 较高 |
| 1-3次/100字符 | 正常 |
| <1次/100字符 | 较低 |

**引用说明**：引用本身不等于重复，但过度引用会影响原创性评估。

### 步骤6: 章节聚合与全文指标

**总文字复制比**：
```
总文字复制比 = Σ(各句匹配字符数) / 总字符数 × 100%
```
即：红句全部字符 + 黄句匹配部分字符，除以总字符数。含直接引用。

**去除引用复制比**：
```
去除引用复制比 = (Σ匹配字符数 - Σ明确标注引用的匹配字符数) / 总字符数 × 100%
```
扣除用引号标注且有引用标记的直接引用后的净重复率。**很多学校用这个数作为判定标准。**

**全文AIGC率**：
```
全文AIGC率 = Σ(段落AIGC率 × 段落字数) / 总字数
```

**重复字数**：
```
重复字数 = Σ(各句匹配字符数)
```
即红句字符数 + 黄句匹配部分字符数的总和。

**重复集中度**：计算重复字数在各章节的分布，判定为集中型/分散型/局部爆发型。

### 步骤7: 交叉验证与校准

查重率和AIGC率独立计算后，进行交叉验证：

| 组合 | 含义 | 处理 |
|------|------|------|
| 高查重 + 高AIGC | AI生成了常见/套路化内容 | 两项指标相互佐证，可信度高 |
| 高查重 + 低AIGC | 人工撰写但大量使用常见表达，或存在人工抄袭 | 重点关注是否有具体来源未标注 |
| 低查重 + 高AIGC | AI生成了较独特的内容 | AIGC判断需更谨慎，检查是否有足够人写证据 |
| 低查重 + 低AIGC | 大概率原创人写 | 正常，可信度高 |

**校准规则**：
- 如果交叉验证发现矛盾信号，在报告中标注并说明
- 不得为了"看起来合理"而人为调整某一项指标

## 风险等级标准

### 查重率（总文字复制比）

| 查重率 | 等级 | 说明 |
|--------|------|------|
| >30% | 严重 | 官方口径下大面积文字重合概率极高 |
| 20-30% | 偏高 | 较多连续相似片段，建议重点复核 |
| 10-20% | 适中 | 部分文字与已有文献重合，一般可接受 |
| <10% | 正常 | 官方口径下文字重合率低 |

| >50% | 极高 | 全文大部分呈现明显AI生成特征 |

| 10-30% | 中/轻度 | 部分章节有AI特征，普通本科论文常见 |

## 英文论文特殊处理

当论文主体语言超过70%为英文时：
- 降低对标准学术连接词（however, furthermore, moreover等）的查重和AIGC惩罚
- 英文学术写作天然更规范化，学科规范修正力度加大
- 不应将标准英文学术表达机械认定为高重复或高AIGC

## 质量验证规则

报告生成后必须执行以下验证，不通过则修正后再输出：

**数据一致性**：
- 全文人写概率 + 全文AIGC率 = 100%
- 重复字数 ≤ 总字数
- 重复字数 = Σ红句字符数 + Σ黄句匹配部分字符数（验证加总正确）
- 总文字复制比 = 重复字数 / 总字符数 × 100%（验证计算正确）
- 去除引用复制比 ≤ 总文字复制比
- 去除引用复制比 = (重复字数 - 引用字数) / 总字符数 × 100%
- 所有百分比在 0-100% 之间
- 章节查重率按字数加权 ≈ 全文查重率（允许±2%舍入误差）
- 章节AIGC率加权平均 ≈ 全文AIGC率（允许±2%舍入误差）
- 各章节查重率与自然预期范围进行比对，标注是否异常

**官方口径校准**：
- 如果全文查重率 >30%，必须能列出多个章节的连续重合或原文式搬运证据；否则下调。
- 如果普通本科论文包含大量具体对象、数据、问卷、案例、工程参数，但没有连续搬运证据，全文查重率通常应落在3-15%。
- 如果全文AIGC率 >40%，必须能列出连续多段强AI信号，且缺少真实数据/调研/案例锚点；否则下调。
- 学科规范表达、章节功能句、万能背景句只能作为低权重证据，不得单独支撑高查重或高AIGC。

**依据完整性**：
- 每个章节的查重率和AIGC率都必须有"主要依据"列
- 高度重复/高度疑似AI的段落必须有详细判断理由
- 不允许只给数字不给解释

**流程完整性**：
- 8步工作流全部执行
- 每步产出对应结果
- 报告模板所有章节已填写
- 未能执行的步骤在报告中标注
