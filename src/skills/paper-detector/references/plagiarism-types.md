# 剽窃类型分析

> 学术论文剽窃类型的详细分析。
> 返回主技能：[SKILL.md](../SKILL.md)

---

## 概述

剽窃检测识别学术写作中的不同类型学术不端行为。本文档提供了检测和分类剽窃类型的详细方法论。

---

## 4种剽窃类型

### 类型1：观点剽窃

**定义**：在未适当注明出处的情况下，挪用另一作品的基本观点、论点或逻辑结构，即使表达方式不同。

**相似度范围**：30-40%

**特征**：
- 相似的论点结构
- 平行的逻辑流程
- 相同的概念框架
- 不同的措辞但观点相同
- 缺少对原始来源的注明

**检测方法**：
1. 分析论点结构和逻辑
2. 比较概念框架
3. 识别相似的推理模式
4. 检查是否有适当的注明

**示例**：
```
原文：气候变化通过栖息地丧失、改变迁移模式和生态系统破坏
      影响生物多样性。

观点剽窃：全球变暖通过破坏栖息地、改变迁移路线和扰乱
           生态系统来影响物种多样性。
```

**分析**：
- 措辞不同（改写）
- 相同的三点结构
- 相同的概念框架
- 无原始出处引用

---

### 类型2：文字表述剽窃

**定义**：在未适当注明出处的情况下，复制或紧密改写另一来源的文本，或改写不充分。

**相似度范围**：40-60%

**特征**：
- 高度相似的措辞
- 直接复制且改动很少
- 简单的同义词替换
- 相同的句子结构
- 改写不充分

**检测方法**：
1. 文本相似度分析
2. N-gram匹配
3. 短语级别比较
4. 识别复制的片段

**示例**：
```
原文：本研究采用混合方法，结合定量调查和定性访谈以获得
      全面洞察。

文字表述剽窃：本调查利用混合方法策略，整合定量问卷和
              定性访谈以获得透彻理解。
```

**分析**：
- 相同的结构（混合方法 → 定量 + 定性）
- 同义词替换（采用 → 利用，调查 → 问卷）
- 相同的句子模式
- 改写不充分

---

### 类型3：整体剽窃

**定义**：从另一来源复制大部分内容，改动极少或没有改动。

**相似度**：≥60% 且 >300字

**特征**：
- 大块复制的文本
- 多个连续段落
- 极少改写
- 直接复制大部分内容
- 可能包括复制结构、图表、表格

**检测方法**：
1. 连续高相似度检测
2. 逐片段分析
3. 识别复制的块
4. 计算累积相似度

**示例**：
```
原文（500字）：[方法论的广泛讨论...]

整体剽窃（480字）：[几乎相同的讨论，仅做少量词汇更改和
                   格式调整]
```

**分析**：
- 96%的文本相似度
- 480字被复制
- 相同的整体结构
- 极少原创内容

---

### 类型4：过度引用

**定义**：过度使用引用导致论文主要是他人作品汇编而非原创内容。

**阈值**：每100字超过3个引用

**特征**：
- 引用密度过高
- 文本主要由引用内容组成
- 缺乏原创分析
- 引用拼凑
- 缺乏综合

**检测方法**：
1. 引用密度计算
2. 引用内容百分比
3. 识别引用集群
4. 分析原创内容比例

**示例**：
```
[1]根据Smith [2]，这种现象很普遍[3]。Jones [4]认为[5]影响很大[6]。
Brown [7]建议[8]需要进一步研究[9]。

引用密度：约200字中10个引用 = 每100字5个
状态：过度引用
```

**分析**：
- 引用密度：每100字5个（阈值：3）
- 文本主要是引用
- 极少原创内容
- 综合性差

## 检测流程

### 步骤1：相似度分析

对每个片段，计算：
1. 文本相似度（精确匹配、近似匹配）
2. 语义相似度（含义、观点）
3. 结构相似度（组织、流程）
4. 综合相似度分数

### 步骤2：引用分析

1. 统计引用标记
2. 计算引用密度
3. 识别引用集群
4. 分析引用模式

### 步骤3：分类

基于相似度分数和特征：
- 30-40% + 观点相似 → 观点剽窃
- 40-60% + 文本相似 → 文字表述剽窃
- ≥60% + >300字 → 整体剽窃
- 引用密度 >3/100字 → 过度引用

### 步骤4：报告

对每种剽窃类型，报告：
- 位置（章节、片段）
- 相似度分数
- 字符数
- 违规描述
- 置信度水平
- 来源类型（如果可识别）

## 剽窃严重程度评估

| 类型 | 严重程度 | 学术影响 | 建议 |
|------|----------|---------------------|------|
| 观点剽窃 | 中 | 损害原创性 | 需要修改 |
| 文字表述剽窃 | 高 | 违反学术诚信 | 需要大幅修改 |
| 整体剽窃 | 极高 | 严重不端行为 | 需要重写 |
| 过度引用 | 低-中 | 缺乏原创性 | 增加综合内容 |

## 特殊情况

### 自我剽窃

**定义**：在未适当注明出处的情况下，重复使用自己之前发表的作品。

**检测**：
- 与作者之前发表的作品比较
- 识别回收的内容
- 检查是否有适当注明
- 区分于合法的自我引用

**处理**：
- 类似于文字表述剽窃
- 有适当注明时可能可接受
- 取决于发表政策

### 镶嵌剽窃

**定义**：在没有清晰归属的情况下，穿插复制的文本和原创内容。

**检测**：
- 识别交替的相似度模式
- 检测拼凑结构
- 分析引用位置
- 检查归属清晰度

**处理**：
- 通常归类为文字表述剽窃
- 需要全面修改
- 所有来源必须正确引用

### 无意剽窃

**定义**：由于引用不当或缺乏知识而无意中剽窃。

**检测**：
- 与其他剽窃类型相同
- 考虑引用模式
- 如果可能，评估意图

**处理**：
- 教育方式
- 教授正确引用
- 允许修改

## 预防策略

### 对于作者

1. **正确改写**：同时改变措辞和结构
2. **引用来源**：注明所有观点和文本
3. **使用引号**：对于精确文本使用引号
4. **综合**：整合多个来源
5. **保留笔记**：研究过程中记录来源

### 对于审查者

1. **使用工具**：使用剽窃检测软件
2. **检查引用**：验证来源归属
3. **分析结构**：寻找组织相似性
4. **审查异常措辞**：调查不一致之处
5. **比较来源**：检查引用的文档
