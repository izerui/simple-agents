# 论文检测标准与判定依据

本文档描述论文相似度和AIGC检测的判定标准和依据。

## 相似度检测标准

### 相似度等级划分

| 等级 | 相似度范围 | 颜色标识 | 说明 |
|------|-----------|----------|------|
| 高相似度 | ≥50% | 红色 | 严重重复，需要大幅修改 |
| 中等相似度 | 40%-50% | 黄色 | 存在重复，建议修改 |
| 低相似度 | 30%-40% | 绿色 | 轻度相似，关注即可 |
| 正常 | <30% | 无标识 | 在正常范围内 |

### 检测指标定义

1. **总文字复制比**
   - 论文中与已有文献相似文字占总字数的百分比
   - 包括引用、重复内容等所有相似部分
   - 是最基础的相似度指标

2. **去除引用文献复制比**
   - 排除正确标注的引用文献后的相似度
   - 反映论文原创内容的相似程度
   - 通常低于总文字复制比

3. **去除本人已发表文献复制比**
   - 排除作者本人已发表作品后的相似度
   - 用于避免自我引用造成的误判
   - 通常与总文字复制比相同（除非作者有相关发表）

### 相似度来源类型

| 来源类型 | 说明 | 典型特征 |
|----------|------|----------|
| 学术期刊 | 已发表的学术论文 | 专业术语密集，逻辑严谨 |
| 学位论文 | 硕士/博士学位论文 | 结构完整，研究详细 |
| 会议论文 | 学术会议发表论文 | 内容较新，篇幅较短 |
| 网络资源 | 互联网公开内容 | 语言通俗，来源多样 |
| 教材著作 | 出版书籍教材 | 系统性强，权威性高 |

## AIGC检测标准

### AIGC生成率等级

| 等级 | 生成率 | 风险等级 | 建议措施 |
|------|--------|----------|----------|
| 极高 | >50% | 极高风险 | 完全重写 |
| 高 | 30%-50% | 高风险 | 大幅修改 |
| 中 | 15%-30% | 中风险 | 重点修改 |
| 低 | 5%-15% | 低风险 | 适当修改 |
| 正常 | <5% | 正常 | 无需修改 |

### AIGC判定依据

1. **语言特征**
   - 句式过于规整统一
   - 缺乏个人表达风格
   - 连接词使用模式化
   - 语气过于中立客观

2. **内容特征**
   - 缺乏具体案例和数据
   - 论述过于泛泛而谈
   - 缺少个人观点和见解
   - 逻辑推导过于完美

3. **结构特征**
   - 段落长度过于均匀
   - 结构过于标准化
   - 缺乏变化和创新

### 高风险段落识别

高风险段落通常具备以下特征：

- "首先...其次...最后..."等过于规整的结构
- 大量使用"综上所述"、"值得注意的是"等套话
- 缺乏具体的例子、数据支撑
- 论述空洞，缺乏实际内容
- 语言风格与其他部分明显不一致

## 检测报告解读

### 合格标准

不同机构/期刊的合格标准可能不同，一般参考：

- **本科毕业论文**: 总文字复制比 ≤ 30%
- **硕士毕业论文**: 总文字复制比 ≤ 20%
- **博士毕业论文**: 总文字复制比 ≤ 15%
- **期刊投稿**: 总文字复制比 ≤ 15%（核心期刊更低）
- **AIGC生成率**: 一般要求 ≤ 10%

### 报告使用建议

1. **重点关注高相似度片段**
   - 优先修改红色标注（≥50%）部分
   - 适当关注黄色标注（40%-50%）部分
   - 了解绿色标注（30%-40%）部分

2. **正确处理引用**
   - 确保所有引用都有正确标注
   - 引用部分不应计入相似度
   - 避免过度引用

3. **AIGC内容处理**
   - 对高风险段落进行人工重写
   - 增加个人分析和观点
   - 补充具体案例和数据

## 常见问题

### Q1: 引用文献为什么也被检测为相似？

A: 引用文献确实会与原文相似，但：
- "去除引用文献复制比"指标会排除正确引用
- 确保引用格式规范，便于系统识别
- 避免大段引用，建议 paraphrasing

### Q2: 如何降低相似度？

A: 实用方法：
- 用自己的话重新表述（paraphrasing）
- 调整句式结构
- 增加个人分析和见解
- 补充新的研究内容

### Q3: AIGC检测准确吗？

A: 注意事项：
- AIGC检测是概率性的，不是100%准确
- 人工写作也可能被误判
- 建议结合内容质量综合判断
- 真实的研究和数据是最好的证明
