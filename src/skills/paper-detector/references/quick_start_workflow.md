# 论文检测快速使用指南（工作流版）

## ⚡ 快速开始

### 1. 基础检测（推荐）

```bash
cd /Users/liuyuhua/PycharmProjects/simple-agents/src/skills/paper-detector
python3 scripts/ai_paper_detector.py your_paper.md
```

这将执行**所有12个强制检测步骤**，覆盖**29个核心检测项**。

### 2. 增强检测（含AI深度分析）

```bash
python3 scripts/ai_paper_detector.py your_paper.md --enhanced-ai
```

额外增加**3项增强AI检测**：
- AI词汇密度检测
- 句式突发性检测
- 改写攻击检测

### 3. 生成检测报告

```bash
python3 scripts/generate_report.py detection_result_PDXXXXXXXXXXXX.json
```

生成3种类型的报告：
- 简洁版报告（核心指标）
- 全文版报告（详细分析）
- AIGC专项报告（AI检测详情）

## 📊 检测流程说明

### 12个强制步骤

```
步骤1: 文档读取与预处理
  ├─ 提取论文内容
  ├─ 统计字数（知网标准）
  └─ 识别基本信息

步骤2: 章节提取
  └─ 识别摘要、引言、正文、结论等章节

步骤3: 文本分割
  └─ 将文本分割为100-2000字的检测片段

步骤4: 引用识别
  └─ 识别[数字]和(作者,年份)格式的引用

步骤5: 相似度检测（核心）
  ├─ 分析每个片段的相似度
  └─ 统计相似度分布（高/中/低/正常）

步骤6: AIGC检测（核心）
  ├─ 检测AI生成内容
  └─ 识别高风险段落

步骤7: 剽窃类型检测（4种）
  ├─ 疑似剽窃观点
  ├─ 疑似剽窃文字表述
  ├─ 疑似整体剽窃
  └─ 过度引用

步骤8: 过度引用检测
  └─ 识别引用密度过高的片段

步骤9: 相似内容检测（表格、公式）
  ├─ 检测相似表格
  └─ 检测相似公式

步骤10: 增强AI检测（3项）[可选]
  ├─ AI词汇密度检测
  ├─ 句式突发性检测
  └─ 改写攻击检测

步骤11: 统计指标计算
  ├─ 知网指标（4项）
  ├─ 维普指标（3项）
  ├─ 字数统计（8项）
  └─ 百分比划分（2项）

步骤12: 报告生成
  ├─ 简洁版报告
  ├─ 全文版报告
  └─ AIGC专项报告
```

### 29个核心检测项

#### 知网指标（4项）
1. 总文字复制比
2. 去除引用文献复制比
3. 去除本人已发表文献复制比
4. 单篇最大文字复制比

#### 维普指标（3项）
1. 引用率（正确引用内容占比）
2. 复写率（相似度≥50%内容占比）
3. 自写率（相似度<30%原创内容占比）

#### 字数统计（8项）
1. 总字数
2. 总段落数
3. 重复字数
4. 疑似段落数
5. 单篇最大重复字数
6. 单篇最大重复位置
7. 前部重合字数
8. 疑似段落最大/最小重合字数

#### 百分比划分（2项）
1. 文字复制部分（基于重复字数计算）
2. 无问题部分（100% - 文字复制部分）

#### 剽窃类型（4种）
1. 疑似剽窃观点
2. 疑似剽窃文字表述
3. 疑似整体剽窃
4. 过度引用

#### 相似内容（2类）
1. 相似表格
2. 相似公式

#### AIGC检测（2项）
1. AIGC总体生成率
2. 各章节AIGC生成率

#### 增强AI检测（3项可选）
1. AI词汇密度
2. 句式突发性
3. 改写攻击

## 🔍 结果解读

### 相似度等级

| 等级 | 范围 | 说明 | 建议 |
|------|------|------|------|
| 高相似度 | ≥50% | 严重重复 | 必须修改 |
| 中等相似度 | 40%-50% | 存在重复 | 建议修改 |
| 低相似度 | 30%-40% | 轻度相似 | 关注即可 |
| 正常 | <30% | 在正常范围 | 无需修改 |

### AIGC风险等级

| 等级 | 生成率 | 风险 | 建议 |
|------|--------|------|------|
| 极高风险 | ≥50% | 很可能AI生成 | 完全重写 |
| 高风险 | 30%-50% | AI生成可能性大 | 大幅修改 |
| 中风险 | 15%-30% | 有AI特征 | 重点修改 |
| 低风险 | 5%-15% | 少量AI特征 | 适当修改 |
| 正常 | <5% | 主要是人工撰写 | 无需修改 |

### 合格标准参考

- **本科毕业论文**: 总文字复制比 ≤ 30%
- **硕士毕业论文**: 总文字复制比 ≤ 20%
- **博士毕业论文**: 总文字复制比 ≤ 15%
- **期刊投稿**: 总文字复制比 ≤ 15%
- **AIGC生成率**: 一般要求 ≤ 10%

## 💡 使用建议

### 1. 检测前
- 确保论文格式正确（.md, .txt, .docx, .pdf）
- 检查文件是否完整
- 备份原始文件

### 2. 检测中
- 使用强制工作流模式（默认）
- 仔细观察每个步骤的执行状态
- 记录任何错误信息

### 3. 检测后
- 阅读3种报告，全面了解检测结果
- 重点关注高相似度和高风险段落
- 结合具体内容判断检测结果
- 对问题段落进行针对性修改

### 4. 修改后
- 重新检测验证修改效果
- 对比修改前后的指标变化
- 确保达到合格标准

## ⚠️ 常见问题

### Q1: 检测需要多长时间？

A: 取决于论文长度，一般：
- 5000字：约1-2分钟
- 10000字：约2-3分钟
- 50000字：约5-10分钟

### Q2: 可以跳过某些检测步骤吗？

A: **不可以**。强制工作流模式确保所有步骤都执行，保证检测完整性。

如果确实需要，可以使用 `--no-workflow` 禁用工作流模式，但不推荐。

### Q3: 检测结果准确吗？

A: 检测结果基于文本特征分析，仅供参考：
- 建议结合官方检测平台（知网、维普）交叉验证
- 重点关注高相似度和高风险段落
- 根据具体内容判断是否真的存在问题

### Q4: 如何降低相似度和AIGC率？

A: 实用方法：
- 用自己的话重新表述（paraphrasing）
- 调整句式结构
- 增加个人分析和见解
- 补充具体的数据和案例
- 避免过度使用连接词和套话

### Q5: 增强AI检测有什么用？

A: 提供3项额外的AI内容分析：
- **AI词汇密度**：识别AI高频词汇使用频率
- **句式突发性**：分析句式变化的自然程度
- **改写攻击**：检测AI改写工具的使用痕迹

适合需要更深入AI内容分析的场景。
