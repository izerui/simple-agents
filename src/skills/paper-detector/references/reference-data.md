# 参考数据与特征库（v8.1 官方口径校准）

> 逐段语义分析的认知框架与评估原则。不是模式词表——模型已经知道这些模式。
> 返回主技能：[SKILL.md](../SKILL.md)

---

## 核心原则

你的推理过程可以感知文本是否常见，但当前目标是模拟官方报告。读到一个句子时：
- 预测概率高 → 说明表达常见，但不等于官方一定标红
- 连续文字骨架重合、定义/法规/规范原文、整段综述搬运 → 官方更可能标红
- 只有语义相似、章节套话、学科规范表达 → 降权，通常不完整计入复制比

你不是在追求最大覆盖，而是在按官方系统可能命中的字符比例做保守预估。本文档帮助你校准到官方口径。

## 一、查重判断的认知框架

### 你在做什么

你在模拟传统查重系统的最终指标，而不是把所有熟悉表达都算作重复：

```
传统系统：句子 → 精确字符串搜索海量论文 → 报告匹配来源
你      ：句子 → 判断是否存在官方可命中的连续重合/近似重合 → 保守计入复制比
```

模型熟悉感只是线索。最终数值必须向知网/维普报告的常见输出范围看齐。

### 逐句三级分类

| 分类 | 你的感知 | 对应处理 |
|------|---------|---------|
| **红句** | "这个句子存在明显连续重合或原文式复用" | 全部字符计入匹配 |
| **黄句** | "有局部连续重合/轻度改写骨架，但混入特异性内容" | 按官方可能标红片段计入，通常10-40% |
| **绿句** | "这个文字组合不太可能在已有文献中出现" | 不计入匹配 |

### 校准直觉

**红句的典型场景**（几乎必然被标红）：
- 教科书/百科式定义的原文或微调版
- 政策法规原文引用
- 统计方法、工程规范、护理流程等标准原文
- 文献综述或摘要/结论整句搬运

**低权重黄句的典型场景**：
- "随着…的发展，…越来越…"等万能背景句
- 研究目的、研究意义、章节安排等功能句
- 有具体对象/数据/地点的通用方法描述
- 只有语义相似但文字不同的学科常识

**绿句的典型场景**（几乎不会被标红）：
- 作者自己调查的具体数据+来源
- 独特的因果推理链（具体政策+具体时间+具体数据）
- 个人经历和观察

**关键规则**：连续13字以上相同即判重复。在常见表达中间插入足够特异性内容可以打断连续性。

### 学科规范说明

不同学科天然有大量规范表达，但官方报告不一定完整标红。学科规范表达应更多作为解释和低权重证据，不应直接抬高全文复制比。

### 官方输出范围锚点

| 文本类型 | 查重率校准 |
|---------|-----------|
| 普通本科论文，有具体案例/调研/数据，套话集中在摘要绪论结论 | 3-12% |
| 护理综述、工程造价、艺术音乐、旅游管理等规范表达较多 | 5-15% |
| 文献综述/理论定义多，局部连续套用 | 10-20% |
| 多章节整段搬运或引用/定义堆叠 | 20-30% |
| 核心章节也大量连续重合 | >30% |

## 二、AIGC判断的认知框架

### 你在判断什么

> "这段文字读起来像是一个AI模型一次性生成的，还是一个人在思考、犹豫、修改后写出来的？"

你自己就是AI模型，你对"AI会怎么写"有最直接的认知。关键不是找某个特定词，而是感知整体的**生成概率分布**。

### AI文本的本质特征

AI生成文本的根本特征不是用了某个词，而是：

1. **高可预测性**：每个位置都选择了概率最高或接近最高的token。整段文字沿着概率梯度"滑行"，没有意外
2. **均匀分布**：句长、段长、论证深度、修辞密度在全文中分布均匀，像是由同一个参数控制
3. **缺乏锚点**：没有与外部现实世界锚定的信息（具体时间地点机构数据），因为AI没有这些经历

### 人写文本的本质特征

人写文本的根本特征是：

1. **局部不规则**：有的地方写得好有的地方写得差，有的段落长有的短，节奏不均匀——因为人的注意力和精力波动
2. **现实锚定**：包含只有亲历者才知道的细节，或者需要实际查阅才能获得的精确数据
3. **思维痕迹**：有犹豫、修正、回溯——先说了一个判断，后面又补充限定条件

### 五级感知量表

| 级别 | 语义感知 | 对应AIGC率 |
|------|---------|-----------|
| **几乎确定是AI** | 读起来极其顺滑、可预测，像是模型一次生成。完全没有人的痕迹 | 50-100% |
| **很可能是AI** | 大部分很顺滑，但有少量可能是人为修改的痕迹 | 30-50% |
| **不太确定** | 有一些AI特征但也有一些人写证据，难以判断 | 10-30% |
| **很可能是人写** | 有明显的人写特征（具体细节、不规则性、个人经历），少量AI特征可能只是写得规范 | 5-15% |
| **几乎确定是人写** | 充满个性化表达、真实细节、思维痕迹 | 0-10% |

### 高置信度 AI 写作信号（经实证验证）

以下模式来自 Wikipedia "Signs of AI writing" 社区对数千篇 AI 生成文本的实证观察。当这些模式**密集共现**时，可显著提高 AIGC 判断的置信度：

**语法层面的 AI 指纹**：
- **回避 is/are**：用 "serves as""stands as""represents" 替代简单系动词——AI 倾向于选择"更丰富"的表达
- **-ing 尾缀伪深度**：句尾附加 "highlighting...""reflecting...""ensuring..." 制造假分析感
- **否定并列结构**：过度使用 "不仅…而且…""不是…而是…" 结构
- **三连并列**：强制把信息凑成三个一组（"创新、协作与卓越"）
- **同义词轮换**：同一概念在相邻句中用不同词指代以避免重复（主角→主人公→核心人物→英雄）

**词汇层面的 AI 偏好**：
- 高频 AI 词汇在 2023 年后的文本中出现率显著上升：additionally, crucial, delve, foster, garner, highlight, interplay, intricate, landscape（抽象用法）, pivotal, showcase, tapestry（抽象用法）, testament, underscore, vibrant
- 中文对应：此外、至关重要、深入探讨、培育、彰显、交织、错综复杂、格局/图景、关键性、展示、画卷、见证、强调、充满活力

**格式层面的 AI 习惯**：
- 破折号过度使用（中文用——，英文用 em dash）
- 加粗关键词做伪结构化
- "关键词: 解释" 格式的列表项
- 标题全部 Title Case（英文）

**内容层面的 AI 模式**：
- 泛泛归因："专家认为""研究表明""业内人士指出"——不给具体来源
- 模板化结尾："未来可期""前景广阔""任重道远"
- 夸大重要性："具有里程碑意义""标志着…的新篇章""开创性的"
- 挑战与展望公式："尽管面临…挑战，但…前景依然…"

> **使用原则**：这些信号是校准锚点，不是判定标准。单个信号不说明问题，但 5 个以上信号密集共现时，AIGC 置信度应显著上调。同样，这些信号的完全缺失是人写的正面证据。

### AIGC判断的陷阱

1. **规范≠AI**：方法论描述、统计结果报告天然规范，不代表是AI写的
2. **流畅≠AI**：写作水平高的人也能写出流畅文本，关键看是否有"不完美的真实"
3. **模板≠AI**：按固定结构写论文是学术训练的结果，不是AI的证据
4. **短段≠AI**：短段落信息量少，判断置信度天然低，不要轻易下高AIGC结论
5. **英文摘要≠全文AI**：英文摘要常由翻译软件或模板生成，不能单独推高全文AIGC
6. **本科表达不成熟≠AI**：病句、重复、口语化、逻辑跳跃通常是人写证据

### 官方AIGC范围锚点

| 文本类型 | AIGC率校准 |
|---------|-----------|
| 有真实调研、问卷、访谈、工程参数、临床/护理对象、具体企业/景区案例 | 0-15% |
| 摘要/结论/建议模板化，但主体材料具体 | 10-25% |
| 多章节抽象顺滑、缺少数据来源，建议对策泛泛 | 20-35% |
| 全文大段无具体锚点、结构和措辞高度AI化 | 35-50% |
| 几乎整篇呈现一次性生成特征 | >50% |

## 三、综合判断原则

### 证据权重

不是所有信号等权：

| 信号类型 | 权重 | 原因 |
|---------|------|------|
| 具体可验证信息（数据+来源、机构名、时间点） | 最高 | 这些是最难伪造的人写证据，也是最能区分重合/原创的信息 |
| 整体语义感知（"读起来像..."） | 高 | 这是你作为大模型的核心能力 |
| 文本不规则性（句长波动、质量起伏） | 中 | 有参考价值但不绝对——有人刻意模仿不规则 |
| 单个词汇或短语 | 低 | 任何单个词都不应成为判断依据 |

### 置信度意识

你的判断本质上是概率估计。在报告中体现置信度：

- 段落字数越多，判断越可靠
- 信号越多且越一致，置信度越高
- 信号矛盾时（如有具体数据但表达极其顺滑），应降低置信度并在报告中说明
- 摘要和结论因为天然短且程式化，置信度天然低
