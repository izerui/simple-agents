## AI学术模式特征（51项）

### 结构性连接词（12项）

**模式**：
- 因此...此外 / 另外
- 然而...此外 / 而且
- 一方面...另一方面
- 首先...其次...第三...
- 不仅...而且...
- 既...又...

**分析**：这些是常见的学术结构。过度使用可能表明AI生成内容。

### 常见句式（15项）

**开篇模式**：
- 需要注意的是
- 值得指出的是
- 重要的是
- 应当注意

**过渡模式**：
- 此外...
- 另外...
- 而且...
- 还有

**结论模式**：
- 总之
- 综上所述
- 基于以上分析
- 总而言之

**分析**：这些是标准学术表达。偶尔使用正常；过度使用表明公式化写作。

### 数据呈现模式（10项）

**图表引用**：
- 如图1所示
- 从表2可以看出
- 图3的数据表明

**结果陈述**：
- 结果表明
- 研究结果显示
- 数据显示

**分析**：这些是标准科学写作模式。在上下文中评估。

### 研究方法模式（14项）

**方法描述**：
- 本研究采用
- 我们运用了...方法
- 使用...方法
- 采用...策略

**模型引用**：
- 基于...模型
- 使用...框架
- 根据...理论

**分析**：方法描述往往标准化。关注应用原创性。

## 使用指南

### 对于分析

1. **上下文重要**：始终在上下文中评估特征
2. **累积证据**：寻找多个指标一起出现
3. **领域差异**：学术规范因学科而异
4. **文化差异**：写作风格因文化而异
5. **你的判断**：这些是参考，不是规则

### 对于检测

1. **AI模式**：通用模式的高频率可能表明AI
2. **人类特征**：具体细节的存在表明人类
3. **混合信号**：许多论文具有混合特征
4. **置信度水平**：报告发现时的置信度
5. **专业判断**：使用你的理解，而不仅仅是模式

### 对于报告

1. **具体明确**：列出的具体发现特征
2. **提供上下文**：解释为什么特征重要
3. **避免绝对**：使用概率语言，而非绝对值
4. **考虑替代方案**：提及其他可能的解释
5. **建议行动**：基于发现建议下一步行动
