## 一、知网核心指标（5项）

### 1. 总文字复制比

**定义**：论文整体相似度百分比（核心指标）

**计算公式**：
```
总文字复制比 = 总相似字数 / 总字数 × 100%
```

**检测方法**（融合相似度方法论 - v3.0优化版）：

对每个段落进行4维度相似度分析：

1. **表达相似度（35%权重）**
   - 检测直接复制的文字
   - 分析句子结构相似性
   - 识别简单改写内容

2. **语义相似度（25%权重）**
   - 分析论证逻辑相似性
   - 检测观点表达的相似性
   - 评估推理路径的重合度

3. **结构相似度（25%权重）**
   - 分析段落组织方式
   - 检测论证框架相似性
   - 评估文章结构一致性

4. **数据/案例相似度（15%权重）**
   - 识别相同的数据引用
   - 检测案例复用
   - 分析图表相似性

**综合相似度计算**：
```
综合相似度 = 表达相似度×0.35 + 语义相似度×0.25 + 结构相似度×0.25 + 数据相似度×0.15
```

**动态校准**：
```
| AI原始值范围 | 校准系数 | 偏移量 |
|-------------|---------|--------|
| 0-5%        | 0.30    | 0.3%   |
| 5-10%       | 0.35    | 0.5%   |
| 10-20%      | 0.40    | 0.8%   |
| >20%        | 0.45    | 1.0%   |

调整后值 = AI原始值 × 校准系数 + 偏移量
```

**输出格式**：
```json
{
  "总文字复制比": "23.5%",
  "总相似字数": 2350,
  "相似片段数": 42,
  "风险等级": "中等"
}
```

---

### 2. 去除引用文献复制比

**定义**：排除所有正确引用内容后的相似度百分比

**计算公式**：
```
去除引用文献复制比 = (总相似字数 - 引用字数) / 总字数 × 100%
```

**检测方法**（v3.0优化版）：

1. **识别引用标记**
   - `[数字]`格式：如[1]、[2-3]
   - `(作者, 年份)`格式：如(Smith, 2020)
   - 脚注/尾注格式
   - 超链接引用

2. **识别隐式引用**
   - "根据XXX研究"
   - "XXX指出"
   - "研究表明"
   - "XXX认为"
   - "正如XXX所述"

3. **判断引用有效性**
   - 是否正确标注来源
   - 引用内容是否为合理引用
   - 引用密度是否过高（不超过段落30%）
   - 引用后是否有个人分析
   - 引用格式是否规范

4. **计算排除引用后的相似度**

**输出格式**：
```json
{
  "去除引用文献复制比": "18.2%",
  "引用字数": 528,
  "引用片段数": 18
}
```

---

### 3. 去除本人文献复制比

**定义**：排除作者本人已发表文献后的相似度百分比

**计算公式**：
```
去除本人文献复制比 = (总相似字数 - 自引相似字数) / 总字数 × 100%
```

**检测方法**：

1. **识别作者姓名**
   - 从论文标题页提取
   - 从致谢中提取
   - 识别多种变体（全名、缩写等）

2. **标记自引来源**
   - 在参考文献中识别自引项
   - 识别自引标记（如"作者前期研究"、"我们之前的发现"）
   - 分析相似片段与作者已发表工作的关联性

3. **计算去除自引后的相似度**

**输出格式**：
```json
{
  "去除本人文献复制比": "20.1%",
  "自引字数": 340,
  "自引片段": [
    {"位置": "引言第3段", "字数": 245, "相似度": "45%"}
  ]
}
```

---

### 4. 单篇最大文字复制比

**定义**：与单个来源文献相似度最高的片段占比

**计算公式**：
```
单篇最大文字复制比 = max(各文献来源相似字数) / 总字数 × 100%
```

**检测方法**：

1. **按来源文献分组相似片段**
   - 识别相同来源的多个相似片段
   - 判断是否构成整体抄袭
   - 评估集中复制的严重程度

2. **计算每篇文献的总相似字数**

3. **找出最大值**

**输出格式**：
```json
{
  "单篇最大文字复制比": "15.2%",
  "来源文献": "张三. 基于深度学习的图像识别研究[D]. 北京大学, 2020.",
  "相似片段数": 5,
  "总相似字数": 1520
}
```

---

### 5. 重复字符数

**定义**：被识别为相似内容的字符总数

**计算公式**：
```
重复字符数 = sum(各相似片段字数)
```

**检测方法**：

1. **统计所有相似度≥30%的片段字数**
2. **区分完全复制和部分相似**
3. **考虑片段重叠情况**

**输出格式**：
```json
{
  "重复字符数": 2350,
  "高相似(≥50%)": 1200,
  "中相似(40-50%)": 650,
  "低相似(30-40%)": 500
}
```

## 二、维普核心指标（7项）

### 6. 引用率

**定义**：正确引用的内容占总字数的比例

**计算公式**：
```
引用率 = 带引用标记的字数 / 总字数 × 100%
```

**检测方法**：

1. **识别所有引用标记**
   - `[数字]`格式
   - `(作者, 年份)`格式

2. **统计引用内容字数**

3. **验证引用的合法性**
   - 引用格式识别
   - 引用内容相关性
   - 引用密度评估

**输出格式**：
```json
{
  "引用率": "22.5%",
  "引用数量": 35,
  "引用字数": 2250,
  "引用密度": "3.5个/100字符"
}
```

---

### 7. 复制率

**定义**：≥50%相似度内容百分比

**计算公式**：
```
复制率 = ≥50%相似字数 / 总字数 × 100%
```

**检测方法**：

1. **统计所有≥50%相似度的片段**
2. **累加相似字数**
3. **计算占比**

**输出格式**：
```json
{
  "复制率": "12.0%",
  "高相似片段数": 12,
  "高相似字数": 1200
}
```

---

### 8. 原创率

**定义**：<30%相似度原创内容百分比

**计算公式**：
```
原创率 = <30%相似字数 / 总字数 × 100%
原创率 = 100% - 复制率 - 引用率
```

**检测方法**：

1. **统计所有<30%相似度的片段**
2. **计算原创内容字数**
3. **评估原创性**

**输出格式**：
```json
{
  "原创率": "76.5%",
  "原创字数": 7650,
  "原创片段数": 28
}
```

---

### 9. 复写率

**定义**：经过改写但仍保留原有结构和逻辑的相似内容占比

**计算公式**：
```
复写率 = 复写相似字数 / 总字数 × 100%
```

**检测方法**：

识别文字不同但结构相似的片段：

1. **结构相似度分析**：段落组织、论证逻辑
2. **语义相似度分析**：核心观点、推理路径
3. **表达差异度分析**：词汇替换、句式变化

**判定标准**：
| 结构相似度 | 语义相似度 | 表达差异度 | 判定 |
|-----------|-----------|-----------|------|
| ≥70% | ≥70% | 任意 | 高复写 |
| 50-70% | 50-70% | 任意 | 中复写 |
| 30-50% | 30-50% | 任意 | 低复写 |

**输出格式**：
```json
{
  "复写率": "8.5%",
  "高复写片段": 3,
  "中复写片段": 5,
  "低复写片段": 8,
  "复写类型": {
    "同义词替换": 6,
    "句式变换": 4,
    "语序调整": 3
  }
}
```

---

### 10. 自引率

**定义**：引用作者本人已发表文献的占比

**计算公式**：
```
自引率 = 自引字数 / 总引用字数 × 100%
```

**检测方法**：

1. **识别作者姓名**（多种变体）
2. **标记参考文献中的自引项**
3. **统计自引内容字数**

**输出格式**：
```json
{
  "自引率": "15.8%",
  "自引文献数": 3,
  "自引总字数": 356,
  "全部引用字数": 2254
}
```

---

### 11. 他引率

**定义**：引用他人文献的占比

**计算公式**：
```
他引率 = 他引字数 / 总引用字数 × 100%
他引率 = 100% - 自引率
```

**检测方法**：

1. **从总引用中排除自引**
2. **统计他引字数**
3. **计算比例**

**输出格式**：
```json
{
  "他引率": "84.2%",
  "他引文献数": 28,
  "他引总字数": 1898
}
```

---

### 12. 全文总相似比

**定义**：综合考虑所有相似度指标的总体相似度

**计算公式**：
```
全文总相似比 = (总文字复制比 + 复写率×0.5 + 引用率×0.3) / 综合权重
```

**权重分配**：
- 总文字复制比：权重1.0
- 复写率：权重0.5
- 引用率：权重0.3

**输出格式**：
```json
{
  "全文总相似比": "26.8%",
  "指标构成": {
    "总文字复制比": "23.5% (权重1.0)",
    "复写率": "8.5% (权重0.5 → 4.25%)",
    "引用率": "12.5% (权重0.3 → 3.75%)"
  }
}
```

## 三、论文基础统计（8项）

### 13. 论文字符数

**定义**：论文正文部分的字符总数（知网标准）

**计算公式**：
```
论文字符数 = 中文字符+英文字符+数字+标点-空格-换行
```

**检测方法**：

1. **提取正文内容**（排除参考文献、致谢等）
2. **按知网标准统计字符数**
3. **区分中英文字符**

**输出格式**：
```json
{
  "论文字符数": 10000,
  "中文字符数": 8500,
  "英文字符数": 1200,
  "数字字符数": 300,
  "统计标准": "知网标准（不含空格换行）"
}
```

---

### 14. 论文页数

**定义**：论文的页面总数（按A4标准排版估算）

**计算公式**：
```
论文页数 = ceil(论文字符数 / 单页标准字符数)
```

**标准参数**：
- 单页标准字符数：约1500-2000字符
- 图表占用：每个表格/图片约占用300-500字符位置

**输出格式**：
```json
{
  "论文页数": 8,
  "估算依据": "标准A4排版，小四号字，1.5倍行距",
  "纯文字页数": 6,
  "图表占用": 2
}
```

---

### 15. 表格数量

**定义**：论文中表格的总数量

**检测方法**：

1. **识别Markdown表格格式**
2. **识别表格引用标记**（表1、Table 1等）
3. **统计表格数量**

**输出格式**：
```json
{
  "表格数量": 5,
  "表格列表": [
    {"序号": "表1", "标题": "实验参数设置", "位置": "方法部分"}
  ]
}
```

### 16. 图片数量

**定义**：论文中图片的总数量

**检测方法**：

1. **识别Markdown图片标记** `![alt](url)`
2. **识别图片引用标记**（图1、Figure 1等）
3. **统计图片数量**

**输出格式**：
```json
{
  "图片数量": 8,
  "图片列表": [
```

### 17. 总相似片段

**定义**：检测到的相似片段总数

**计算公式**：
```
总相似片段 = count(相似度 ≥ 30% 的片段)
```

**检测方法**：

1. **遍历所有检测片段**
2. **统计相似度≥30%的片段**
3. **按相似度等级分类**

**输出格式**：
```json
{
  "总相似片段": 42,
  "高相似片段(≥50%)": 12,
  "中相似片段(40-50%)": 15,
  "低相似片段(30-40%)": 15
}
```

### 20. 去除专业术语相似率

**定义**：排除专业术语后的相似度（专业术语属于合理使用）

**计算公式**：

```
去除专业术语相似率 = (总相似字数 - 专业术语相似字数) / 总字数 × 100%
```

**检测方法**：

1. **识别相似片段中的专业术语**
2. **计算术语部分字数**
3. **调整相似度计算**

**输出格式**：
```json
{
  "去除专业术语相似率": "20.1%",
  "原始总文字复制比": "23.5%",

}
```

## 四、相似度来源统计（6项）

### 21-26. 相似度来源统计（6项）

**指标**：
- 期刊相似度
- 综合相似度
- 外文相似度
- 博硕相似度
- 互联网相似度
- 自建库相似度

**检测方法**：

1. **分析相似片段的来源类型**
2. **根据引用格式判断来源**：
   - 期刊论文：ISSN、卷期号、J标记
   - 学位论文：[D]、博士、硕士标记
   - 图书：[M]标记
   - 外文文献：非中文内容
   - 网络资源：URL、访问日期
   - 自建库：内部特征
3. **统计各来源相似度占比**

**输出格式**：
```json
{
  "来源统计": {
    "期刊相似度": "8.5%",
    "综合相似度": "3.2%",
    "外文相似度": "5.8%",
    "博硕相似度": "6.5%",
    "互联网相似度": "4.2%",
    "自建库相似度": "1.5%"
  }
}
```

## 五、AIGC检测指标（13项）

### 27. 全文疑似AIGC生成率

**定义**：整篇论文中疑似AI生成内容的占比

**计算公式**：
```
全文疑似AIGC生成率 = sum(各片段AIGC概率×片段字数) / 总字数 × 100%
```

**检测方法**（融合AIGC方法论）：

对每个段落进行3维度AIGC分析：

1. **语言特征分析**（40%权重）
   - 句子规律性：分析句子长度变化、多样性
   - 词汇丰富度：检测词汇多样性和个性化
   - 表达自然度：识别过于规律、模板化表达

2. **内容特征分析**（35%权重）
   - 个人观点：检测独特见解和观点
   - 具体案例分析：判断是否有具体研究数据、案例支撑
   - 逻辑连贯性：分析论证逻辑的自然流畅

3. **结构特征分析**（25%权重）
   - 段落组织：分析自然度和个性化
   - 逻辑连接：检测逻辑连接词的自然度
   - 论证深度：评估深度和个人思考痕迹

**综合AIGC概率计算**：
```
AIGC概率 = 语言特征×0.4 + 内容特征×0.35 + 结构特征×0.25
```

**风险等级**：
| 生成率 | 风险等级 | 说明 |
|--------|----------|------|
| ≥50% | 极高 | AI生成概率很高 |
| 30-50% | 高 | AI生成概率较高 |
| 15-30% | 中 | 有明显AI特征 |
| 5-15% | 低 | 有一定AI特征 |
| <5% | 正常 | AI生成概率极低 |

**输出格式**：
```json
{
  "全文疑似AIGC生成率": "18.5%",
  "风险等级": "中",
  "高风险片段(≥50%)": 2,
  "中风险片段(30-50%)": 5,
  "低风险片段(15-30%)": 8
}
```

### 28. 全文人写概率

**定义**：整篇论文中人工撰写内容的概率

**计算公式**：
```
全文人写概率 = 100% - 全文疑似AIGC生成率
```

**检测方法**：

1. **从AIGC生成率推导**
2. **考虑人机混合撰写情况**
3. **评估人工撰写特征**

**人工撰写识别标志**：
- 个人观点数（每1个-2%）
- 具体案例数（每1个-3%）
- 自然表达片段（每1个-2%）

**输出格式**：
```json
{
  "全文人写概率": "81.5%",
  "人工撰写特征": {
    "个人观点数": 12,
    "具体案例数": 8,
```

### 41. 单篇最大重复字符数

**定义**：与单个来源文献相似的最大字符数

**计算公式**：
```
单篇最大重复字符数 = max(各文献来源相似字数)
```

### 42. 去除本人引用相似率

**定义**：排除自引后的相似度占比

**计算公式**：
```
去除本人引用相似率 = (总相似字数 - 自引相似字数) / 总字数 × 100%
```

**输出格式**：
```json

  "去除本人引用相似率": "19.8%",
  "原始总文字复制比": "23.5%",
  "排除的自引字数": 370
}
```

### 43. 自写率

**定义**：完全由作者原创撰写的部分占比

**计算公式**：
```
自写率 = 100% - 总文字复制比
```

**输出格式**：

## 剽窃类型检测方法

作为相似度检测的补充，识别4种剽窃类型：

### 疑似观点抄袭（30-40%相似度）

**特征**：论证结构、逻辑相似
**判定**：结构相似度≥50% 且 语义相似度≥50%

### 疑似文字抄袭（40-60%相似度）

**特征**：文字高度相似，缺乏原创性改写
**判定**：表达相似度≥40% 且 相似度在40-60%

### 疑似整体抄袭（≥60%相似度且>300字符）

**特征**：大段内容高度相似
**判定**：综合相似度≥60% 且 相似字数>300

### 过度引用（>3次引用/100字符）

**特征**：引用密度过高
**判定**：引用密度>3/100字符

**输出格式**：
```json
{
  "剽窃类型统计": {
    "疑似观点抄袭": {"count": 5, "总字数": 1250},
    "疑似文字抄袭": {"count": 8, "总字数": 3200},
    "疑似整体抄袭": {"count": 2, "总字数": 1800},
    "过度引用": {"count": 3, "总字数": 450}
  }
}
```
