# 汉斯出版社书目检索服务

## 概述

本技能提供对汉斯出版社（https://www.hanspub.org）开放获取学术资源的专业检索能力，支持按学科分类、关键词、作者、特定期刊等多种检索方式，帮助用户快速定位相关学术文献。

## 何时使用此技能

- 用户明确提到"汉斯出版社"、"hanspub"或相关期刊名称
- 需要检索中文开放获取学术论文
- 要求按学科分类查找学术资源
- 需要查找特定作者或标题的论文
- 要求获取标准书目引用格式

## 核心功能

### 1. 学科分类检索
支持9个主要学科领域的分类检索：
- **医药卫生**：包含心内科、心血管等医学专业期刊
- **信息通讯**：计算机科学、人工智能、数据挖掘等
- **工程技术**：机械工程、电气工程、土木工程等
- **生命科学**：生物医学、植物学、微生物学等
- **人文社科**：心理学、教育学、法学、经济学等
- **数学与物理**：理论数学、应用物理、统计学等
- **化学与材料**：材料科学、分析化学、纳米技术等
- **地球与环境**：环境保护、地理科学、农业科学等
- **经济与管理**：金融、市场营销、管理科学等

### 2. 多维度检索
- **关键词检索**：在标题、作者或全文中搜索
- **作者检索**：按作者姓名查找相关论文
- **期刊特定期刊检索**：在指定期刊中精确查找
- **组合检索**：支持多条件组合查询

### 3. 结果标准化
自动返回结构化书目信息，包含：
- 文章标题（中英文双语）
- 作者列表
- 期刊名称和ISSN
- 卷期页码信息
- DOI编号
- PDF下载链接
- 发表日期

## 使用方法

### 基础检索模式
```python
# 按关键词检索（默认在标题中搜索）
hanspub_search("人工智能")

# 按作者检索  
hanspub_search("张三", search_field="authors")

# 按学科检索
hanspub_search("机器学习", subject="信息通讯")

# 特定期刊检索
hanspub_search("深度学习", journal="CSA")
```

### 高级检索模式
```python
# 组合条件检索
hanspub_search(
    query="冠心病",
    subject="医药卫生",
    journal="ACRVM",  # 亚洲心脑血管病例研究
    page=1
)
```

## 资源引用

### scripts/
可执行代码模块，包含核心检索功能：
- `scripts/hanspub_retriever.py` - 核心检索模块，提供`hanspub_search()`、`get_subject_journals()`等API
- `scripts/__init__.py` - Python包初始化文件

### references/
参考文档，包含详细的期刊映射信息：
- `references/journal_mapping.md` - 完整的期刊代码映射表，包含100+种期刊的中英文名称和代码

### examples/
使用示例，演示各种检索场景：
- `examples/usage_examples.py` - 完整的使用示例，包括基础检索、医学领域检索、计算机科学检索等

## 核心API

- `hanspub_search(query, search_field="title", subject=None, journal=None, page=1, max_results=20)`
- `get_subject_journals(subject_name)` - 获取指定学科下的所有期刊列表
- `get_journal_info(journal_code)` - 获取期刊详细信息

## 注意事项

- 汉斯出版社采用开放获取模式，所有论文均可免费访问
- 网络请求包含重试机制和错误处理
- 检索结果按相关性排序，支持分页
- 中文关键词会自动进行URL编码处理

## 典型应用场景

1. **学术研究**：查找特定领域的最新研究成果
2. **文献综述**：按学科或关键词批量获取相关论文
3. **作者追踪**：查找特定作者的所有发表论文
4. **期刊浏览**：了解特定期刊的研究方向和内容
5. **引用管理**：获取标准格式的书目引用信息
