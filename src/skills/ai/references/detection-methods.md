## 第一层：核心检测方法详解

> **原理**：AI检测基于两个核心技术——困惑度（可预测性）和突发性（变化程度）

## 方法1：AI词汇密度分析（详细版）

### 词汇分类体系

**连接词类（高权重）：**
```
此外、同时、另外、再者、总体而言、综上所述、再者、加之
而且、并且、进一步、首先、其次、最后、首先、其次、再次
```

**形容词类（高权重）：**
```
重要的、关键的、核心的、显著的、深刻的、广泛的、全面的
必要的、本质的、根本的、基本的、典型的、突出的、明显的
```

**动词类（中权重）：**
```
体现、反映、展现、表明、涵盖、包含、包括、涉及、关联
影响、促进、推动、助力、改善、提升、增强、加强、强化
```

**虚词组合（高权重）：**
```
具有重要、提供参考、具有重要意义、具有价值、具有重要意义
具有重要的、关键的、核心的
```

### 权重计算

```
AI词汇密度 = (连接词数×1.5 + 形容词数×1.2 + 动词数×1.0 + 虚词组合数×2.0) / 总字数 × 1000
```

### 判断标准（细分）

| AI词汇密度 | 风险等级 | 检测特征 | 建议 |
|-----------|---------|---------|------|
| <20个/1000字 | 安全 | 自然写作 | 无需修改 |
| 20-30个/1000字 | 低风险 | 轻微AI特征 | 局部调整 |
| 30-40个/1000字 | 中风险 | 明显AI特征 | 需要修改 |
| 40-50个/1000字 | 高风险 | 强烈AI特征 | 大幅修改 |
| >50个/1000字 | 极高风险 | 几乎确定AI | 需要重写 |

### 实战检测步骤

**步骤1：选择检测样本**
- 选取连续1000字作为样本
- 避免选择引用、图表说明等非正文内容
- 包含完整的段落结构

**步骤2：逐类统计**
```
示例样本：
"此外，本研究采用重要的问卷方法，对大学生网络使用行为进行了
全面的调查。研究结果表明，网络使用时间与学习成绩呈显著负相关。
这一发现对于高校教育管理具有重要的参考价值。"

统计结果：
- 连接词：此外、此外(1)
- 形容词：重要的、全面的、显著的、重要的(4)
- 动词：采用、调查、表明、具有(4)
- 虚词组合：具有重要的(1)

加权得分：1×1.5 + 4×1.2 + 4×1.0 + 1×2.0 = 10.3
样本字数：85字
密度：10.3 / 85 × 1000 = 121个/1000字（极高风险）
```

**步骤3：定位问题词汇**
- 标记所有检测到的AI词汇
- 分析词汇分布是否均匀
- 识别高频重复词

**步骤4：针对性修改**
- 高密度区域优先修改
- 保留必要的学术表达
- 替换冗余词汇

## 方法2：句式突发性检查（详细版）

### 突发性计算公式

```
突发性指标 = 标准差(句长) / 平均句长

其中：
- 标准差越大，突发性越强（越像人类）
- 标准差越小，突发性越弱（越像AI）
```

### 判断标准（量化）

| 突发性指标 | 风险等级 | 特征描述 |
|-----------|---------|---------|
| CV < 0.10 | 极高风险 | 句子长度高度一致，典型AI特征 |
| 0.10 ≤ CV < 0.15 | 高风险 | 句子长度变化很小，AI特征明显 |
| 0.15 ≤ CV < 0.20 | 中风险 | 句子长度有一定变化，但仍较单调 |
| 0.20 ≤ CV < 0.25 | 低风险 | 句子长度变化较为自然 |
| CV ≥ 0.25 | 安全 | 句子长度变化丰富，人类写作特征 |

### 检测方法详解

**方法A：标准差计算法**

```
1. 统计连续20句的字数
2. 计算平均值：μ = (x₁ + x₂ + ... + x₂₀) / 20
3. 计算标准差：σ = √[(Σ(xᵢ - μ)²) / 20]
4. 计算变异系数：CV = σ / μ

示例：
句长序列：28, 29, 27, 28, 30, 26, 29, 28, 27, 29,
         28, 30, 26, 28, 29, 27, 28, 29, 28, 27

平均值 μ = 28.1
标准差 σ = 1.12
变异系数 CV = 1.12 / 28.1 = 0.040（极高风险）
```

**方法B：极差快速判断法**

```
1. 统计连续10句的字数
2. 找出最大值和最小值
3. 计算极差：R = 最大值 - 最小值

判断标准：
- R < 5：极高风险
- 5 ≤ R < 10：高风险
- 10 ≤ R < 15：中风险
- 15 ≤ R < 20：低风险
- R ≥ 20：安全
```

**方法C：相邻差异法**

```
1. 计算相邻句子的长度差异
2. 统计差异小于5的句子对数量

判断标准：
- 差异<5的句子对 > 80%：极高风险
- 差异<5的句子对 60-80%：高风险
- 差异<5的句子对 40-60%：中风险
- 差异<5的句子对 20-40%：低风险
- 差异<5的句子对 < 20%：安全
```

### 改写技巧

**增加突发性的方法：**

1. **混入短句**（5-10字）
   ```
   原句：本研究采用问卷调查法对大学生网络使用行为进行了深入分析。
   改写：本研究采用问卷调查法。分析对象是大学生网络使用行为。
   ```

2. **使用长句**（30+字）
   ```
   原句：这个影响在理工科更明显。
   改写：这一影响在理工科学生群体中表现得尤为突出——达到了12.1分的显著差异。
   ```

3. **加入破折号和括号**
   ```
   原句：网络使用时间与学习成绩呈负相关。
   改写：网络使用时间与学习成绩呈负相关——即上网时间越长，成绩越低。
   ```

4. **使用倒装和强调**
   ```
   原句：我们发现了一个有趣的现象。
   改写：有趣的是，我们发现了一个现象——
   ```

## 方法3：公式化结构检测（详细版）

### 摘要部分公式

**高风险公式：**
```
本文采用XXX方法，对XXX问题进行了研究。
首先，...其次，...最后，...
研究结果表明XXX。
本研究对于XXX具有重要的理论和实践意义。
```

**识别特征：**
- 开头必用"本文""本研究"
- 中间用"首先、其次、最后"连接
- 结尾必提"理论实践意义"

**降AI率策略：**
```
模板：以XXX为例。我们收集了XXX份样本，
用XXX方法分析后发现：XXX对XXX的影响达到XXX。
具体来说，当XXX时，结果会有XXX的变化。
但也存在XXX问题，这可能是后续研究的方向。
```

### 文献综述公式

**高风险公式：**
```
研究表明，XXX对XXX有重要影响。
学者们普遍认为XXX。
还有研究指出XXX。
此外，XXX等人的研究发现XXX。
```

**识别特征：**
- 无具体作者和年份引用
- 连续使用"研究表明""学者认为"
- 缺乏观点对比和批判

**降AI率策略：**
```
模板：关于XXX的影响，学者们有不同观点。
张三（2022）认为XXX，但李四（2023）的实验显示...
这种差异可能是因为...
笔者认为，现有研究在XXX方面还有待深入。
```

### 研究方法公式

**高风险公式：**
```
本研究采用问卷调查法。
按照标准流程进行数据收集和分析。
```

**识别特征：**
- 只说方法名，不描述细节
- 使用"标准流程""常规方法"等模糊表达
- 缺乏样本量、时间、工具等信息

**降AI率策略：**
```
模板：我们设计了包含15个问题的问卷。
2024年3月在XX学校发放，共回收XXX份，有效XXX份。
用SPSS 26.0进行数据分析时发现...
之所以选择问卷法，是因为...
```

### 结论公式

**高风险公式：**
```
综上所述，本研究...
本研究具有重要的理论和实践意义。
研究局限性在于...
```

**识别特征：**
- 必用"综上所述"开头
- 必提"理论实践意义"
- 局限性表述过于笼统

**降AI率策略：**
```
模板：简单来说，我们发现了三个主要结果：
一是...二是...三是...
当然，本研究也有局限：样本量较小，
仅限于XX地区，这可能是后续研究的方向。
```

## 组合检测策略

### 三维检测矩阵

```
              词汇密度
            低    中    高
        +-----+-----+-----+
突发性 高 | 安全 | 低   | 中   |
  低    | 低   | 中   | 高   |
        +-----+-----+-----+

        中 | 中   | 高   | 极高 |
  低    |     |     |     |
        +-----+-----+-----+

公式化  低 | 安全 | 低   | 中   |
程度   高 | 中   | 高   | 极高 |
        +-----+-----+-----+
```

### 综合评分

```
综合AI概率 = 词汇密度得分×0.4 + 突发性得分×0.35 + 公式化得分×0.25

其中：
- 词汇密度得分 = min(密度/50, 1.0)
- 突发性得分 = 1 - min(CV/0.25, 1.0)
- 公式化得分 = 公式化句子比例

判断标准：
- <30%：安全
- 30-60%：需要修改
- >60%：高风险
```
