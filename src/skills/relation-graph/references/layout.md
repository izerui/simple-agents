# 布局参考

## 1. 坐标系

- 画布原点：`(0, 0)`
- `x` 向右增大，向左减小
- `y` 向下增大，向上减小
- `x/y` 表示节点左上角位置
- 布局时必须同时考虑 `x`、`y`、`width`、`height`

## 2. 生成顺序

1. 先确定根节点和一级分区
2. 再确定每个分区向哪个方向展开
3. 先估算节点 `width/height`
4. 再填写 `x/y`

不要先写坐标再补尺寸。

## 3. 分区规则

- 一级分区优先均分到上、下、左、右四周
- 不要把一级分区长期压在单一方向
- 这种四周分区不只适用于中心节点；任何高连接度节点都应优先向上、下、左、右分区展开
- 每个分区都必须独立可见
- 分区之间不得重叠、压边或互相侵入
- 某个方向拥挤时，优先改到其他方向，不要继续往原方向堆

## 4. 展开规则

- 同组节点只能选一个主方向展开：横排或竖排，不要混用
- 步骤链优先竖向展开
- 枚举组优先横向展开；放不下时再改为竖向展开
- 同一个父节点子节点过多时，优先增加中间分组节点
- 不要把过多子节点直接压在同一层或同一轴线上
- 单一区域放不下时，开第二分区，不要靠缩小间距硬塞

## 5. 外挂规则

- 先决、案例、支持、策略等辅助节点放在主干外侧
- 外挂节点不要插入主链中间
- 案例和策略节点默认作为外围叶子节点，不反向回连主链

## 6. 连线规则

- 主展开优先水平或垂直连接
- 外挂节点优先斜向外侧连接
- 连线尽量短，不要跨多个分区
- 连线不要穿过主干核心区和密集节点区
- 如果一条补充关系会造成交叉或打断主链，优先改成分组、改层级或改为外围挂接

## 7. 尺寸规则

- 节点文字字号按 `12` 估算
- 连线关系文字字号按 `10` 估算
- 先按文本长度估算 `width/height`
- 文本长时优先加宽，避免压成很窄的高框
- 节点之间必须留出文字和连线的安全间距
