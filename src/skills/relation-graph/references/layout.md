## 一、目标与优先级

核心要求：

1. 骨架清楚
2. 分区明确
3. 节点不重叠
4. 连线尽量少交叉

执行优先级：

1. 先保证全局分区清楚
2. 再保证父子连线方向一致，子节点不得落到比父节点更靠中心的位置
3. 再减少局部交叉
4. 最后做视觉微调

---

## 二、坐标系与节点表示

### 2.1 画布坐标系

```text
        负Y（上）
         ↑
  负X ←──┼──→ 正X
  （左）  ↓  （右）
        正Y（下）

原点 (0, 0) = 整张图的视觉中心
```

### 2.2 节点占据区域

每个节点由左上角坐标和尺寸唯一确定：

```text
NodeX / NodeY    节点左上角坐标（最终输出必须是整数，允许负数）
NodeWidth        节点宽度
NodeHeight       节点高度

Right  = NodeX + NodeWidth      右边界 X
Bottom = NodeY + NodeHeight     下边界 Y

节点占据区域：X轴 [NodeX, Right] × Y轴 [NodeY, Bottom]
```

NodeX 和 NodeY 均可为负数。负 Y 表示节点位于画布中心上方，负 X 表示节点位于画布中心左侧。放射型布局中，上方区域的节点 NodeY 必须为负值。

摆放节点时，始终以"把这块矩形放在哪片区域"来思考，而不是只关注一个点。

### 2.3 相邻节点坐标推算

```text
// B 在 A 右侧，水平间距 gap：
B.NodeX = A.Right + gap
B.NodeY = A.NodeY + ((A.NodeHeight - B.NodeHeight) / 2)   → 取整

// B 在 A 左侧，水平间距 gap：
B.NodeX = A.NodeX - gap - B.NodeWidth
B.NodeY = A.NodeY + ((A.NodeHeight - B.NodeHeight) / 2)   → 取整

// B 在 A 下方，垂直间距 gap：
B.NodeX = A.NodeX + ((A.NodeWidth - B.NodeWidth) / 2)     → 取整
B.NodeY = A.Bottom + gap

// B 在 A 上方，垂直间距 gap：
B.NodeX = A.NodeX + ((A.NodeWidth - B.NodeWidth) / 2)     → 取整
B.NodeY = A.NodeY - gap - B.NodeHeight
```

## 三、数据字段

```text
NodeID                  节点唯一标识
NodeText                节点显示文本
NodeType                节点类型（见下）
ParentID                父节点ID；为空表示根节点或独立起点
RelationText            连线说明
NodeX / NodeY           节点左上角坐标
NodeWidth / NodeHeight  节点尺寸
NodeSemantic            节点语义说明
```

NodeType 取值：

```text
DK = 主体知识节点
PK = 结构/过程节点
FC = 案例/实验/练习节点
CS = 方法/建议/策略节点
```

### 3.1 多入边节点

同一节点可能在表中出现多行，表示它有多个来源节点。同一节点只能有一个坐标位置，多行记录共用同一组坐标。

```text
| 163 | 定时器/计数器原理 | DK | 35  | 包含   | -356 | -56 | 115 | 69 |
| 163 | 定时器/计数器原理 | DK | 170 | 包含   | -356 | -56 | 115 | 69 |
| 163 | 定时器/计数器原理 | DK | 5   | 是前提 | -356 | -56 | 115 | 69 |
```

## 四、节点类型的空间规则

### 4.1 DK / PK（主体骨架）

优先占据中心区和主轴区。

1. `DK` 优先靠近中心
2. 带后代的 `PK` 节点与最近兄弟节点的间距，应比无后代节点至少增加 20px
3. 仍有后续出边的节点不得放在当前簇外接矩形的最外层边界线上

### 4.2 FC / CS（外围补充节点）

不进入主干密集区。

1. 必须放在关联主节点的更外侧，不得插入两个主簇之间
2. `FC / CS` 节点的几何中心到画布原点的距离，必须大于其关联主节点的几何中心到画布原点的距离
3. 若 `FC / CS` 比关联的 `DK / PK` 更靠中心，则视为布局错误，必须重排

## 五、推荐间距与尺寸

间距参考值：

```text
一级节点距中心：        170 ~ 230
一级到二级主簇距离：    150 ~ 220
同组兄弟横向间距：      130 ~ 190
同组兄弟纵向间距：       70 ~ 110
簇与簇最小间距：        120 ~ 220
FC / CS 外挂距离：      160 ~ 260
```

节点尺寸参考值：

```text
根节点：    130~160 × 40~48
主干节点：  100~140 × 36~42
子节点：     80~120 × 32~38
外围节点：   90~130 × 32~38
```

使用原则：

1. 优先取各参数范围的上半区，不得主动压缩到最小值附近
2. 有后代的父节点周围留白应更多
3. 同一组兄弟节点间距尽量统一
4. 若整体显得密集，优先整体拉大主簇半径和簇间距，而不是只微调个别节点

## 六、布局总原则

### 6.1 先分区，后摆节点

布局以"分区/分块"为驱动，不允许逐个节点逐条边地决定位置。区块边界先于坐标存在，坐标只是区块划定的结果。

执行顺序：

1. 确定视觉锚点，划定画布中心区
2. 统计每个一级簇的后代规模，按规模大小划分各一级区块的方向和空间预算
3. 各一级区块内部再细分子区块，每个父节点的子簇作为一个独立区块处理
4. 区块划定完成后，再在各区块内摆放节点坐标
5. FC / CS 作为最外层附属区块，最后处理

### 6.2 后代规模决定分区优先级

先统计后代规模，再做区域决策，最后做坐标决策。

后代规模对分区的影响：

```text
后代节点数 1~3   → 可分配到斜角方向，区块空间紧凑
后代节点数 4~8   → 优先分配到主方向（上/左/右/下），区块空间适中
后代节点数 9~15  → 必须分配到主方向，一级锚点距中心 ≥ 200
后代节点数 > 15  → 独占主方向，一级锚点距中心 ≥ 280，可跨两个象限展开
```

规模大的簇优先占主方向（上/左/右/下），规模小的簇退让到斜角；若多个簇规模相近，按连接强度排序。

### 6.3 区块之间不得重叠

1. 各一级区块方向不同，中心区、左区、右区、上区、下区一眼可辨
2. 任意两个区块（含所有后代）的外接边界不得相交，区块间距 ≥ 120px；空间不足时优先整体拉开，不要只移动单个节点
3. 通过合理分区在布局阶段避免连线交叉，不依赖事后调整

### 6.4 子簇向外扩，不回穿中心

1. 子节点分配在父节点远离中心的那一侧，不得放到比父节点更靠近中心的位置
2. 子节点以父节点为锚点做放射式扩散，在父节点外侧的扇形区域内向多个方向展开，不得只排成单行、单列或只堆在父节点某一侧
3. 方向覆盖数下限：子节点数 2~3 时，至少覆盖 2 个方向；4~5 时，至少覆盖 3 个方向；≥6 时，至少覆盖 4 个方向
4. 若大多数子节点落在同一侧，必须重新分散到其他可用方向
5. 子树整体不得折返跨过父节点向中心方向延伸

## 七、布局执行流程

### Step 1：识别结构骨架

整理以下信息：

1. 哪些节点 `ParentID` 为空（根节点）
2. 每个节点的入边、出边列表
3. 哪些节点是高连接度节点、多入边节点
4. 每个一级节点的后代规模（直接子节点数 + 所有子孙节点总数）

确定视觉锚点：

- 有唯一根节点 → 用该根节点作为视觉锚点，放置在画布中心附近
- 无根节点或有多个根节点 → 选连接度（出边 + 入边总数）最高的节点；若并列，选后代规模最大的
- 多个完全独立的子图 → 每个子图各自选一个锚点，分区排列，不强行合并

### Step 2：确定布局方向策略

只选一种，不混用：

1. **放射型**：有明显中心锚点，一级节点向四周扩散
2. **主轴型**：存在明显主线流程，主流程沿左到右排成主轴，辅助簇挂在两侧
3. **对峙型**：两大类知识左右对照，中间放总主题

### Step 3：自底向上计算每个簇的空间预算

不允许跳过。在分配任何坐标之前，必须先算出每个簇的外接矩形尺寸。

叶子节点：

```text
簇宽 = NodeWidth
簇高 = NodeHeight
```

有子节点的父节点，按子节点排列方向分三种情况：

**横向排列**（子节点在父节点上方或下方）：

```text
子簇总宽 = sum(所有子节点簇宽) + (子节点数 - 1) × 横向间距
子簇总高 = max(所有子节点簇高)

本簇总宽 = max(NodeWidth, 子簇总宽)
本簇总高 = NodeHeight + 纵向间距(80~110) + 子簇总高
```

**纵向排列**（子节点在父节点左方或右方）：

```text
子簇总高 = sum(所有子节点簇高) + (子节点数 - 1) × 纵向间距
子簇总宽 = max(所有子节点簇宽)

本簇总高 = max(NodeHeight, 子簇总高)
本簇总宽 = NodeWidth + 横向间距(130~160) + 子簇总宽
```

**放射式多方向展开**（子节点分布在多个方向）：

```text
本簇总宽 = 左侧子簇最大宽 + NodeWidth + 右侧子簇最大宽 + 2 × 横向间距
本簇总高 = 上方子簇最大高 + NodeHeight + 下方子簇最大高 + 2 × 纵向间距
```

执行要求：

1. 自底向上计算，先算叶子节点，再算其父节点，最后算一级节点的完整区块
2. 相邻一级区块之间必须预留簇间距（≥ 120px）
3. 一级区块尺寸估算完成后，才能确定各一级节点的锚点坐标

区域边界参考：

```text
左侧簇：中心 x < -120    右侧簇：中心 x >  120
上侧簇：中心 y < -100    下侧簇：中心 y >  100
```

### Step 4：分配一级节点方向和锚点坐标

在填写任何坐标之前，必须先在内部完成方向规划（不需要向用户显式输出）。

内部规划模板：

```text
- 视觉锚点：[节点名] → 画布中心附近
- [一级节点A] → 左侧，后代规模 N，区块预估 W×H，左上角约 (-X, -H/2)
- [一级节点B] → 右侧，后代规模 N，区块预估 W×H，左上角约 (X, -H/2)
- [一级节点C] → 上方，后代规模 N，区块预估 W×H，左上角约 (-W/2, -Y)
- [一级节点D] → 下方，后代规模 N，区块预估 W×H，左上角约 (-W/2, Y)
确认：所有一级节点方向不同 ✓
确认：规模大的簇已分配到主方向 ✓
```

一级节点数量与方向的默认对应：

```text
1 个  →  下方
2 个  →  左、右
3 个  →  左、右、下
4 个  →  上、左、右、下
5 个  →  上、左、右、下、左下（或右下）
6 个  →  上、左上、左、右、右上、下
7+    →  八方向轮流分配，优先填满上/左/右/下，再填斜角
```

执行规则：

1. 方向规划必须先于坐标表格生成，不允许先写表格再补规划
2. 若出现 2 个以上一级节点方向相同，必须先修改规划再继续
3. 按后代规模从大到小依次分配方向，规模大的优先占主方向
4. 锚点距中心距离：后代 1~3 个取 170~200；后代 4~8 个取 200~260；后代 ≥9 个取 280 以上
5. 确保相邻一级区块间距 ≥ 120px

### Step 5：逐个父节点生成子簇坐标

每次处理一个父节点，按父节点所在方向向外扩散：

```text
父节点在左侧 → 子节点优先分配到：左上、左、左下
父节点在右侧 → 子节点优先分配到：右上、右、右下
父节点在上侧 → 子节点优先分配到：左上、上、右上
父节点在下侧 → 子节点优先分配到：左下、下、右下
父节点在中心 → 子节点向四方向分配
```

子节点数量与方向对应（相对父节点）：

```text
1 个  →  沿父节点当前方向继续外扩
2 个  →  父节点方向的两侧（如父在左：左上、左下）
3 个  →  父节点方向 + 两侧（如父在左：左上、左、左下）
4+    →  向多个方向放射式扩散；空间不足时可跨相邻象限继续外扩
```

坐标推算见第八章。若子节点自身还有后代，gap 必须额外增加其子簇总宽/总高，防止孙节点与父节点区域交叉。不得把所有子节点全部放在父节点正下方。

每摆完一个父节点的全部子节点后，立即做局部验证（三条，全部满足才继续）：

```text
验证 A：方向覆盖数
  子节点数 2~3 → 至少覆盖 2 个方向
  子节点数 4~5 → 至少覆盖 3 个方向
  子节点数 ≥6  → 至少覆盖 4 个方向
  不满足 → 立即重新分配，不允许继续

验证 B：无节点比父节点更靠近画布中心
  若任一子节点到原点距离 < 父节点到原点距离，必须向外推移

验证 C：无区域交叉
  与每个已有节点区域对比，四项至少满足一项才无重叠：
    A.Right + 20 <= B.NodeX  或  B.Right + 20 <= A.NodeX
    或  A.Bottom + 12 <= B.NodeY  或  B.Bottom + 12 <= A.NodeY
  若区域交叉 → 沿当前方向继续向外推移，直到无交叉
```

验证不通过时原地修正，不要继续摆放后续父节点。

### Step 6：单独处理多入边节点

1. 先计算其主要来源节点的视觉重心
2. 将节点放在这些来源之间或其外侧，只保留一个坐标位置
3. 不得塞进某个单一簇的中心
4. 若还有后代：优先沿出边数量最多的方向继续展开；若并列，沿离中心更远的方向展开

### Step 7：最后放置 FC / CS

1. 放在关联主节点的更外侧，距离 160~260px
2. 与关联主簇方向一致，不得进入任意两个一级主簇之间的通道区域
3. 其节点区域必须完全落在关联主节点区域的外侧

## 八、局部坐标公式

P = 父节点，C = 子节点。

### 8.1 父节点在左侧

子节点向左扩散：左上、左、左下。

```text
// 左方（垂直居中）
C.NodeX = P.NodeX - gap_h - C.NodeWidth
C.NodeY = P.NodeY + ((P.NodeHeight - C.NodeHeight) / 2)  → 取整

// 左上
C.NodeX = P.NodeX - gap_h×0.8 - C.NodeWidth
C.NodeY = P.NodeY - gap_v - C.NodeHeight

// 左下
C.NodeX = P.NodeX - gap_h×0.8 - C.NodeWidth
C.NodeY = P.Bottom + gap_v

gap_h：130~160    gap_v：80~110
```

只有 1 个子节点：`C.NodeX = P.NodeX - 150 - C.NodeWidth`，`C.NodeY` 垂直居中对齐。

### 8.2 父节点在右侧

子节点向右扩散：右上、右、右下。

```text
// 右方（垂直居中）
C.NodeX = P.Right + gap_h
C.NodeY = P.NodeY + ((P.NodeHeight - C.NodeHeight) / 2)  → 取整

// 右上
C.NodeX = P.Right + gap_h×0.8
C.NodeY = P.NodeY - gap_v - C.NodeHeight

// 右下
C.NodeX = P.Right + gap_h×0.8
C.NodeY = P.Bottom + gap_v

gap_h：130~160    gap_v：80~110
```

只有 1 个子节点：`C.NodeX = P.Right + 150`，`C.NodeY` 垂直居中对齐。

### 8.3 父节点在上侧

子节点向上扩散：左上、上、右上。

```text
// 上方（水平居中）
C.NodeX = P.NodeX + ((P.NodeWidth - C.NodeWidth) / 2)    → 取整
C.NodeY = P.NodeY - gap_v - C.NodeHeight

// 左上
C.NodeX = P.NodeX - gap_h×0.6 - C.NodeWidth
C.NodeY = P.NodeY - gap_v - C.NodeHeight

// 右上
C.NodeX = P.Right + gap_h×0.6
C.NodeY = P.NodeY - gap_v - C.NodeHeight

gap_v：80~110    gap_h：100~140
```

只有 1 个子节点：水平居中，`C.NodeY = P.NodeY - 100 - C.NodeHeight`。

### 8.4 父节点在下侧

子节点向下扩散：左下、下、右下。

```text
// 下方（水平居中）
C.NodeX = P.NodeX + ((P.NodeWidth - C.NodeWidth) / 2)    → 取整
C.NodeY = P.Bottom + gap_v

// 左下
C.NodeX = P.NodeX - gap_h×0.6 - C.NodeWidth
C.NodeY = P.Bottom + gap_v

// 右下
C.NodeX = P.Right + gap_h×0.6
C.NodeY = P.Bottom + gap_v

gap_v：80~110    gap_h：100~140
```

只有 1 个子节点：水平居中，`C.NodeY = P.Bottom + 100`。

### 8.5 父节点在斜角时

斜角方向同时叠加水平和垂直位移，分别参照 8.1~8.4 中对应方向的公式，两个方向间距均不得缩减。不得把全部子节点压成单列或单行。

### 8.6 同方向多个子节点的对齐方式

上下方向（水平展开）：

```text
同组总宽 = sum(所有子节点宽) + (节点数-1) × 横向间距
第一个节点 NodeX = P.NodeX + ((P.NodeWidth - 同组总宽) / 2)  → 取整
之后：下一个.NodeX = 上一个.Right + 横向间距
```

左右方向（垂直展开）：

```text
同组总高 = sum(所有子节点高) + (节点数-1) × 纵向间距
第一个节点 NodeY = P.NodeY + ((P.NodeHeight - 同组总高) / 2)  → 取整
之后：下一个.NodeY = 上一个.Bottom + 纵向间距
```

同方向有叶子节点与带后代节点混合时：叶子节点整齐并排，带后代节点做纵向堆叠并在外扩方向预留空间；`DK / PK` 靠内侧，`FC / CS` 靠外侧。

### 8.7 通用规则

1. 父节点有 2 个以上子节点时，必须向多个方向分配，不得全堆在同一侧
2. 子节点自身有后代时，必须先算出其子簇尺寸（Step 3），再以子簇尺寸为基础确定偏移量，不得只按子节点本身尺寸偏移
3. 同一方向若有多个子节点并排，间距必须统一，不允许随机漂移

## 九、硬性规则

1. 不得先按单条边独立决定方向再回头拼整体布局；必须先完成一级簇分区，再分配局部方向
2. 必须先定分区和区块预算（Step 3），再给节点定坐标
3. 子节点不得大规模跨过父节点回穿中心
4. `FC / CS` 只能放在关联主节点外侧，不得塞进主干缝隙
5. 同方向兄弟节点必须共用同一条基准线，并保持统一间距
6. 多入边节点只能有一个坐标位置
7. 所有输出坐标必须是左上角整数坐标
8. 必须先完成内部布局规划（Step 4）：在填坐标前先确定每个一级节点的方向、区块尺寸和左上角坐标；2 个以上一级节点不允许方向相同

## 十、执行步骤速查

按以下顺序执行，不允许跳步：

1. 找出根节点、一级主干节点、多入边节点；统计每个一级节点的后代规模，按规模从大到小排序；选定骨架模板（放射型 / 主轴型 / 对峙型），不混用
2. 自底向上计算每个簇的空间预算（Step 3），不允许跳过
3. 为一级节点分配方向和区块坐标（Step 4），内部完成，不向用户输出
4. 逐个父节点生成子簇坐标，每摆完一个父节点立即做三项局部验证（Step 5）
5. 放置多入边节点（Step 6）
6. 放置 FC / CS 节点（Step 7）
7. 输出坐标，所有 NodeX / NodeY 必须是整数
