## 一、核心目标

**避免连线交叉，节点不重叠，连接关系清晰，视觉整洁。**

---

## 二、画布与坐标系

```
画布是以中心点为原点的无边框二维平面：

        负Y（上）
         ↑
  负X ←──┼──→ 正X
  （左）  ↓  （右）
        正Y（下）

原点 (0, 0) = 画布视觉中心

节点坐标 (X, Y) = 节点矩形左上角相对于画布中心的偏移量
节点占用范围：
  X方向：[X,   X + Width ]
  Y方向：[Y,   Y + Height]
节点中心点：
  centerX = X + Width  / 2
  centerY = Y + Height / 2
```

---

## 三、基础换算公式

```
已知左上角坐标(X, Y)和尺寸(W, H)：

  右边界   = X + W
  下边界   = Y + H
  中心X    = X + W / 2
  中心Y    = Y + H / 2

已知期望中心点(cX, cY)，反算左上角：
  X = cX - W / 2
  Y = cY - H / 2
```

## 四、数据格式说明

```
| NodeID | NodeText | NodeType | ParentID | RelationText |
| NodeX  | NodeY    | NodeWidth| NodeHeight| NodeSemantic |
```

**字段说明：**

```
NodeID        节点唯一标识（数字或字符串）
NodeText      节点显示文本
NodeType      节点类型：
                DK = 知识节点（核心概念）
                PK = 过程节点（结构化知识框架）
                FC = 拓展节点（案例/实验/延伸）
                CS = 策略节点（方法/建议）
ParentID      连线来源节点ID（谁连向我）
              同一节点有多个入边时该节点出现多行，
              每行ParentID不同，X/Y/W/H相同
RelationText  连线标注文字
NodeX         节点矩形左上角X坐标
NodeY         节点矩形左上角Y坐标
NodeWidth     节点矩形宽度
NodeHeight    节点矩形高度
NodeSemantic  节点语义标注
```

```

## 五、图结构分析（布局前必做）

### 5.1 整理每个节点的连接情况

```
对每个节点记录：
  入边列表：哪些节点连向它（来自哪些ParentID）
  出边列表：它连向哪些节点（它作为ParentID出现的目标）
  连接度   = 入边数 + 出边数
```

### 5.2 统计每个节点的方向占用情况

```
对每个节点维护一张方向占用表：

  方向     状态
  ──────────────
  上(Top)   空闲 / 入边占用 / 出边占用
  下(Bottom)空闲 / 入边占用 / 出边占用
  左(Left)  空闲 / 入边占用 / 出边占用
  右(Right) 空闲 / 入边占用 / 出边占用

初始状态：全部空闲
随着入边和出边的确定，逐步更新状态
```

### 5.3 识别连接簇

```
将频繁互相连接的节点归为同一簇，同簇节点集中摆放。

簇的空间包围盒：
  左边界 = MIN(节点.X)
  右边界 = MAX(节点.X + 节点.Width)
  上边界 = MIN(节点.Y)
  下边界 = MAX(节点.Y + 节点.Height)

簇与簇之间保留间距：≥ 50px
```

### 5.4 节点类型与空间分配

```
DK：图的主体骨架，优先确定位置
PK：结构化框架，需要较大展开空间
FC：案例/实验，放在关联节点外侧边缘
CS：方法/建议，放在关联节点旁侧边角
```

## 六、核心布局规则：出边方向分配

**这是避免连线交叉最重要的规则。**

### 6.1 基本原则

```
每个节点的连线方向资源共有四个：上、下、左、右

规则一：优先使用完全空闲的方向
  → 既没有入边也没有出边的方向，是最优选择
  → 可以保证新出边与已有连线不产生交叉

规则二：出边方向必须避开入边方向
  → 入边从哪个方向进来，出边不能从同一方向出去

规则三：出边方向必须避开已分配的其他出边方向
  → 每条出边尽量占用一个独立方向
  → 同一方向上不应同时存在多组不相关的出边

规则四：向四周均匀展开
  → 优先将出边分散到不同方向
  → 避免所有出边挤在同一方向造成密集交叉
```

### 6.2 方向判断标准

```
判断节点B相对于节点A的方位：

  B在A的上方：B.Y + B.Height ≤ A.Y
  B在A的下方：B.Y ≥ A.Y + A.Height
  B在A的左方：B.X + B.Width ≤ A.X
  B在A的右方：B.X ≥ A.X + A.Width

若同时满足两个条件（既偏上又偏右等对角情况）
→ 以偏移量较大的方向为主方向：
    水平偏移 = |A.centerX - B.centerX|
    垂直偏移 = |A.centerY - B.centerY|
    水平偏移 > 垂直偏移 → 主方向为左或右
    垂直偏移 > 水平偏移 → 主方向为上或下
```

### 6.3 出边方向优先级

```
为当前节点N的某条出边选择方向时，
按以下优先级从高到低选择：

优先级1（最优）：完全空闲方向
  → 该方向既无入边也无出边
  → 选这个方向不会与任何已有连线交叉

优先级2：只有同类出边的方向
  → 该方向已有出边，但没有入边
  → 可以与已有出边共享方向，放在同侧

优先级3（最差）：已有入边的方向
  → 该方向已被入边占用
  → 尽量避免，除非所有方向都已有入边

选择逻辑：
  可用方向 = {上、下、左、右}
  空闲方向 = 可用方向 - 入边方向 - 出边方向

  if 空闲方向不为空：
      → 从空闲方向中选择
      → 若有多个空闲方向，选能让整体布局最均衡的那个

  elif 只剩有出边的方向：
      → 选出边数量最少的方向，与已有出边共享

  else 所有方向都有入边：
      → 选入边数量最少的方向叠加出边
      → 将新出边节点放在已有节点的外侧延伸位置
```

### 6.4 方向分配流程

```
对当前节点N，按以下步骤逐条分配出边方向：

Step 1  初始化方向占用表
        上：空闲  下：空闲  左：空闲  右：空闲

Step 2  标记入边方向
        → 找出所有ParentID节点（入边来源）
        → 判断每个来源节点相对于N的方位
        → 将对应方向标记为"入边占用"

        更新方向占用表：
        上：入边  下：空闲  左：空闲  右：空闲（示例）

Step 3  按类型排序待分配出边
        → DK/PK 类型的出边优先分配
        → FC/CS 类型的出边后分配

Step 4  逐条分配出边方向
        → 按优先级6.3选择当前最优空闲方向
        → 分配后将该方向更新为"出边占用"
        → 继续下一条出边

        每分配一条后更新：
        已占用方向 = 入边方向 ∪ 已分配出边方向
        空闲方向   = {上下左右} - 已占用方向

Step 5  出边数量超过可用方向数时
        → 将多条出边合并到同一方向内排列
        → DK/PK 在内侧（靠近N），FC/CS 在外侧
        → 同方向内根据子节点是否有进一步出边
          决定水平并排还是垂直堆叠（见第七节）
```

### 6.5 典型场景示例

**场景一：1条入边，4条出边**
```
节点A：入边从上方来，出边4条

  初始：上=入边  下=空闲  左=空闲  右=空闲
  空闲方向：下、左、右

  分配：
    出边1(DK) → 下（空闲，优先）→ 下=出边
    出边2(DK) → 左（空闲，优先）→ 左=出边
    出边3(PK) → 右（空闲，优先）→ 右=出边
    出边4(FC) → 下（无空闲，与出边1共享）

        [Parent]
           ↓ 入边
          [A]
   ↙左   ↓下    ↘右
  [出2] [出1]  [出3]
        [出4]
```

**场景二：2条入边来自不同方向，3条出边**
```
节点B：入边从上方和右方来，出边3条

  初始：上=入边  下=空闲  左=空闲  右=入边
  空闲方向：下、左

  分配：
    出边1(DK) → 下（空闲，优先）→ 下=出边
    出边2(DK) → 左（空闲，优先）→ 左=出边
    出边3(FC) → 下（无空闲，与出边1共享，放外侧）

  [RightParent] →→ [B] ←← [TopParent]
                    ↓出1  ↙左出2
                   [出1] [出2]
                   [出3]
```

**场景三：四个方向都有入边（高连接中心节点）**
```
节点C：四个方向都有入边，还有2条出边

  初始：上=入边  下=入边  左=入边  右=入边
  空闲方向：无

  → 选入边数量最少的方向（假设下方只有1条入边）
  → 将出边节点放在下方已有入边节点的外侧延伸
  → 或利用对角位置（斜向）放置FC/CS节点
```

**场景四：某方向有多条出边**
```
节点D 向右方有4条出边：

  判断排列方式：
    出边节点还有进一步出边 → 垂直堆叠（为其子节点留横向空间）
    出边节点是叶节点       → 水平并排或垂直堆叠均可

  垂直堆叠示例：
    [D] →→ [出1]
        →→ [出2]
        →→ [出3]
        →→ [出4]
    （4个节点X相同，Y依次递增）
```

### 6.6 方向与坐标范围对应

```
出边向下方：
  出边节点.Y ≥ 当前节点.Y + 当前节点.Height + 垂直间距
  垂直间距推荐：60 ~ 80px
  出边节点.X 以当前节点中心X为基准水平展开

出边向上方：
  出边节点.Y + 出边节点.Height ≤ 当前节点.Y - 垂直间距
  垂直间距推荐：60 ~ 80px
  出边节点.X 以当前节点中心X为基准水平展开

出边向右方：
  出边节点.X ≥ 当前节点.X + 当前节点.Width + 水平间距
  水平间距推荐：40 ~ 80px
  出边节点.Y 以当前节点中心Y为基准垂直展开

出边向左方：
  出边节点.X + 出边节点.Width ≤ 当前节点.X - 水平间距
  水平间距推荐：40 ~ 80px
  出边节点.Y 以当前节点中心Y为基准垂直展开
```

## 七、坐标计算方法

### 7.1 水平展开：居中对齐父节点

```
适用：出边方向为上方或下方

父节点中心X = 父节点.X + 父节点.Width / 2

同组出边节点总宽度：
  totalWidth = Σ(节点.Width) + (节点数-1) × 水平间距

第一个节点左上角X：
  startX = 父节点中心X - totalWidth / 2

后续节点依次向右：
  节点[0].X = startX
  节点[1].X = 节点[0].X + 节点[0].Width + 水平间距
  节点[2].X = 节点[1].X + 节点[1].Width + 水平间距
  ...

水平间距推荐：20 ~ 30px
```

### 7.2 垂直展开：居中对齐父节点

```
适用：出边方向为左方或右方

父节点中心Y = 父节点.Y + 父节点.Height / 2

同组出边节点总高度：
  totalHeight = Σ(节点.Height) + (节点数-1) × 垂直间距

第一个节点左上角Y：
  startY = 父节点中心Y - totalHeight / 2

后续节点依次向下：
  节点[0].Y = startY
  节点[1].Y = 节点[0].Y + 节点[0].Height + 垂直间距
  节点[2].Y = 节点[1].Y + 节点[1].Height + 垂直间距
  ...

垂直间距推荐：10 ~ 20px
```

### 7.3 同方向多条出边的排列选择

```
同一方向上有多条出边节点时，选择排列方式：

情况A：出边节点是叶节点（无进一步出边）
  → 水平并排（上下方向展开时）
  → 垂直堆叠（左右方向展开时）

情况B：出边节点还有进一步出边
  → 垂直堆叠（上下方向展开时，为子节点留水平空间）
  → 垂直堆叠（左右方向展开时）

情况C：出边节点中混合有DK/PK和FC/CS
  → DK/PK放内侧（靠近父节点）
  → FC/CS放外侧（远离父节点）
```

### 7.4 多方向混合展开

```
出边节点分配到了多个不同方向时：

1. 按方向将出边节点分组
2. 每组独立按 7.1 或 7.2 计算坐标
3. 检查各方向的节点是否与其他方向节点产生重叠
4. 若有重叠，整体平移冲突方向的节点组
```

## 八、冲突检测

### 8.1 节点矩形重叠

```
节点A：X区间[A.X, A.X+A.W]，Y区间[A.Y, A.Y+A.H]
节点B：X区间[B.X, B.X+B.W]，Y区间[B.Y, B.Y+B.H]

重叠条件（两方向同时满足）：
  X重叠：A.X < B.X+B.W+minGap  且  A.X+A.W+minGap > B.X
  Y重叠：A.Y < B.Y+B.H+minGap  且  A.Y+A.H+minGap > B.Y

推荐 minGap：水平20px，垂直10px
```

### 8.2 簇区域边界重叠

```
两个簇的包围盒有重叠
→ 整体平移其中一个簇的所有节点
→ 直到两个包围盒间距 ≥ 50px
```

### 8.3 连线路径穿越节点

```
连线 A→B 为直线时，检查是否有节点C被穿越：

  节点C中心到线段AB的垂直距离 < C.Width/2 或 C.Height/2
  且 C在AB线段的投影范围内
  → 节点C被穿越，移动C或调整A/B位置使连线绕开
```

### 8.4 入边与出边连线交叉

```
当一个节点同时有多条入边和多条出边时：

检查方法：
  将所有入边线段和出边线段两两比对，判断是否相交

若相交：
  → 重新检查出边方向分配是否正确执行了规则6.1
  → 出边方向是否真正选择了空闲方向
  → 调整冲突的出边节点到另一空闲方向
```

## 九、微调与收尾

```
1. FC/CS 节点处理
   → 紧靠关联DK/PK节点的出边方向末端外侧
   → 不插入核心连接密集区
   → 同类节点Y坐标尽量对齐

2. 多入边节点位置
   → 位置应兼顾所有来源节点的视觉重心
   → X ≈ 所有来源节点中心X的平均值
   → Y ≈ 所有来源节点在主要入边方向上的延伸位置
   → 确认后重新检查该节点的出边方向是否仍然合理

3. 坐标取整
   → X/Y 取整为整数，避免小数坐标
   → 小数坐标（如 -406.925...）是拖拽产生的，应修正

4. 视觉居中检查
   → 所有节点X范围中点应接近0
   → 所有节点Y范围中点应接近0

5. 间距参数参考
   水平节点间距（同方向兄弟节点）：  20 ~ 30 px
   垂直层间距（上下方向父子）：      60 ~ 80 px
   垂直排列子节点间距：              10 ~ 20 px
   水平方向展开间距（左右父子）：    40 ~ 80 px
   簇与簇之间间距：                  50 ~ 150 px
```

## 十、完整流程速查

```
Step 1  读取表格数据
        → 整理每个节点的出边列表、入边列表、连接度
        → 识别多入边节点、无入边节点

Step 2  识别连接簇
        → 将频繁互联节点归为同一簇
        → FC/CS节点单独标记

Step 3  区域分配
        → 高连接度节点放中心
        → 各簇分配独立空间区域
        → FC/CS节点安排在关联节点出边末端

Step 4  逐节点分配出边方向
        → 初始化方向占用表（全空闲）
        → 标记入边占用方向
        → 优先选择完全空闲方向分配出边
        → 每分配一条出边立即更新方向占用表
        → 出边数超过空闲方向时同方向内分层排列

Step 5  计算坐标
        → 出边向上/下：水平居中对齐父节点中心X
        → 出边向左/右：垂直居中对齐父节点中心Y
        → 多方向混合时各组独立计算后检查重叠

Step 6  冲突检测
        → 矩形重叠检测
        → 簇区域边界重叠检测
        → 连线路径穿越检测
        → 入边与出边连线交叉检测

Step 7  微调收尾
        → FC/CS节点归出边末端外侧
        → 多入边节点取视觉重心
        → 坐标取整（无小数）
        → 视觉居中检查
        → 间距检查
```

## 十一、操作前自检清单

```
□ 每个节点的出边列表和入边列表是否已整理清楚？
□ 多入边节点是否已识别（表格中同ID多行）？
□ 无入边节点（ParentID为空）是否已标记？
□ 每个节点是否已初始化方向占用表？
□ 入边方向是否已正确标记到占用表？
□ 每条出边是否优先选择了完全空闲方向？
□ 每分配一条出边后是否立即更新了方向占用表？
□ 出边数量超过空闲方向时是否合理合并分层？
□ 各簇的空间区域是否互不重叠（≥50px间距）？
□ 出边向上/下时：是否居中对齐了父节点中心X？
□ 出边向左/右时：是否居中对齐了父节点中心Y？
□ 所有节点矩形是否互不重叠（含最小间距）？
□ 入边与出边连线是否存在交叉？
