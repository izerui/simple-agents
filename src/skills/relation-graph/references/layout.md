## 一、核心目标

**避免连线交叉，节点不重叠，连接关系清晰，视觉整洁。**

---

## 二、画布与坐标系

```
画布是以中心点为原点的无边框二维平面：

        负Y（上）
          ↑
  负X ←──┼──→ 正X
  （左）  ↓  （右）
        正Y（下）

原点 (0, 0) = 画布视觉中心

节点坐标 (X, Y) = 节点矩形左上角相对于画布中心的偏移量
节点占用范围：
  X方向：[X,   X + Width ]
  Y方向：[Y,   Y + Height]
节点中心点：
  centerX = X + Width  / 2
  centerY = Y + Height / 2
```

**示例（来自实际数据）：**
```
节点 X=-296, Y=-157, Width=72, Height=26
→ 左上角在画布中心左上方
→ 占用X范围：[-296, -224]
→ 占用Y范围：[-157, -131]
→ 节点中心：(-260, -144)

节点 X=153, Y=181, Width=72, Height=42
→ 左上角在画布中心右下方
→ 占用X范围：[153, 225]
→ 占用Y范围：[181, 223]
→ 节点中心：(189, 202)
```

## 三、基础换算公式

```
已知左上角坐标(X, Y)和尺寸(W, H)：

  右边界   = X + W
  下边界   = Y + H
  中心X    = X + W / 2
  中心Y    = Y + H / 2

已知期望中心点(cX, cY)，反算左上角：
  X = cX - W / 2
  Y = cY - H / 2
```

## 四、数据格式说明

布局操作基于以下 Markdown 表格格式：

```
| NodeID | NodeText | NodeType | ParentID | RelationText | 
| NodeX  | NodeY    | NodeWidth| NodeHeight| NodeSemantic |
```

**关键字段说明：**

```
NodeID        节点唯一标识，可以是数字或字符串
NodeText      节点显示文本
NodeType      节点类型：
                DK = 知识节点（核心概念）
                PK = 过程节点（结构化知识框架）
                FC = 拓展节点（案例/实验/延伸）
                CS = 策略节点（方法/建议）
ParentID      连线来源节点的ID（即"谁连向我"）
              同一节点有多个入边时，该节点会出现多行，
              每行 ParentID 不同，但 X/Y/W/H 相同
RelationText  连线上的标注文字
NodeX         节点矩形左上角X坐标
NodeY         节点矩形左上角Y坐标
NodeWidth     节点矩形宽度
NodeHeight    节点矩形高度
NodeSemantic  节点语义标注
```

**多入边节点示例（同一节点出现多行）：**
```
| 163 | 定时器/计数器原理 | DK | 35  | 包含 | -356 | -56 | 115 | 69 |
| 163 | 定时器/计数器原理 | DK | 170 | 包含 | -356 | -56 | 115 | 69 |
| 163 | 定时器/计数器原理 | DK | 5   | 是前提 | -356 | -56 | 115 | 69 |

→ 节点163有3条入边，来自节点35、170、5
→ 节点163只有一个位置，X/Y/W/H在所有行中相同
```

**无入边节点（ParentID为空）：**
```
| 173 | 计算若干个机器周期的时间 | DK |  |  | -17 | -276 | 158 | 60 |

→ 该节点无入边，是图中的"起点"节点
```

## 五、图结构分析（布局前必做）

### 5.1 整理连接关系

从表格数据中提取每个节点的连接情况：

```
对每个节点记录：
  出边：该节点作为 ParentID 出现的所有行
        → 它连向哪些节点
  入边：该节点自身ID出现时对应的 ParentID
        → 哪些节点连向它
  连接度 = 出边数 + 入边数
```

**示例（来自实际数据）：**
```
节点 46（工作方式）：
  入边来自：177(方式0)、179(方式1)、181(方式2)、183(方式3)、292(支持)
  出边：作为ParentID连向其他节点
  连接度较高 → 应放在连接密集区的中心位置

节点 173（计算若干个机器周期的时间）：
  ParentID 为空 → 无入边
  出边：被 169(单片机定时) 引用
  连接度低 → 可放在图形边缘
```

### 5.2 识别连接簇

将频繁互相连接的节点归为同一簇，
同簇节点在空间上集中摆放。

```
识别方法：
  从任意节点出发，沿连线方向扩展，
  将直接相连的节点归入同一簇，
  直到没有新节点加入为止。

簇的空间区域：
  该簇所有节点占用的矩形包围盒
  左边界 = MIN(节点.X)
  右边界 = MAX(节点.X + 节点.Width)
  上边界 = MIN(节点.Y)
  下边界 = MAX(节点.Y + 节点.Height)
```

**示例（来自实际数据）：**
```
定时器应用簇：
  3-hwcmM(定时器/计数器应用)
  → 14(设置工作方式) → 235(考虑实际需求选择)
  → 15(设置模式)     → 269(X=M-C)
  → 17(置数)
  → 19(中断设置)
  → 189(定时器/计数器启动)
  → 285(优先级设置)  → 286(合理规划)
  集中在画布左侧区域：X约[-820, -520]

工作方式簇：
  46(工作方式)
  → 177(方式0) → 216(13位加计数器)
  → 179(方式1) → 218(16位加计数器)
  → 181(方式2) → 220(8位重装初值的计数器)
  → 183(方式3) → 222(2个8位定时器和1个计数器)
  集中在画布右侧区域：X约[153, 670]
```

### 5.3 识别节点类型分布

```
DK 知识节点：图的主体骨架，优先确定位置
PK 过程节点：结构化框架，通常连接多个子节点，
             需要较大的垂直展开空间
FC 拓展节点：案例/实验，放在对应知识节点附近边缘
CS 策略节点：方法/建议，放在对应节点旁侧边角
```

## 六、区域分配策略

### 6.1 以高连接度节点为中心

```
连接度最高的节点 → 放在画布中心区域
其他节点按连接关系向外展开

实际数据中：
  节点 163（定时器/计数器原理）连接度=5 → 放在中心偏左
  节点 3-hwcmM（定时器应用）   连接度=4 → 放在中心偏左下
  节点 46（工作方式）          连接度=5 → 放在中心偏右
```

### 6.2 各簇独立区域，互不侵入

```
区域划分原则：

  连接密集的簇 → 分配较大区域（上下方向展开）
  连接稀疏的簇 → 分配较小区域（紧凑排列）
  FC/CS节点   → 紧靠关联节点的外侧边缘
  无入边节点   → 放在关联节点的延伸末端

簇与簇之间保留间距：≥ 50px
```

### 6.3 连线方向决定相对位置

```
连线从 A 指向 B，A 是 B 的 ParentID：

  B 在 A 下方：B.Y > A.Y + A.Height + 间距
  B 在 A 上方：B.Y + B.Height < A.Y - 间距
  B 在 A 右侧：B.X > A.X + A.Width + 间距
  B 在 A 左侧：B.X + B.Width < A.X - 间距

布局时节点的实际位置必须与连线的视觉方向一致，
Junction 方向由脚本自动计算，无需手动声明。
```

## 七、坐标计算方法

### 7.1 垂直层级分配（Y坐标）

```
同一连接层级的节点 Y 坐标相同（顶边对齐）

层间距计算：
  下层Y = 上层Y + 上层节点最大Height + 垂直间距
  推荐垂直间距：60 ~ 80px

实际数据层级示例：
  层级0（顶层无入边节点）：Y ≈ -276 ~ -267
  层级1：                  Y ≈ -170 ~ -146
  层级2：                  Y ≈  -56 ~  -39
  层级3：                  Y ≈    0 ~   83
  层级4：                  Y ≈  130 ~  181
  层级5：                  Y ≈  228 ~  284
  层级6：                  Y ≈  332 ~  389
  层级7（底部拓展节点）：   Y ≈  427 ~  479
```

### 7.2 水平居中对齐（X坐标）

```
同组节点（同一 ParentID 连出的多个节点）
水平中心对齐 Parent 节点的中心X：

Parent 中心X = Parent.X + Parent.Width / 2

同组节点总占用宽度：
  totalWidth = Σ(节点.Width) + (节点数-1) × 水平间距
  推荐水平间距：20 ~ 30px

第一个节点左上角X：
  startX = Parent中心X - totalWidth / 2

后续节点依次向右：
  节点[0].X = startX
  节点[1].X = 节点[0].X + 节点[0].Width + 水平间距
  节点[2].X = 节点[1].X + 节点[1].Width + 水平间距
  ...
```

**示例（来自实际数据）：**
```
节点 46（工作方式）X=153, W=72
  Parent中心X = 153 + 72/2 = 189

  连出4个方式节点，宽度均为57，水平间距20：
  totalWidth = 4×57 + 3×20 = 288
  startX = 189 - 288/2 = 189 - 144 = 45

  但实际数据中4个节点X均为344~345
  → 说明实际布局采用了垂直排列（Y递增）而非水平排列
  → 当子节点数量多且有进一步子节点时，
    优先采用垂直排列避免横向扩展过宽
```

### 7.3 垂直排列（子节点数量多时）

```
当一个节点的子节点数量 ≥ 4，
或子节点还有进一步的子节点时，
优先采用垂直排列：

  所有子节点 X 相同（左边界对齐 Parent 右侧或指定X）
  子节点[0].Y = 起始Y
  子节点[1].Y = 子节点[0].Y + 子节点[0].Height + 垂直间距
  子节点[2].Y = 子节点[1].Y + 子节点[1].Height + 垂直间距
  ...
  推荐垂直间距：10 ~ 20px

实际数据示例（节点46的子节点垂直排列）：
  177(方式0)  X=344, Y=150, H=26
  179(方式1)  X=345, Y=187, H=26  间距=187-(150+26)=11
  181(方式2)  X=345, Y=223, H=26  间距=223-(187+26)=10
  183(方式3)  X=345, Y=260, H=26  间距=260-(223+26)=11
```

## 八、冲突检测

### 8.1 节点矩形重叠检测

```
节点A：X区间[A.X, A.X+A.W]，Y区间[A.Y, A.Y+A.H]
节点B：X区间[B.X, B.X+B.W]，Y区间[B.Y, B.Y+B.H]

重叠条件（两个方向同时满足）：
  X重叠：A.X < B.X+B.W+minGap  且  A.X+A.W+minGap > B.X
  Y重叠：A.Y < B.Y+B.H+minGap  且  A.Y+A.H+minGap > B.Y

推荐最小间距 minGap：水平20px，垂直10px
```

### 8.2 簇区域边界重叠检测

```
簇A包围盒：[左A, 右A] × [上A, 下A]
簇B包围盒：[左B, 右B] × [上B, 下B]

若两个包围盒有重叠
→ 整体平移其中一个簇的所有节点
→ 直到两个包围盒间距 ≥ 50px
```

### 8.3 连线路径冲突检测

```
连线为直线时，检查路径上是否有其他节点阻挡：

连线 A→B 的路径：
  起点 = A的连接锚点（中心或边缘某点）
  终点 = B的连接锚点

节点C是否被穿越：
  C的中心点到线段AB的垂直距离 < C.Width/2 或 C.Height/2
  且 C在AB线段的投影范围内
  → 节点C被穿越，需移动C或调整A/B位置
```

## 九、微调与收尾

```
1. FC/CS 节点处理
   → 紧靠关联的DK/PK节点外侧
   → 不插入核心连接密集区
   → 同类节点Y坐标尽量对齐

   实际数据示例：
   FC节点 9(方波输出设计实例)    X=-550, Y=389  → 左下角边缘
   FC节点 300(交通灯设计实例)    X=-519, Y=-39  → 左侧边缘
   FC节点 250(单片机测频信号)    X=199,  Y=-154 → 右上边缘

2. 多入边节点位置确定
   → 有多个ParentID的节点，位置应兼顾所有来源节点
   → 放在所有来源节点的视觉重心位置
   → X ≈ 所有来源节点中心X的平均值
   → Y ≈ 所有来源节点下方第一层

3. 坐标取整
   → X/Y 取整到个位数即可（参考实际数据精度）
   → 避免出现小数坐标（如-406.92510986328125）
   → 小数坐标通常是拖拽产生的，应手工修正为整数

4. 视觉居中检查
   → 所有节点X范围中点应接近0
   → 所有节点Y范围中点应接近0
   → 避免图形整体偏向画布一侧

5. 间距参数参考
   水平节点间距（兄弟节点之间）：  20 ~ 30 px
   垂直层间距（父子节点之间）：    60 ~ 80 px
   垂直排列子节点间距：            10 ~ 20 px
   簇与簇之间间距：               50 ~ 150 px
```

## 十、完整流程速查

```
Step 1  读取表格数据
        → 整理每个节点的出边、入边、连接度
        → 识别多入边节点、无入边节点

Step 2  识别连接簇
        → 将频繁互联的节点归为同一簇
        → FC/CS节点单独标记

Step 3  区域分配
        → 高连接度节点放中心
        → 各簇分配独立空间区域
        → FC/CS节点安排在关联节点外侧边缘

Step 4  确定排列方向
        → 子节点少(≤3)：水平排列
        → 子节点多(≥4)或有进一步子节点：垂直排列

Step 5  分配Y坐标
        → 按连接层级分配，同层Y值相同
        → 层间距 = 上层最大Height + 60~80px

Step 6  分配X坐标
        → 水平排列：居中对齐父节点中心X
        → 垂直排列：X对齐父节点右侧或指定列X

Step 7  冲突检测
        → 矩形重叠检测
        → 簇区域边界重叠检测
        → 连线路径穿越检测

Step 8  微调收尾
        → FC/CS节点归边缘
        → 多入边节点位置取重心
        → 坐标取整（无小数）
        → 视觉居中检查
        → 间距检查
```

## 十一、操作前自检清单

```
□ 每个节点的出边和入边是否已整理清楚？
□ 多入边节点是否已识别（表格中同ID多行）？
□ 无入边节点（ParentID为空）是否已标记？
□ 连接簇是否已识别？同簇节点是否在同一区域？
□ 高连接度节点是否在中心位置？
□ 各簇的空间区域是否互不重叠（≥50px间距）？
□ 子节点排列方向是否已确定（水平/垂直）？
□ 同层节点Y值是否相同（顶边对齐）？
□ 水平排列时是否居中对齐了父节点中心X？
□ 所有节点矩形是否互不重叠（含最小间距）？
□ 连线路径是否没有穿越其他节点？
□ FC/CS节点是否已移至关联节点外侧边缘？
□ 是否存在小数坐标？是否已修正为整数？
□ 整体图形是否接近画布中心？
```
