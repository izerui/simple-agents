# 布局参考

## 1. 坐标系

- 画布原点：`(0, 0)`
- `x` 向右增大，向左减小
- `y` 向下增大，向上减小
- `x/y` 表示节点左上角位置
- 布局时必须同时考虑 `x`、`y`、`width`、`height`

## 2. 生成顺序

1. 先确定根节点和一级分区
2. 再确定每个分区向哪个方向展开
3. 先估算节点 `width/height`
4. 再填写 `x/y`

不要先写坐标再补尺寸。

## 3. 分区规则

- 任何层级的子分区都应优先均分到上、下、左、右四周，不只适用于一级分区
- 不要把任一层级的子分区长期压在单一方向
- 这种四周分区适用于所有高连接度节点；任何高连接度节点都应优先向上、下、左、右分区展开
- 每个分区都必须独立可见
- 分区之间不得重叠、压边或互相侵入
- 某个方向拥挤时，优先改到其他方向，不要继续往原方向堆
- 无论采用水平、垂直还是斜向外挂，多个同级子分区都应尽量均分，不要明显偏向单侧或单角

## 4. 展开规则

- 同组节点只能选一个主方向展开：横排或竖排，不要混用
- 步骤链优先竖向展开
- 枚举组优先横向展开；放不下时再改为竖向展开
- 同一个父节点子节点过多时，优先增加中间分组节点
- 不要把过多子节点直接压在同一层或同一轴线上
- 单一区域放不下时，开第二分区，不要靠缩小间距硬塞

## 5. 外挂规则

- 先决、案例、支持、策略等辅助节点放在主干外侧
- 外挂节点不要插入主链中间
- 案例和策略节点默认作为外围叶子节点，不反向回连主链

## 6. 连线规则

- 主展开优先水平或垂直连接
- 外挂节点优先斜向外侧连接
- 连线尽量短，不要跨多个分区
- 连线不要穿过主干核心区和密集节点区
- 如果一条补充关系会造成交叉或打断主链，优先改成分组、改层级或改为外围挂接

## 7. 尺寸规则

- 节点文字字号按 `12` 估算
- 连线关系文字字号按 `10` 估算
- 单行节点高度默认取 `16`：`12` 号字高 + 上下各 `2` 的留白
- 节点宽度按文本占位加左右留白估算；不要只按感觉给宽度
- 先按文本长度估算 `width/height`
- 文本长时优先加宽，避免压成很窄的高框
- 节点之间必须留出文字和连线的安全间距

## 8. 间距计算规则

- 设节点 `A = (x1, y1, w1, h1)`，节点 `B = (x2, y2, w2, h2)`
- 节点横向不重叠的条件必须满足其一：
  - `x1 + w1 + gapX <= x2`
  - `x2 + w2 + gapX <= x1`
- 节点纵向不重叠的条件必须满足其一：
  - `y1 + h1 + gapY <= y2`
  - `y2 + h2 + gapY <= y1`
- 若同级节点横向并排，必须满足：`next.x = prev.x + prev.width + gapX`
- 若同级节点纵向并排，必须满足：`next.y = prev.y + prev.height + gapY`
- 不允许只看 `x` 或只看 `y` 排布，必须同时结合宽高判断是否发生占位交叉

推荐最小安全间距：
- `gapX >= 40`
- `gapY >= 32`

连线文字留白规则：
- 若两节点之间要显示关系文字，当前方向上的间距必须额外预留 `labelGap`
- 横向连接时：`gapX >= 40 + labelGap`
- 纵向连接时：`gapY >= 32 + labelGap`
- `labelGap` 默认按 `24` 估算；关系文字较长时继续增大

分区间距规则：
- 若两个节点组属于不同分区，分区外框之间必须再额外预留 `zoneGap`
- `zoneGap` 默认不小于 `80`
- 新分区放不下时，优先拉大 `zoneGap` 或改到其他方向，不要压缩已有节点间距
