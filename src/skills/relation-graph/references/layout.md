## 一、核心目标

**避免连线交叉，节点不重叠，层级清晰，视觉整洁。**

---

## 二、画布与坐标系

```
画布是以中心点为原点的无边框二维平面：

        负Y（上）
          ↑
  负X ←──┼──→ 正X
  （左）  ↓  （右）
        正Y（下）

原点 (0, 0) = 画布视觉中心

节点坐标 (X, Y) = 节点矩形左上角相对于画布中心的偏移量
节点占用范围：
  X方向：[X,      X + Width ]
  Y方向：[Y,      Y + Height]
节点中心点：
  centerX = X + Width  / 2
  centerY = Y + Height / 2
```

**示例：**
```
节点 X=-44, Y=-18, Width=88, Height=36
→ 左上角在画布中心左上方
→ 节点中心恰好在画布原点(0,0)
→ 占用X范围：[-44, 44]
→ 占用Y范围：[-18, 18]

节点 X=100, Y=50, Width=72, Height=36
→ 左上角在画布中心右下方(100, 50)
→ 节点中心在(136, 68)
→ 占用X范围：[100, 172]
→ 占用Y范围：[50,  86]
```

## 三、基础换算公式

```
已知左上角坐标(X, Y)和尺寸(W, H)：

  右边界   = X + W
  下边界   = Y + H
  中心X    = X + W / 2
  中心Y    = Y + H / 2

已知期望中心点(cX, cY)，反算左上角：
  X = cX - W / 2
  Y = cY - H / 2
```

## 四、图结构分析（布局前必做）

### 4.1 整理连接关系

布局前先从 lines 数据整理出每个节点的：

```
对每个节点记录：
  - 它连出去的节点（出边目标）
  - 连进来的节点（入边来源）
  - 与它直接相连的所有节点
```

> 知识图谱是有向图，任意节点之间都可以建立连接，
> 不一定是树状结构，可能存在：
> - 一个节点有多个入边（多个节点指向它）
> - 节点之间存在环路
> - 孤立节点（无连接）
> - 跨区域的长距离连线

### 4.2 识别核心节点与密集区

```
连接度 = 该节点的出边数 + 入边数

连接度高的节点：
  → 视觉上应放在较中心的位置
  → 周围需要留出足够空间给连线

连接度低的节点：
  → 可以放在图形边缘
```

### 4.3 识别连接簇（自然分组）

将频繁互相连接的节点识别为一个簇，
同一个簇的节点在空间上应该靠近摆放。

```
示例（细胞分裂图）：

簇A：细胞周期相关
  node-2(细胞周期) — node-6(间期) — node-7(分裂期)
  — node-8(前期) — node-9(中期) — node-10(后期) — node-11(末期)
  — node-32(细胞周期阶段识别方法)

簇B：有丝分裂相关
  node-3(有丝分裂) — node-19(有丝分裂过程)
  — node-20 — node-21 — node-22 — node-23
  — node-29(洋葱根尖实验)

簇C：减数分裂相关
  node-4(减数分裂) — node-24(减数分裂过程)
  — node-25 — node-26 — node-30(蝗虫精母细胞实验)

簇D：染色体相关
  node-12(染色体) — node-13 — node-14
  — node-15 — node-16 — node-35

簇E：纺锤体相关
  node-17(纺锤体) — node-18(纺锤丝结构)
```

## 五、布局策略

### 5.1 以连接度最高的节点为中心

```
找出连接度最高的节点，将其放置在画布中心附近。
其他节点围绕它向外展开。

本例中 root(细胞分裂) 连接度最高 → 放在画布中心区域。
```

### 5.2 按连接方向分配空间区域

将画布划分为若干方向区域，每个连接簇占据一个区域，
簇与簇之间的区域不互相侵入。

```
区域划分原则：

1. 连接密集的簇 → 分配较大区域（上下方向展开）
2. 连接稀疏的簇 → 分配较小区域（左右侧紧凑排列）
3. 拓展性节点(FC/CS) → 安排在边角，不占据核心区域
4. 同一簇内节点 → 集中在同一区域，避免分散

示例区域分配：

        ┌─────────────────────────────────────┐
        │  上方：root的直接相连节点（一级展开） │
        └──────────────┬──────────────────────┘
                       │
  [左侧区域]           │           [右侧区域]
  簇E：纺锤体  ←── [root] ──→  簇D：染色体
                       │
        ┌──────────────┼──────────────────────┐
        │   左下       │      中下      右下   │
        │  簇A:细胞周期 │  簇B:有丝分裂  簇C:减数分裂 │
        └─────────────────────────────────────┘
                  [底部：FC/CS拓展节点]
```

### 5.3 连线方向决定相对位置

```
连线的 fromJunctionPoint 和 toJunctionPoint 属性
直接决定了两个节点的相对位置关系：

from:bottom → to:top    目标节点在来源节点的下方
from:top    → to:bottom 目标节点在来源节点的上方
from:right  → to:left   目标节点在来源节点的右方
from:left   → to:right  目标节点在来源节点的左方

布局时必须与这些属性保持一致，
否则连线会从错误锚点引出，产生绕路或交叉。
```

## 六、坐标计算方法

### 6.1 区域内节点排列

**同一区域内的节点，按照连接关系确定相对位置。**

```
垂直排列（上下展开）：
  上层节点Y + 上层节点Height + 垂直间距 = 下层节点Y
  推荐垂直间距：60 ~ 80px

水平排列（左右展开）：
  左侧节点X + 左侧节点Width + 水平间距 = 右侧节点X
  推荐水平间距：20 ~ 30px
```

### 6.2 同组节点水平居中对齐来源节点

```
来源节点中心X = 来源节点.X + 来源节点.Width / 2

同组目标节点总占用宽度：
  totalWidth = Σ(每个节点Width) + (节点数-1) × 水平间距

第一个目标节点的左上角X：
  startX = 来源节点中心X - totalWidth / 2

后续节点依次向右排列：
  节点[0].X = startX
  节点[1].X = 节点[0].X + 节点[0].Width + 水平间距
  节点[2].X = 节点[1].X + 节点[1].Width + 水平间距
  ...
```

**示例：来源节点中心X = -212，3个目标节点宽度均为56，间距20**

```
totalWidth = 3×56 + 2×20 = 208
startX     = -212 - 208/2 = -212 - 104 = -316

节点[0].X = -316
节点[1].X = -316 + 56 + 20 = -240
节点[2].X = -240 + 56 + 20 = -164

验证：
  群左边界 = -316
  群右边界 = -164 + 56 = -108
  群中心X  = (-316 + (-108)) / 2 = -212 ✓
```

### 6.3 Y坐标层级分配

```
同一连接层级的节点Y坐标相同（顶边对齐）

层级Y值计算：
  第N层Y = 上一层Y + 上一层节点最大Height + 垂直层间距

推荐层间距：
  节点最大Height + 60px
  （为连线和标签预留空间）
```

## 七、冲突检测

### 7.1 节点矩形重叠检测

```
节点A占用范围：X区间[A.X, A.X+A.W]，Y区间[A.Y, A.Y+A.H]
节点B占用范围：X区间[B.X, B.X+B.W]，Y区间[B.Y, B.Y+B.H]

发生重叠的条件（两个方向同时满足）：
  X方向重叠：A.X < B.X+B.W+间距  且  A.X+A.W+间距 > B.X
  Y方向重叠：A.Y < B.Y+B.H+间距  且  A.Y+A.H+间距 > B.Y

推荐最小间距：水平20px，垂直10px
```

### 7.2 区域边界重叠检测

```
每个节点簇的占用区域：
  左边界 = 该簇所有节点的 MIN(节点.X)
  右边界 = 该簇所有节点的 MAX(节点.X + 节点.Width)
  上边界 = 该簇所有节点的 MIN(节点.Y)
  下边界 = 该簇所有节点的 MAX(节点.Y + 节点.Height)

若两个簇的区域有重叠
→ 整体平移其中一个簇的所有节点坐标
→ 直到两个区域之间留有足够间距（推荐50px以上）
```

### 7.3 连线路径冲突检测

```
连线为直线时检查路径上是否有其他节点阻挡：

判断节点C是否被连线AB穿越：
  1. 计算节点C的中心点到线段AB的垂直距离d
  2. 若 d < C.Width/2 或 d < C.Height/2
     且 节点C的位置在AB线段投影范围内
  → 节点C被连线穿越，需要调整位置

解决方案：
  → 移动节点C的X或Y，使其偏离连线路径
  → 或调整来源/目标节点坐标使连线绕开
  → 或将直线连线改为折线连线
```

## 八、连线方向验证

布局完成后，逐条验证每条连线的方向属性与实际坐标是否匹配：

| 连线方向属性 | 实际位置要求 | 验证公式 |
|-------------|------------|---------|
| `from:bottom → to:top` | 目标在来源下方 | 目标.Y > 来源.Y + 来源.H |
| `from:top → to:bottom` | 目标在来源上方 | 目标.Y + 目标.H < 来源.Y |
| `from:right → to:left` | 目标在来源右侧 | 目标.X > 来源.X + 来源.W |
| `from:left → to:right` | 目标在来源左侧 | 目标.X + 目标.W < 来源.X |

> 位置与方向属性不符时：
> 优先调整节点坐标保持位置正确，
> 再同步修改连线的 Junction 属性。

## 九、微调与收尾

```
1. 拓展节点处理（FC/CS类型）
   → 集中排列在图形边角区域
   → 不插入核心连接密集区
   → 同类节点Y坐标对齐

2. 视觉居中检查
   → 所有节点X范围中点应接近0
   → 所有节点Y范围中点应接近0
   → 避免整体图形偏向画布一侧

3. 坐标取整
   → X/Y取整到10的倍数
   → 视觉整齐，便于手工微调

4. 间距参数参考
   水平节点间距：        20 ~ 30 px
   垂直层间距：         100 ~ 120 px
   簇与簇之间间距：     150 ~ 300 px
   节点与画布边缘间距：  50 px以上
```

## 十、完整流程速查

```
Step 1  整理连接关系
        → 记录每个节点的出边、入边、连接度

Step 2  识别连接簇
        → 将频繁互联的节点归为同一簇
        → 识别拓展节点(FC/CS)单独归组

Step 3  区域分配
        → 连接度高的节点放中心
        → 各簇分配独立的空间区域
        → 拓展节点安排在边角

Step 4  确定连线方向
        → 根据连线Junction属性确定节点相对位置关系
        → 同一簇内上下或左右展开方向统一

Step 5  分配Y坐标
        → 按连接层级分配，同层Y值相同
        → 层间距 = 节点最大Height + 60px

Step 6  分配X坐标
        → 同组节点水平居中对齐来源节点中心X
        → 依次向右排列，保持固定间距

Step 7  冲突检测
        → 矩形重叠检测
        → 区域边界重叠检测
        → 连线路径穿越检测

Step 8  连线方向验证
        → 核对每条连线的Junction属性与实际位置

Step 9  微调收尾
        → 拓展节点归边角
        → 坐标取整
        → 视觉居中
        → 间距检查
```

```

□ 连接度高的节点是否在中心位置？
□ 各簇的空间区域是否互不重叠？

□ 连线路径是否没有穿越其他节点？
□ FC/CS拓展节点是否已移至边角区域？
```
