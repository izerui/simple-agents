## 一、核心目标

**避免连线交叉，节点不重叠，连接关系清晰，视觉整洁。**

---

## 二、画布与坐标系

```
画布是以中心点为原点的无边框二维平面：

        负Y（上）
          ↑
  负X ←──┼──→ 正X
  （左）  ↓  （右）
        正Y（下）

原点 (0, 0) = 画布视觉中心

节点坐标 (X, Y) = 节点矩形左上角相对于画布中心的偏移量
节点占用范围：
  X方向：[X,   X + Width ]
  Y方向：[Y,   Y + Height]
节点中心点：
  centerX = X + Width  / 2
  centerY = Y + Height / 2
```

**示例：**
```
节点 X=-296, Y=-157, Width=72, Height=26
→ 左上角在画布中心左上方
→ 占用X范围：[-296, -224]
→ 占用Y范围：[-157, -131]
→ 节点中心：(-260, -144)
```

## 三、基础换算公式

```
已知左上角坐标(X, Y)和尺寸(W, H)：

  右边界   = X + W
  下边界   = Y + H
  中心X    = X + W / 2
  中心Y    = Y + H / 2

已知期望中心点(cX, cY)，反算左上角：
  X = cX - W / 2
  Y = cY - H / 2
```

## 四、数据格式说明

```
| NodeID | NodeText | NodeType | ParentID | RelationText |
| NodeX  | NodeY    | NodeWidth| NodeHeight| NodeSemantic |
```

**字段说明：**

```
NodeID        节点唯一标识（数字或字符串）
NodeText      节点显示文本
NodeType      节点类型：
                DK = 知识节点（核心概念）
                PK = 过程节点（结构化知识框架）
                FC = 拓展节点（案例/实验/延伸）
                CS = 策略节点（方法/建议）
ParentID      连线来源节点ID（谁连向我）
              同一节点有多个入边时，该节点出现多行，
              每行 ParentID 不同，X/Y/W/H 相同
RelationText  连线标注文字
NodeX         节点矩形左上角X坐标
NodeY         节点矩形左上角Y坐标
NodeWidth     节点矩形宽度
NodeHeight    节点矩形高度
NodeSemantic  节点语义标注
```

**多入边节点（同一节点多行）：**
```
| 163 | 定时器/计数器原理 | DK | 35  | 包含 | -356 | -56 | 115 | 69 |
| 163 | 定时器/计数器原理 | DK | 170 | 包含 | -356 | -56 | 115 | 69 |
| 163 | 定时器/计数器原理 | DK | 5   | 是前提 | -356 | -56 | 115 | 69 |
→ 节点163有3条入边，来自节点35、170、5
→ 节点163只有一个位置，所有行X/Y/W/H相同
```

**无入边节点（ParentID为空）：**
```
| 173 | 计算若干个机器周期的时间 | DK |  |  | -17 | -276 | 158 | 60 |
→ 该节点无入边，是图中的起点节点
```

## 五、图结构分析（布局前必做）

### 5.1 整理连接关系

```
对每个节点记录：
  入边：ParentID列 → 哪些节点连向它，从哪个方向来
  出边：作为ParentID出现 → 它连向哪些节点
  连接度 = 入边数 + 出边数
```

### 5.2 识别连接簇

```
将频繁互相连接的节点归为同一簇，同簇节点集中摆放。

簇的空间包围盒：
  左边界 = MIN(节点.X)
  右边界 = MAX(节点.X + 节点.Width)
  上边界 = MIN(节点.Y)
  下边界 = MAX(节点.Y + 节点.Height)

簇与簇之间保留间距：≥ 50px
```

### 5.3 节点类型与空间分配

```
DK：图的主体骨架，优先确定位置
PK：结构化框架，需要较大垂直展开空间
FC：案例/实验，放在关联节点附近外侧边缘
CS：方法/建议，放在关联节点旁侧边角
```

## 六、核心布局规则：出边方向

**这是避免连线交叉最重要的规则。**

### 6.1 出边向四周展开，避开入边方向

```
每个节点的出边连线，应向四个方向（上下左右）尽量均匀展开，
同时必须避开该节点入边进入的方向。

基本原则：
  入边从哪个方向来 → 出边不能从同一方向出去
  出边应优先使用入边以外的其他三个方向
```

**四个方向定义：**
```
  上方(Top)：   出边节点的 Y + Height < 当前节点.Y
  下方(Bottom)：出边节点的 Y > 当前节点.Y + Height
  左方(Left)：  出边节点的 X + Width < 当前节点.X
  右方(Right)： 出边节点的 X > 当前节点.X + Width
```

### 6.2 典型场景示例

**场景一：单一入边方向**
```
节点A 的入边从上方来（ParentID节点在A上方）
→ A 的出边应向 下、左、右 三个方向展开
→ 不应再向上方连出（会与入边重叠或交叉）

示意：
        [Parent]
           ↓ 入边（从上方来）
          [A]
    ↙出边  ↓出边  ↘出边
   [B]    [C]    [D]
```

**场景二：多个入边，来自同一方向**
```
节点163 入边来自节点35、170、5
若这三个节点都在163的上方或左上方
→ 163的出边应向 下方和右方 展开
→ 避开左侧和上方（入边方向）
```

**场景三：多个入边，来自不同方向**
```
节点 3-hwcmM 有来自163(左上)、300(左)、276(下)、9(右下)的入边
入边方向：左、上、下
→ 出边优先向 右方 展开
→ 左、上、下方向已被入边占用，出边尽量避免
```

**场景四：出边数量多，单方向放不下**
```
当出边节点数量较多，单一方向空间不足时：
→ 按出边数量和节点类型分配到多个方向
→ 优先分配到最空旷的方向
→ 同一方向的出边节点按水平或垂直排列展开

分配建议：
  主要出边（DK/PK类型）→ 分配到最主要的展开方向
  次要出边（FC/CS类型）→ 分配到剩余方向的边缘位置
```

### 6.3 方向选择优先级

```
确定出边方向的步骤：

Step 1  统计当前节点所有入边的来向
        → 标记已占用方向

Step 2  从未占用方向中选择出边方向
        优先级：下方 > 右方 > 左方 > 上方
        （下方视觉上最自然，符合阅读习惯）

Step 3  若未占用方向只有一个
        → 所有出边集中在该方向展开

Step 4  若所有方向都有入边（四面都有入边）
        → 选择入边数量最少的方向放出边
        → 或将出边节点放在入边节点的间隙位置

Step 5  出边数量多时
        → 按 DK/PK 优先、FC/CS 靠边 的原则
          分配到多个可用方向
```

### 6.4 方向与坐标关系

```
确定出边方向后，按以下规则计算出边节点坐标范围：

出边向下方：
  出边节点.Y ≥ 当前节点.Y + 当前节点.Height + 垂直间距(60~80px)
  出边节点.X 以当前节点中心X为基准水平展开

出边向上方：
  出边节点.Y + 出边节点.Height ≤ 当前节点.Y - 垂直间距(60~80px)
  出边节点.X 以当前节点中心X为基准水平展开

出边向右方：
  出边节点.X ≥ 当前节点.X + 当前节点.Width + 水平间距(40~80px)
  出边节点.Y 以当前节点中心Y为基准垂直展开

出边向左方：
  出边节点.X + 出边节点.Width ≤ 当前节点.X - 水平间距(40~80px)
  出边节点.Y 以当前节点中心Y为基准垂直展开
```

## 七、坐标计算方法

### 7.1 水平展开：居中对齐父节点

```
适用：出边方向为上方或下方时

父节点中心X = 父节点.X + 父节点.Width / 2

同组出边节点总宽度：
  totalWidth = Σ(节点.Width) + (节点数-1) × 水平间距(20~30px)

第一个节点左上角X：
  startX = 父节点中心X - totalWidth / 2

后续节点依次向右：
  节点[0].X = startX
  节点[1].X = 节点[0].X + 节点[0].Width + 水平间距
  节点[2].X = 节点[1].X + 节点[1].Width + 水平间距
  ...
```

### 7.2 垂直展开：对齐父节点侧边

```
适用：出边方向为左方或右方时，
      或出边节点数量 ≥ 4 时

父节点中心Y = 父节点.Y + 父节点.Height / 2

同组出边节点总高度：
  totalHeight = Σ(节点.Height) + (节点数-1) × 垂直间距(10~20px)

第一个节点左上角Y：
  startY = 父节点中心Y - totalHeight / 2

后续节点依次向下：
  节点[0].Y = startY
  节点[1].Y = 节点[0].Y + 节点[0].Height + 垂直间距
  节点[2].Y = 节点[1].Y + 节点[1].Height + 垂直间距
  ...
```

### 7.3 混合展开：多方向分配

```
适用：出边数量多，需要分配到多个方向时

步骤：
1. 将出边节点按类型分组
   主组(DK/PK) → 分配到主要展开方向
   副组(FC/CS) → 分配到次要展开方向

2. 主组按 7.1 或 7.2 计算坐标

3. 副组放在主组外侧边缘
   不与主组节点的X/Y区间重叠
```

## 八、冲突检测

### 8.1 节点矩形重叠

```
节点A：X区间[A.X, A.X+A.W]，Y区间[A.Y, A.Y+A.H]
节点B：X区间[B.X, B.X+B.W]，Y区间[B.Y, B.Y+B.H]

重叠条件（两方向同时满足）：
  X重叠：A.X < B.X+B.W+minGap  且  A.X+A.W+minGap > B.X
  Y重叠：A.Y < B.Y+B.H+minGap  且  A.Y+A.H+minGap > B.Y

推荐 minGap：水平20px，垂直10px
```

### 8.2 簇区域边界重叠

```
两个簇的包围盒有重叠
→ 整体平移其中一个簇的所有节点
→ 直到两个包围盒间距 ≥ 50px
```

### 8.3 连线路径穿越节点

```
连线 A→B 为直线时，检查是否有节点C被穿越：

  节点C中心到线段AB的垂直距离 < C.Width/2 或 C.Height/2
  且 C在AB线段的投影范围内
  → 节点C被穿越

解决：移动节点C，或调整A/B位置使连线绕开
```

### 8.4 出边与入边连线交叉检测

```
当一个节点同时有多条入边和多条出边时，
检查这些连线是否交叉：

判断方法：
  入边连线段集合 与 出边连线段集合
  逐对检查是否相交

若相交：
  → 调整出边节点位置，使出边连线远离入边连线
  → 通常将出边节点整体向远离入边来源的方向平移
```

## 九、微调与收尾

```
1. FC/CS 节点处理
   → 紧靠关联的DK/PK节点外侧边缘
   → 不插入核心连接密集区
   → 放在对应节点出边方向的末端位置

2. 多入边节点位置
   → 位置应兼顾所有来源节点
   → X ≈ 所有来源节点中心X的平均值
   → Y ≈ 所有来源节点下方（或其他主要方向）第一层
   → 确认新位置后，检查所有入边方向是否仍然合理

3. 坐标取整
   → X/Y 取整为整数，避免小数坐标
   → 小数坐标（如-406.925...）是拖拽产生的，应修正

4. 视觉居中检查
   → 所有节点X范围中点应接近0
   → 所有节点Y范围中点应接近0

5. 间距参数参考
   水平节点间距（同层兄弟）：   20 ~ 30 px
   垂直层间距（父子之间）：     60 ~ 80 px
   垂直排列子节点间距：         10 ~ 20 px
   左右方向展开间距：           40 ~ 80 px
   簇与簇之间间距：             50 ~ 150 px
```

## 十、完整流程速查

```
Step 1  读取表格数据
        → 整理每个节点的出边、入边、连接度
        → 识别多入边节点、无入边节点

Step 2  识别连接簇
        → 将频繁互联节点归为同一簇
        → FC/CS节点单独标记

Step 3  区域分配
        → 高连接度节点放中心
        → 各簇分配独立空间区域
        → FC/CS节点安排在关联节点外侧边缘

Step 4  确定每个节点的出边方向
        → 统计入边来向，标记已占用方向
        → 出边优先选择未占用方向
        → 出边数量多时按类型分配到多个方向

Step 5  分配Y坐标
        → 出边向上/下展开：按层级分配Y，同层Y值相同
        → 出边向左/右展开：按父节点中心Y垂直居中

Step 6  分配X坐标
        → 出边向上/下展开：以父节点中心X水平居中
        → 出边向左/右展开：以父节点左/右边界为基准

Step 7  冲突检测
        → 矩形重叠检测
        → 簇区域边界重叠检测
        → 连线路径穿越检测
        → 出边与入边连线交叉检测

Step 8  微调收尾
        → FC/CS节点归边缘
        → 多入边节点取重心位置
        → 坐标取整（无小数）
        → 视觉居中检查
        → 间距检查
```
