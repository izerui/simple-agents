## 一、核心目标

**避免连线交叉，节点不重叠，连接关系清晰，视觉整洁。**

---

## 二、画布与坐标系

```
画布是以中心点为原点的无边框二维平面：

        负Y（上）
         ↑
  负X ←──┼──→ 正X
  （左）  ↓  （右）
        正Y（下）

原点 (0, 0) = 画布视觉中心

节点坐标 (X, Y) = 节点矩形左上角相对于画布中心的偏移量
节点占用范围：
  X方向：[X,   X + Width ]
  Y方向：[Y,   Y + Height]
节点中心点：
  centerX = X + Width  / 2
  centerY = Y + Height / 2
```

---

## 三、基础换算公式

```
已知左上角坐标(X, Y)和尺寸(W, H)：

  右边界   = X + W
  下边界   = Y + H
  中心X    = X + W / 2
  中心Y    = Y + H / 2

已知期望中心点(cX, cY)，反算左上角：
  X = cX - W / 2
  Y = cY - H / 2
```

## 四、数据格式说明

```
| NodeID | NodeText | NodeType | ParentID | RelationText |
| NodeX  | NodeY    | NodeWidth| NodeHeight| NodeSemantic |
```

**字段说明：**

```
NodeID        节点唯一标识（数字或字符串）
NodeText      节点显示文本
NodeType      节点类型：
                DK = 知识节点（核心概念）
                PK = 过程节点（结构化知识框架）
                FC = 拓展节点（案例/实验/延伸）
                CS = 策略节点（方法/建议）
ParentID      连线来源节点ID（谁连向我）
              同一节点有多个入边时该节点出现多行，
              每行ParentID不同，X/Y/W/H相同
RelationText  连线标注文字
NodeX         节点矩形左上角X坐标
NodeY         节点矩形左上角Y坐标
NodeWidth     节点矩形宽度
NodeHeight    节点矩形高度
NodeSemantic  节点语义标注
```

**多入边节点（同一节点多行）：**
```
| 163 | 定时器/计数器原理 | DK | 35  | 包含 | -356 | -56 | 115 | 69 |
| 163 | 定时器/计数器原理 | DK | 170 | 包含 | -356 | -56 | 115 | 69 |
| 163 | 定时器/计数器原理 | DK | 5   | 是前提 | -356 | -56 | 115 | 69 |
→ 节点163有3条入边，来自节点35、170、5
→ 节点163只有一个位置，所有行X/Y/W/H相同
```

**无入边节点（ParentID为空）：**
```
| 173 | 计算若干个机器周期的时间 | DK |  |  | -17 | -276 | 158 | 60 |
→ 该节点无入边，是图中的起点节点
```

## 五、图结构分析（布局前必做）

### 5.1 整理每个节点的连接情况

```
对每个节点记录：
  入边列表：哪些节点连向它（来自哪些ParentID）
  出边列表：它连向哪些节点（它作为ParentID出现的目标）
  连接度   = 入边数 + 出边数
```

### 5.2 统计每个节点的方向占用情况

```
对每个节点，在确定坐标后记录：

  已占用方向 = 入边方向 ∪ 已分配的出边方向

  入边方向：来源节点相对于当前节点的方位
  出边方向：目标节点相对于当前节点的方位

  四个基本方向：上(Top) 下(Bottom) 左(Left) 右(Right)
```

### 5.3 识别连接簇

```
将频繁互相连接的节点归为同一簇，同簇节点集中摆放。

簇的空间包围盒：
  左边界 = MIN(节点.X)
  右边界 = MAX(节点.X + 节点.Width)
  上边界 = MIN(节点.Y)
  下边界 = MAX(节点.Y + 节点.Height)

簇与簇之间保留间距：≥ 50px
```

### 5.4 节点类型与空间分配

```
DK：图的主体骨架，优先确定位置
PK：结构化框架，需要较大展开空间
FC：案例/实验，放在关联节点外侧边缘
CS：方法/建议，放在关联节点旁侧边角
```

## 六、核心布局规则：出边方向分配

**这是避免连线交叉最重要的规则。**

### 6.1 基本原则

```
每个节点的连线方向资源共有四个：上、下、左、右

规则一：出边方向必须避开入边方向
  → 入边从哪个方向进来，出边不能从同一方向出去

规则二：出边方向必须避开已分配的其他出边方向
  → 每条出边尽量占用一个独立方向
  → 同一方向上不应同时存在多组不相关的出边

规则三：向四周均匀展开
  → 优先将出边分散到不同方向
  → 避免所有出边挤在同一方向造成密集交叉
```

### 6.2 方向判断标准

```
判断节点B相对于节点A的方位：

  B在A的上方：B.Y + B.Height ≤ A.Y
  B在A的下方：B.Y ≥ A.Y + A.Height
  B在A的左方：B.X + B.Width ≤ A.X
  B在A的右方：B.X ≥ A.X + A.Width

  若同时满足两个条件（如既偏上又偏右）
  → 以偏移量较大的方向为主方向
  → 偏移量 = |中心点差值|
    水平偏移 = |A.centerX - B.centerX|
    垂直偏移 = |A.centerY - B.centerY|
    水平偏移 > 垂直偏移 → 主方向为左或右
    垂直偏移 > 水平偏移 → 主方向为上或下
```

### 6.3 方向分配流程

```
对当前节点N，按以下步骤分配出边方向：

Step 1  统计入边方向
        → 找出所有ParentID节点的位置
        → 记录每个入边的主方向
        → 汇总：已占用方向 = {所有入边方向}

Step 2  统计待分配出边
        → 找出所有以N为ParentID的目标节点
        → 按节点类型排序：DK/PK优先，FC/CS其次

Step 3  逐条分配出边方向
        → 从可用方向中（未被入边或已分配出边占用）选择
        → 优先级：下 > 右 > 左 > 上
        → 每分配一条出边，将该方向加入已占用方向
        → 更新：已占用方向 = 入边方向 ∪ 已分配出边方向

Step 4  出边数量超过可用方向数时
        → 将多条出边合并到同一方向
        → 同一方向内按节点类型分层或并排
        → DK/PK在内侧（靠近N），FC/CS在外侧（远离N）

Step 5  所有四个方向都已被占用时
        → 选择连线数量最少的方向叠加
        → 将新出边节点放在该方向已有节点的外侧
```

### 6.4 典型场景示例

**场景一：单入边，多出边**
```
节点A 只有1条入边从上方来，有4条出边：

  已占用方向：上（入边）
  可用方向：下、左、右

  分配方案：
    出边1(DK) → 下方
    出边2(DK) → 右方
    出边3(PK) → 左方
    出边4(FC) → 下方（与出边1同方向，放在旁边）

        [Parent]
           ↓ 入边
          [A]
   ↙左     ↓下    ↘右
  [出边3] [出边1] [出边2]
          [出边4]
```

**场景二：两个入边，来自不同方向**
```
节点B 有入边从上方和左方来，有3条出边：

  已占用方向：上（入边）、左（入边）
  可用方向：下、右

  分配方案：
    出边1(DK) → 下方
    出边2(DK) → 右方
    出边3(FC) → 下方（与出边1同方向，放外侧）

  [LeftParent] →→ [B] ←← [TopParent不在图中，B在其下方]
                   ↓出边1    →出边2
                 [出边1]    [出边2]
                 [出边3]
```

**场景三：四个方向都有入边**
```
节点C 四个方向都有入边（高度连接的中心节点）：

  已占用方向：上、下、左、右（全部）
  → 选择入边数量最少的方向叠加出边
  → 将出边节点放在该方向已有入边节点的外侧
  → 或将FC/CS出边节点放在斜向（对角）位置
```

**场景四：同方向有多条出边**
```
节点D 向下方有5条出边：

  排列方式一（水平并排）：
    5个节点在同一Y层水平排列
    以D的中心X为基准居中对齐

  排列方式二（垂直堆叠）：
    5个节点在同一X列垂直排列
    以D的中心X偏移到侧边为基准

  选择依据：
    每个出边节点还有进一步出边 → 用垂直堆叠（为下一层留横向空间）
    出边节点是叶节点           → 用水平并排（视觉更紧凑）
```

### 6.5 方向与坐标范围对应

```
出边向下方：
  出边节点.Y ≥ 当前节点.Y + 当前节点.Height + 垂直间距
  垂直间距推荐：60 ~ 80px
  出边节点.X 以当前节点中心X为基准水平展开

出边向上方：
  出边节点.Y + 出边节点.Height ≤ 当前节点.Y - 垂直间距
  垂直间距推荐：60 ~ 80px
  出边节点.X 以当前节点中心X为基准水平展开

出边向右方：
  出边节点.X ≥ 当前节点.X + 当前节点.Width + 水平间距
  水平间距推荐：40 ~ 80px
  出边节点.Y 以当前节点中心Y为基准垂直展开

出边向左方：
  出边节点.X + 出边节点.Width ≤ 当前节点.X - 水平间距
  水平间距推荐：40 ~ 80px
  出边节点.Y 以当前节点中心Y为基准垂直展开
```

## 七、坐标计算方法

### 7.1 水平展开：居中对齐父节点

```
适用：出边方向为上方或下方

父节点中心X = 父节点.X + 父节点.Width / 2

同组出边节点总宽度：
  totalWidth = Σ(节点.Width) + (节点数-1) × 水平间距

第一个节点左上角X：
  startX = 父节点中心X - totalWidth / 2

后续节点依次向右：
  节点[0].X = startX
  节点[1].X = 节点[0].X + 节点[0].Width + 水平间距
  节点[2].X = 节点[1].X + 节点[1].Width + 水平间距
  ...

水平间距推荐：20 ~ 30px
```

### 7.2 垂直展开：居中对齐父节点

```
适用：出边方向为左方或右方，
      或同方向出边节点数量 ≥ 4 且各有进一步子节点

父节点中心Y = 父节点.Y + 父节点.Height / 2

同组出边节点总高度：
  totalHeight = Σ(节点.Height) + (节点数-1) × 垂直间距

第一个节点左上角Y：
  startY = 父节点中心Y - totalHeight / 2

后续节点依次向下：
  节点[0].Y = startY
  节点[1].Y = 节点[0].Y + 节点[0].Height + 垂直间距
  节点[2].Y = 节点[1].Y + 节点[1].Height + 垂直间距
  ...

垂直间距推荐：10 ~ 20px
```

### 7.3 多方向混合展开

```
适用：出边节点分配到了多个不同方向

步骤：
1. 按方向将出边节点分组
2. 每组独立按 7.1 或 7.2 计算坐标
3. 检查各方向的节点是否与其他方向节点产生重叠
4. 若有重叠，整体平移冲突方向的节点组
```

## 八、冲突检测

### 8.1 节点矩形重叠

```
节点A：X区间[A.X, A.X+A.W]，Y区间[A.Y, A.Y+A.H]
节点B：X区间[B.X, B.X+B.W]，Y区间[B.Y, B.Y+B.H]

重叠条件（两方向同时满足）：
  X重叠：A.X < B.X+B.W+minGap  且  A.X+A.W+minGap > B.X
  Y重叠：A.Y < B.Y+B.H+minGap  且  A.Y+A.H+minGap > B.Y

推荐 minGap：水平20px，垂直10px
```

### 8.2 簇区域边界重叠

```
两个簇的包围盒有重叠
→ 整体平移其中一个簇的所有节点
→ 直到两个包围盒间距 ≥ 50px
```

### 8.3 连线路径穿越节点

```
连线 A→B 为直线时，检查是否有节点C被穿越：

  节点C中心到线段AB的垂直距离 < C.Width/2 或 C.Height/2
  且 C在AB线段的投影范围内
  → 节点C被穿越，移动C或调整A/B位置使连线绕开
```

### 8.4 入边与出边连线交叉

```
当一个节点同时有多条入边和多条出边时：

检查方法：
  将所有入边线段和出边线段两两比对
  判断是否存在相交

若相交：
  → 重新检查出边方向分配是否正确执行了规则6.1
  → 调整出边节点位置，使出边方向远离入边方向
  → 通常将冲突的出边节点整体向另一可用方向平移
```

## 九、微调与收尾

```
1. FC/CS 节点处理
   → 紧靠关联DK/PK节点的出边方向末端
   → 不插入核心连接密集区
   → 同类节点Y坐标尽量对齐

2. 多入边节点位置
   → 位置应兼顾所有来源节点的视觉重心
   → X ≈ 所有来源节点中心X的平均值
   → Y ≈ 所有来源节点在主要入边方向上的延伸位置
   → 确认后重新检查该节点的出边方向是否仍然合理

3. 坐标取整
   → X/Y 取整为整数，避免小数坐标
   → 小数坐标（如 -406.925...）是拖拽产生的，应修正

4. 视觉居中检查
   → 所有节点X范围中点应接近0
   → 所有节点Y范围中点应接近0

5. 间距参数参考
   水平节点间距（同方向兄弟节点）：  20 ~ 30 px
   垂直层间距（上下方向父子）：      60 ~ 80 px
   垂直排列子节点间距：              10 ~ 20 px
   水平方向展开间距（左右父子）：    40 ~ 80 px
   簇与簇之间间距：                  50 ~ 150 px
```

## 十、完整流程速查

```
Step 1  读取表格数据
        → 整理每个节点的出边列表、入边列表、连接度
        → 识别多入边节点、无入边节点

Step 2  识别连接簇
        → 将频繁互联节点归为同一簇
        → FC/CS节点单独标记

Step 3  区域分配
        → 高连接度节点放中心
        → 各簇分配独立空间区域
        → FC/CS节点安排在关联节点出边末端

Step 4  逐节点分配出边方向
        → 统计入边方向 → 标记已占用方向
        → 逐条分配出边，每条占用一个新方向
        → 已占用方向 = 入边方向 ∪ 已分配出边方向
        → 出边数超过可用方向时，同方向内分层排列

Step 5  计算坐标
        → 出边向上/下：水平居中对齐父节点中心X
        → 出边向左/右：垂直居中对齐父节点中心Y
        → 多方向混合时各组独立计算后检查重叠

Step 6  冲突检测
        → 矩形重叠检测
        → 簇区域边界重叠检测
        → 连线路径穿越检测
        → 入边与出边连线交叉检测

Step 7  微调收尾
        → FC/CS节点归出边末端
        → 多入边节点取视觉重心
        → 坐标取整（无小数）
        → 视觉居中检查
        → 间距检查
```

## 十一、操作前自检清单

```
□ 每个节点的出边列表和入边列表是否已整理清楚？
□ 多入边节点是否已识别（表格中同ID多行）？
□ 无入边节点（ParentID为空）是否已标记？
□ 每个节点的入边来向是否已确认？
□ 每条出边是否已分配到独立方向（避开入边和其他出边方向）？
□ 出边数量超过可用方向时，是否已合理合并到同一方向分层？
□ 已占用方向 = 入边方向 ∪ 已分配出边方向，是否每步都更新？
□ 各簇的空间区域是否互不重叠（≥50px间距）？
□ 出边向上/下时：是否居中对齐了父节点中心X？
□ 出边向左/右时：是否居中对齐了父节点中心Y？
□ 所有节点矩形是否互不重叠（含最小间距）？
□ 入边与出边连线是否存在交叉？
□ 连线路径是否没有穿越其他节点？
□ FC/CS节点是否已移至关联节点出边末端？
□ 是否存在小数坐标？是否已修正为整数？
□ 整体图形是否接近画布中心？
```
