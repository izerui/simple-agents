# 知识建模图生成

帮助高校教师为课程创建完整的知识建模图。分两个阶段执行。

---

## 第一阶段：收集信息与建立关系

### 目标

收集课程信息，生成知识点，通过语义关系连接知识点形成知识图谱。

### 步骤1：收集必填信息

老师需要提供：
- **课程名称**：如"单片机原理及应用"
- **课程类型**：专业基础课程/公共基础课程/项目化教学课程
- **适用专业**：如"本科自动化专业"
- **学生层次**：如"大三学生"
- **核心知识**：知识建模图的核心知识点

### 步骤2：收集参考资料

询问是否有：
- **PDF/Word文档**：教学大纲、教材章节等，可上传附件
- **网址链接**：在线教程、参考链接等

如有，读取内容提取知识点。

### 步骤3：生成知识点

根据收集的信息，生成完整的知识点清单：
- 列出所有相关知识点
- 标注每个知识点的类型（data.type：2=陈述性知识, 3=程序性知识, 5=认知策略, 6=事实范例）
- 确定知识点层级（1-4层）

**知识点确定规则：**
1. 知识点应该是某种学习的结果
2. 同时列出相关先决知识（必须有，梳理到知识点末端）
3. 教学材料中没有但需要学生掌握的知识点，也必须列出
4. 如果不确定是不是知识点，团队达成共识即可

### 步骤4：建立语义关系

使用10种语义关系连接知识点：
1. 各类包含 2. 组成 3. 构成 4. 是一种 5. 具有属性 6. 具有特征 7. 定义 8. 并列 9. 是前提 10. 支持

**语义关系说明：**
- 各类包含：总分关系，至少包含2个子内容
- 组成/构成：分总关系
- 是一种：上下位关系
- 是前提：强调必要性
- 支持：提供辅助条件

### 步骤5：确认信息完整性

如果信息不足，继续询问老师补充，直到信息充足为止。

## 第二阶段：生成JSON建模图

### 目标

将第一阶段生成的知识点和关系，转换为符合规范的知识建模图JSON。

### 画布坐标系说明

整个画布是以**中心点(0,0)**为原点，向四周无限延伸的无边区域。

**坐标方向：**
- 原点(0,0)为中心点
- 向左移动：x 减小（如 x - 100）
- 向右移动：x 增大（如 x + 100）
- 向上移动：y 减小（如 y - 100）
- 向下移动：y 增大（如 y + 100）

**节点定位：**
- 节点位置由 **x、y** + **宽高(width、height)** 决定
- 节点中心点 = (x + width/2, y + height/2)

**布局原则：**
- 核心知识点放置在画布中心(0,0)附近
- 子知识点按层级向外延伸分布
- **【核心要求】节点绝对不能重叠，连接线绝对不能交叉**

**核心约束条件：**

1. **节点间距**：
   - 任意两个节点之间**至少保持18px间距**
   - 考虑节点的x、y、width、height，确保不重叠

2. **节点重叠计算规则（重点：必须考虑源节点的宽高）**：

   **【关键原则】计算子节点坐标时，必须从源节点的边界开始计算，而不是从源节点的x/y坐标开始！**

   假设父节点 A(xA, yA, width: wA, height: hA)，子节点 B(width: wB, height: hB)：
   - **右侧子节点**：
     - A的右边界 = xA + wA
     - B.x >= A的右边界 + 间距 = (xA + wA) + 间距
     - 示例：A(x=0, w=200)，B.x >= 0 + 200 + 150 = 350
   - **左侧子节点**：
     - A的左边界 = xA
     - B的右边界 = B.x + wB
     - B的右边界 <= A的左边界 - 间距 = xA - 间距
     - 示例：A(x=0)，B.x + wB <= 0 - 150，即 B.x <= -150 - wB
   - **下方子节点**：
     - A的底部边界 = yA + hA
     - B.y >= A的底部边界 + 间距 = (yA + hA) + 间距
     - 示例：A(y=0, h=60)，B.y >= 0 + 60 + 100 = 160
   - **上方子节点**：
     - A的顶部边界 = yA
     - B的底部边界 = B.y + hB
     - B的底部边界 <= A的顶部边界 - 间距 = yA - 间距
     - 示例：A(y=0)，B.y + hB <= 0 - 100，即 B.y <= -100 - hB

3. **连接线交叉预防**：
   - 相邻层级的节点尽量采用不同的y值或x值偏移
   - 同一父节点的多个子节点，按顺序错开排列
   - 必要时增大层间距或节点间距

4. **跨父节点子节点防交叉（重点）**：
   - 当多个父节点的子节点位于同一层级（左右布局）时，需要整体考虑所有子节点的布局
   - 不同父节点的子节点要在y方向上错开，避免交叉
   - 计算公式：
     ```
     父节点A的子节点范围: yA_min ~ yA_max
     父节点B的子节点范围: yB_min ~ yB_max
     需要满足: yA_max + 间距 < yB_min  或  yB_max + 间距 < yA_min

     示例：
     - 父节点A的4个子节点y范围: -451 ~ -61
     - 父节点B的4个子节点y范围: 25 ~ 398
     - 两者y方向错开，避免交叉
     ```

5. **同父节点多级子节点防重叠**：
   - 当同一个父节点的多个子节点又连接到下一级子节点时，这些孙节点应该在x方向上错开分布
   - 不能所有孙节点都在同一个x位置，应该依次向右偏移
   - 计算公式：
     ```
     父节点A有3个子节点B1,B2,B3，每个Bi又有子节点Ci
     - B1的子节点: x = B1.x + 偏移量1
     - B2的子节点: x = B2.x + 偏移量2 (偏移量2 > 偏移量1)
     - B3的子节点: x = B3.x + 偏移量3 (偏移量3 > 偏移量2)

     示例：
     - node-15(x=687) → node-19(x=1121)
     - node-16(x=687) → node-20(x=1085)
     - 子节点x位置不同，避免垂直排列重叠
     ```

6. **空间预留**：
   - 生成前先计算所有节点所需的总空间
   - 根据子节点数量和层级深度，预留足够的画布区域
   - 避免出现后续节点没有足够空间摆放的情况

5. **对称布局计算（重点）**：

   **上下连接的对称计算**：
   ```
   源节点A: x=0, y=0, width=200, height=60, 右边界=200
   子节点在A右侧，需要计算从右边界开始：
   - 第一个子节点x: 200 + 间距
   - 多个子节点时，从右边界开始均匀分布
   ```

   **左右连接的对称计算**：
   ```
   源节点A: x=0, y=0, width=200, height=60, 底部边界=60
   子节点在A下方，需要计算从底部边界开始：
   - 第一个子节点y: 60 + 间距
   - 多个子节点时，从底部边界开始均匀分布
   ```

   **错误示例（未考虑宽高）**：
   ```
   源节点A: x=0, width=200
   错误: 子节点x = 0 + 150 = 150  ← 从x坐标开始计算，错误！
   正确: 子节点x = 0 + 200 + 150 = 350  ← 从右边界(x+width)开始计算，正确！
   ```

   **正确示例**：
   ```
   父节点A: x=0, y=0, width=200, height=60
   2个子节点在右侧，水平对称分布：
   - 子节点总宽度: 140 * 2 + 30 = 310
   - 起始x = (0 + 200) + 50 = 250  ← 从右边界开始
   - 第一个子节点: x = 250
   - 第二个子节点: x = 250 + 140 + 30 = 420

   父节点A下方有2个子节点，垂直对称分布：
   - 子节点总高度: 45 * 2 + 30 = 120
   - 起始y = (0 + 60) + 50 = 110  ← 从底部边界开始
   - 第一个子节点: y = 110
   - 第二个子节点: y = 110 + 45 + 30 = 185
   ```

**子节点布局规则：**

1. **单个子节点**：
   - 上下连接：可以放在上下位置（x相同，y有一定距离），连接线垂直
   - 左右连接：可以放在左右位置（y相同，x有一定距离），连接线水平

2. **多个子节点 - 上下连接（目标节点在源节点上方/下方）**：
   - 需要在x方向均匀分布，同时y方向也有一定距离
   - 尽量保持与源节点图形中心点对称
   - 计算公式：
     ```
     父节点中心: centerX = x + width/2, centerY = y + height/2
     子节点数量: n
     子节点总宽度: totalWidth = sum(子节点width) + (n-1) * spacing
     起始x: startX = centerX - totalWidth/2
     第i个子节点x: x_i = startX + sum(前i个节点width+spacing)
     y偏移: 根据层级和布局方向计算
     ```

3. **多个子节点 - 左右连接（目标节点在源节点左侧/右侧）**：
   - 需要在y方向均匀分布，同时x方向也有一定距离
   - 尽量保持与源节点图形中心点对称
   - 计算公式：
     ```
     父节点中心: centerX = x + width/2, centerY = y + height/2
     子节点数量: n
     子节点总高度: totalHeight = sum(子节点height) + (n-1) * spacing
     起始y: startY = centerY - totalHeight/2
     第i个子节点y: y_i = startY + sum(前i个节点height+spacing)
     x偏移: 根据层级和布局方向计算
     ```

4. **对称布局示例**：
   ```
   父节点A: x=0, y=0, width=200, height=60, centerX=100, centerY=30
   有3个子节点B,C,D: width=140, height=45, spacing=30

   方案1（上下连接，水平对称分布）:
   - B: x=-195, y=-150
   - C: x=30, y=-150
   - D: x=255, y=-150
   - 保持y一致，x均匀分布

   方案2（左右连接，垂直对称分布）:
   - B: x=300, y=-45
   - C: x=300, y=0
   - D: x=300, y=45
   - 保持x一致，y均匀分布
   ```

**多层布局计算：**
- 第二层节点：以第一层节点为基准计算坐标
- 第三层节点：以第二层节点为基准计算坐标
- 以此类推，确保每一层都不与相邻层重叠

**连接点优先级规则：**

根据目标节点相对于起始节点的位置，结合节点宽高自动计算最佳连接点。

**判断逻辑：**

设起始节点A(xA, yA, widthA, heightA)，目标节点B(xB, yB, widthB, heightB)

```
// 判断相对位置
B在A右侧：B.x > A.x + A.width/2
B在A左侧：B.x + B.width < A.x
B在A下方：B.y > A.y + A.height/2
B在A上方：B.y + B.height < A.y
```

**连接点选择规则：**

| 目标节点位置 | toJunctionPoint（终点） | fromJunctionPoint（起点） |
|:-------------|:----------------------|:------------------------|
| 右上（B在A右上方） | bottom | right |
| 右下（B在A右下方） | top | right |
| 左上（B在A左上方） | bottom | left |
| 左下（B在A左下方） | top | left |
| 正右（B在A正右侧） | left | right |
| 正左（B在A正左侧） | right | left |
| 正上（B在A正上方） | bottom | top |
| 正下（B在A正下方） | top | bottom |
| 其他情况 | border | border |

**说明：**
- 根据B相对于A的位置，选择能让连线最短的连接点组合
- 连接点选择原则：fromJunctionPoint选择离目标节点近的边，toJunctionPoint选择离起始节点近的边
- 无法用简单规则判断时（如跨越多行多列），默认使用 border 自动计算最近边框

```
示例1：起始节点A(x=0,y=0,width=200,height=60)，目标节点B(x=300,y=-50)
→ B在A右侧上方 → fromJunctionPoint="right", toJunctionPoint="bottom"

```

### 步骤4：data字段与知识类型

data字段用于存储节点和边的自定义属性：

**节点 data 字段：**
```
"data": {
  "type": 数字,
  "ownerContainerId": "",
  "backgroundImage": "",
  "imageFit": "cover",
  "startPostion": {"x": 数值, "y": 数值}  // 与节点 x, y 保持一致
}
```

**边 data 字段：**
```
"data": {
  "type": 数字  // 如 9 表示思政点
}
```

**知识类型映射到 data.type：**

| data.type | 类型 | 说明 |
|:----------|:-----|:------|
| 2 | 陈述性知识 | 是什么？为什么？概念、原理 |
| 3 | 程序性知识 | 怎么做？操作步骤 |
| 5 | 认知策略 | 如何学得好？学习方法 |
| 6 | 事实范例 | 案例、例子 |
| 9 | 思政点 | 课程思政点 |

### 步骤5：JSON根对象结构

完整的JSON还需要包含根对象：

| 参数 | 说明 | 类型 | 必选 |
|:-----|:-----|:-----|:-----|
| rootId | 根节点id，随机字符串（如 kp001） | string | 是 |
| datetime | 时间戳 | number | 否 |
| nodes | 节点数组 | array | 是 |
| lines | 边数组 | array | 是 |

### 步骤6：质量检查

生成后检查：
1. 知识点涵盖 data.type (2, 3, 5, 6) 四种类型
2. 核心知识点标红、结构化框架标蓝、先决知识点标绿
3. 包含类关系至少2个子内容
4. 无孤立节点

### 步骤7：JSON结构验证

生成 JSON 后，必须验证结构是否符合要求：

**1. 根对象结构**：
```json
{
  "rootId": "kp001",  // 字符串，必填
  "datetime": 1234567890,  // 数字，可选
  "nodes": [...],  // 数组，必填
  "lines": [...]  // 数组，必填
}
```

**2. 节点对象属性**（每个节点必须包含）：
| 属性 | 类型 | 必填 | 说明 |
|:-----|:-----|:-----|:-----|
| id | string | 是 | 节点id，不能重复 |
| text | string | 是 | 节点文本 |
| x | number | 是 | x坐标 |
| y | number | 是 | y坐标 |
| data.type | number | 是 | 知识点类型：2, 3, 5, 6, 9 |
| fontColor | string | 否 | 文字颜色 |
| borderColor | string | 否 | 边框颜色 |
| nodeShape | number | 否 | 形状：0=圆形，1=矩形 |

**3. 连接线对象属性**（每条边必须包含）：
| 属性 | 类型 | 必填 | 说明 |
|:-----|:-----|:-----|:-----|
| id | string | 是 | 边id，不能重复 |
| from | string | 是 | 源节点id |
| to | string | 是 | 目标节点id |
| text | string | 否 | 关系名称 |

**4. 布局验证**：
- 节点不能重叠
- 连接线不能交叉
- 节点间距至少 18px

## 快速参考

### 知识点类型（data.type）

| data.type | 类型 | 说明 |
|:----------|:-----|:------|
| 2 | 陈述性知识 | 是什么？为什么？概念、原理 |
| 3 | 程序性知识 | 怎么做？操作步骤 |
| 5 | 认知策略 | 如何学得好？学习方法 |
| 6 | 事实范例 | 案例、例子 |
| 9 | 思政点 | 课程思政点 |

### 颜色标注

文字颜色(fontColor)和边框颜色(borderColor)同时改变：

- 红色(#FF4D4F)：核心知识点
- 蓝色(#1890FF)：结构化知识框架
- 绿色(#52C41A)：先决知识点
- 黑色(#000000)：普通知识点

### nodeShape 形状

- 0：圆形
- 1：矩形

### lineShape 线条形状

- 1：直线
- 2：样式2
- 3：样式3
- 4：折线
- 5：样式5
- 6：样式6

### dashType 虚线类型

- 0：实线
- 1：虚线

### 程序性知识标注规则

- 下级知识点为步骤或流程 → 标识为程序性知识(PK)
- 下级知识点不是步骤或流程 → 标识为陈述性知识(DK)

### 不同课程类型要求

**就业方向项目化教学课程：**
- 知识点挖掘全面，注重培养学生工作任务能力
- 必须包含：任务方案研发、任务实施方案制定、任务实施流程、效果评测、常见问题解决方案
- 知识点不能仅来自教材，需融入工程经验

**应用型研究/专业基础/公共基础课程：**
- 知识点涵盖与后续项目化课程关联的知识组块
- 陈述性知识点后列出范例知识点
- 理论性强的知识点后必须有范例
