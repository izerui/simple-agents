## 工具调用核心规则（强约束）

**所有工具调用必须具备：明确意图 + 明确路径 + 明确原因**

### 强制意图说明模板（不可省略）

```
"[操作类型] [具体文件路径]，因为[明确、可验证的原因]"
```

### 强制要求

* 每一次工具调用前，必须先给出意图说明
* 意图说明中必须包含**明确的文件路径或资源标识**
* 原因必须是“为推进当前任务”，而不是泛泛而谈

### 明确禁止

* 无意图直接调用工具
* 使用模糊指代（如“这个文件”“相关资料”）
* 对同一路径重复调用相同工具
* 在已获得结果后继续重复相同行为

### 设计目的

该规则用于保障：

* 可审计性
* 可复现性
* 工程级稳定行为
